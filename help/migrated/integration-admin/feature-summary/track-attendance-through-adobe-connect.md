# 透過 Adobe Connect 錄影檢視追蹤出席情況

## 概觀

Adobe Learning Manager 可以透過錄影檢視來追蹤 Adobe Connect 虛擬教室課程的出席情況。 當學習者錯過直播課程，但持續在 Adobe Connect 上觀看錄影足夠長時，Learning Manager 會標記該學習者為已參加該課程。 學習者完成該會話模組後，即可朝完成該會話所屬的學習物件邁進。

在此功能之前，Learning Manager 無法記錄觀看 Connect 錄影的學習者的出席情況。 錯過直播課程的學習者無法完成，必須由講師親自介入並手動記錄出席。 此功能移除了這個手動步驟。 Adobe Connect 會報告誰觀看了哪段錄影以及觀看了多久，而 Learning Manager 則會將觀看時間與帳戶設定的完成標準進行比較。

一旦學習者符合錄製課程的完成標準，學習者就會在管理應用程式中被標記。

學習者的電子郵件 ID 在 Adobe Learning Manager 與 Adobe Connect 中應該相同，因為 Adobe Learning Manager 會使用相同的電子郵件 ID 將學習者重新導向至 Adobe Connect。
預設的同步頻率以及整合管理員可設定的最短間隔為一小時。


## 誰做什麼

| 角色 | 他們做什麼 |
|----------------------------|-----------------------------------------------------------------------------------------------------------------------|
| 學習者 | 在錯過直播會話後，打開錄影並觀看。 |
| 講師 | 在現場錄音時開始錄音，所以錄音和逐字稿都存在。 |
| 整合管理員 | 設定出席同步所使用的 Adobe Connect 帳戶，並設定同步排程或開啟或關閉同步。 |
| 作者或交付經理 | 排程虛擬教室課程，並於多日課程中重複使用持續教室。 |
| Adobe Connect | 擷取每位學習者的電子郵件與錄影觀看時間，並透過 API 公開錄製檢視者的清單。 |

每個角色在讓記錄式出勤制度運作上都有獨立角色。

## 使用案例

### 學習者錯過了一場即時課程

學習者無法加入線上線上教室課程。 之後，學習者會在 Learning Manager 中開啟該課程並觀看錄影。 一旦觀看時間達到完成標準，Learning Manager 會將學習者標記為已出席，學習者無需向講師求助即可完成模組。

### 一個只部分觀看的學習者

學習者打開錄影，但觀看的片段少於所需分播。 完成條件未被滿足，因此 Learning Manager 不會將學習者標記為已出席。

### 在同一個持續空間進行多日工作階段

作者或交付經理會在同一個持續存在的 Connect 房間排定第 1、2 天和第 3 天的會話。 他們可以在不登入 Adobe Connect 的情況下看到並重複使用房間名稱。

## 主要特色

| 特色 | 它的功能 |
|-------------------------------|-------------------------------------------------------------------------------------------------------------------------------|
| 自動出席 | 當學習者觀看錄影足夠長，達到規定的門檻限制時，將該學員標記為已參與基於 Connect 的虛擬教室課程。 |
| 透過 Connect 觀看時間 | 使用 Adobe Connect 所擷取的學習者電子郵件與錄影觀看時間。 |
| 完成標準門檻 | 當觀看時間達到完成條件中設定的百分比時，會標記學習者已完成該模組。 |
| 僅限實際觀看時長 | 計算學習者真正觀看的時間。 拖曳尋找條不會增加觀看時間。 |
| 排程同步 | 依照整合管理員可控的排程執行後端管線，並可開啟或關閉。 |
| 持續的房間可見性 | 在實例層級顯示 Connect 房間名稱，讓作者能跨天重複使用持續存在的房間。 |

## 出席追蹤的運作方式

*從學習者開啟錄影到Learning Manager標記模組完成。*

### 端對端流程

1. 講師會在 Adobe Connect 上主持線上直播課堂並開始錄影。 錄音與逐字稿會在課程結束後公開。

1. 錯過課程的學習者選擇錄影以觀看。 Adobe Connect 會自動追蹤檢視。

1. Adobe Connect 會記錄學習者的電子郵件以及學習者實際觀看的時間。

1. 在已設定的排程中，後端 SnapLogic 管線會呼叫 Adobe Connect API，並擷取指定時間段內的錄影檢視器清單。 此管線使用在整合管理中設定的 Adobe Connect 帳戶。

1. Learning Manager 會將每位檢視者對應到對應的課程與模組。

1. Learning Manager 會將學習者的總觀看時間與完成標準進行比較。

1. 若觀看時間符合條件，Learning Manager 會將學習者標記為已完成該模組。 在後端，Learning Manager 會透過填寫使用者課程分級 CSV 來記錄此情況。

>[!NOTE]
>
>Adobe Connect 不會將資料推送至 Learning Manager。 Learning Manager 會從 Adobe Connect 實例層級拉取，例如「這五個使用者在過去 24 小時內觀看了這六段錄影。」 因此，出席率會在下一次流程執行後更新，而非學習者觀看結束的那一刻。

### 完成標準與觀看時長

學習者必須觀看完成條件所定義的錄影百分比。 請記住以下規則：

* 百分比是針對錄製時長，而非排定的會話時長。 如果一段 15 分鐘的課程只錄了 5 分鐘，則所需時間會以這 5 分鐘為準。 Adobe Connect 提供錄製時長。

* 百分比是在 Learning Manager 端設定的。 這是整個帳號共用的設定，不是每個實例都有的。 同樣的設定已經套用在現場課程上，例如要求 80% 的參與度。

* Adobe Connect 會記錄學習者實際觀看的時間長短。 用搜尋列快進不算數，Learning Manager 會處理 Connect 經過的觀看時間。

| 完成標準 | 錄音長度 | 所需觀看時間 | 結果 |
|-------------------------|------------------------------------|-----------------------|-------------------------------------------------------------|
| 50% | 5分鐘 | 2.5分鐘 | 觀看 2.5 分鐘後標記為完成。 |
| 50% | 5分鐘（課程為15分鐘） | 2.5分鐘 | 這是根據5分鐘的錄音，而非15分鐘的錄音。 |
| 0% | 任何 | 開門後沒有 | 打開錄影就足夠了。 |

### 資格期限

Learning Manager 僅在學習物件完成日期之前，採用以記錄為基礎的出席。 如果學習物件沒有完成日期，Learning Manager 會使用父學習物件的完成日期。

### 排程同步

整合管理員控制管線執行的頻率。 排程可以是每小時或每週，以及其他間隔，整合管理員可以開啟或關閉排程。 每次執行都會使用同一個 Adobe Connect 帳戶。

### 改變之處

* 當使用者新增第一天建立的持久性房間時，Learning Manager 會授予他們該房間的存取權。 他們之後可以把同一個房間加進其他日子的課程。
* Learning Manager 會在虛擬教室 URL **旁**&#x200B;的課程詳細資料中，以實例層級顯示 Connect 教室名稱。
* 在預設情況下，Learning Manager 會顯示課程建立時已設定的教室。

### 限制與考量

* 出席不是即時的，因為 Learning Manager 是依照排程拉取資料。
* 此功能僅涵蓋基於 Connect 的虛擬教室課程。
* 必須有錄影，因此講師必須在現場課程中開始錄製。
* 學習者會透過 Adobe Connect 所擷取的電子郵件地址進行配對。
* 拖曳尋找條不會增加觀看時間。
* 基於記錄的出席會在學習物件或父學習物件完成日期時停止。

### 需要記住的重點

* 觀看時間必須大於或等於規定的百分比（例如5分鐘的50%等於2.5分鐘）。 如果學習者反覆觀看課程，但觀看時間仍不足於規定的觀看時間，則觀看時間不算數。 然而，即使學習者在不同時間點分段觀看課程並符合門檻標準，觀看時間仍會累積。 例如，如果學習者在第一天觀看該課程的一分鐘，隔天從離開時再觀看 1.5 分鐘，觀看時間就會累積起來。 這發生在 Adobe Connect 端。

* 完成標準可在課程層級及帳戶層級設定。 效果與現場會話參與相同。

* 預設的同步頻率以及整合管理員可設定的最短間隔為一小時。

* 學習者的電子郵件 ID 在 Adobe Learning Manager 與 Adobe Connect 中應該相同，因為 Adobe Learning Manager 會使用相同的電子郵件 ID 將學習者重新導向至 Adobe Connect。

### 常見問題

**Q.學習者是否必須參加現場課程？**
**A.** 不。 錯過現場課程的學習者，只要長時間觀看錄影，仍可被標記為已出席。

**Q.學習者需要觀看多少錄影內容？**
**A.** 完成標準中應用於錄製時長的百分比。 例如，50%的錄影至少需要2.5分鐘的觀看時間。

**Q.在錄音中跳過內容算嗎？**
**A.** 不。 Adobe Connect 記錄的是學習者實際觀看的時間，因此拖曳搜尋條不計入。

**Q.學習者一看完就開始記錄出席紀錄嗎？**
**A.** 不。 Learning Manager 會依照排程從 Adobe Connect 擷取檢視器資料，因此在下一次流程執行後，出席情況會更新。

**Q.Adobe Connect 會將資料傳送到 Learning Manager嗎？**
**A.** 不。 Learning Manager 會拉出它。 這是 Adobe Connect 實例層級的拉取機制，而非推送。

**Q.Learning Manager 如何知道是哪位學習者觀看了？**
**A.Adobe** Connect 會記錄學習者的電子郵件以及錄影觀看時間。 Learning Manager 會將這些資料對應到課程和模組。

**Q.誰控制同步執行的頻率？**
**A.** 整合管理員負責設定排程，並可開啟或關閉。

**Q.每個實例的完成百分比是設定好的嗎？**
**A.** 不。 這是整個帳號中常見的設定。

**Q.多日會話可以共用一個 Connect 房間嗎？**
**答。** 是的。 作者可以在其他工作坊的課程中重複使用第一天建立的持久教室，且教室名稱會在 Learning Manager 的實例層級顯示。
