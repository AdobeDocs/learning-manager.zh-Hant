# 講師在現場樞紐課程中的角色

作為 Adobe Learning Manager 的講師，您在提供有效的 Live Hub 課程並確保學習體驗引人入勝中扮演關鍵角色。

本文將介紹講師工作流程及管理 ALM 中 Live Hub 課程的最佳實務，包括課程前準備、課程中互動管理，以及課程後的成果回顧。

## 講師工作流程 Live Hub 課程

### 在課程開始前做好準備

在預定開始時間前，請使用課程網址（session URL）先加入 Live Hub 房間，讓學習者加入前就已完成。 查看 [加入會議](./join-live-hub-session-as-an-instructor.md) 以獲取更多資訊。

從房間裡，你可以：

* 設定學習者權限，例如啟用螢幕共享與白板存取。 以教師身份查看 [「管理房間設定](./manage-settings.md) 」以獲得更多資訊。

* 事先用 AI 生成的破冰活動或你自己的問題來創建投票。 查看 [建立並啟動投票](./create-and-launch-a-poll.md#create-a-poll-using-ai) 以獲取更多資訊。

* 設計小測驗（選擇題或多題題），以促進參與度與評估。 請參閱 [「建立與管理測驗](./create-and-manage-a-quiz.md#create-a-quiz) 」以獲取更多資訊。

* 設定 Miro 以實現即時協作與腦力激盪。 查看 [分享白板](./share-a-whiteboard.md#share-miro-and-other-external-whiteboards) 以獲取更多資訊。

* 設計分組討論室、分配學習者，並為每個房間加入指示。 查看 [、創建及管理分組討論室](./create-and-manage-breakout-rooms.md#design-a-breakout-session) 以獲取更多資訊。

* 上傳參考資料，讓 AI 能在課程中產生準確且具情境感的學習者問題答案。 查看 [以講師](./use-the-chat-panel-as-an-instructor.md#upload-files-for-better-responses) 身份使用聊天面板以獲得更多資訊。

### 管理會話

在課程中，專注於有效傳遞內容，同時維持學習者的參與度。 你可以：

* 開始並管理線上課程。

* 錄製錄音，方便播放並稍後回顧。 查看 [錄製一場會話](./record-a-session.md) 以獲取更多資訊。

* 利用現有的互動工具如分享、聊天、問答等呈現內容。

* 分享你的螢幕、註解以突出資訊，並匯出快照。 查看 [分享您的螢幕](./share-your-screen-as-an-instructor.md) 以獲取更多資訊。

* 啟動準備好的投票與測驗，並決定是否向學習者展示結果。 請參閱 [「建立與管理測驗](./create-and-manage-a-quiz.md) 」以獲取更多資訊。

* 透過聊天、投票和討論，促進學習者互動。

* 使用參與指標（高、中、低）監控參與者參與度，並追蹤出席情況。 查看  [追蹤參與者參與](./track-the-participant-engagement.md) 度以獲取更多資訊。

* 管理音訊與視訊權限。

### 管理學習者互動

確保整個會談過程中溝通順暢與協作。 你可以：

* 請使用聊天面板和問答回應問題，包括在問題標籤中的 AI 輔助回覆。 查看 [以講師](./use-the-chat-panel-as-an-instructor.md#draft-replies-to-participant-questions-with-ai) 身份使用聊天面板以獲得更多資訊。

* 在「每個人」分頁與所有參與者互動，或在「私人」分頁進行直接對話。

* 視需要啟用或限制學習者權限。

* 從與會者面板視圖管理出席或缺席的學習者，監控舉手與反應，發送私人訊息，靜音麥克風，並降低舉手。 更多資訊請參閱 [「管理參加者」面板](./manage-the-attendees-panel.md) 。

* 促進討論與團體活動，包括啟動分組討論室，並在學習者求助時加入房間。

* 處理會議中的干擾或技術問題。 更多資訊請參閱 [Live Hub](../kb/troubleshooting-guide-for-live-hub.md#connection-issues) 的故障排除指南。

### 結束本次會議

訓練結束後，所有參與者的課程結束。 會談結束後，請檢視會堂總覽頁面的成果：

* 存取錄音和逐字稿，必要時編輯錄音。 查看 [錄製一場會話](./record-a-session.md#view-topics-in-recording) 以獲取更多資訊。

* 檢視場次分析，包括課程摘要;互動內容如投票、測驗、分組討論、問答及反應;參與者活動;以及可下載的報告。 欲了解更多資訊，請參閱 [會話儀表板](./view-the-session-dashboard.md) 。
