# 追蹤參與者的參與情況

Live Hub 中的參與者參與功能讓講師能即時看到學習者在現場課程中的參與情況。 它將瀏覽器焦點、聊天活動和投票參與率合併成一個互動等級，以綠色、黃色或紅色指示顯示。 用它來偵測注意力的下滑，並即時調整你的表達方式。

參與者參與度顯示在特定時間點主教室中所有學習者的平均參與程度。 一旦有學習者加入課程，關卡就會立即刷新。

參與者參與度僅在直播會話中計算並顯示。

>[!NOTE]
>
> 只有教官才能看到參與度計量表。 學習者無法取得它。

## 了解參與度等級的計算方式

您可以在 Live Hub 工作階段介面的右上角查看參與度等級。 它以學習者參與度的即時指標形式出現。

![參與程度指標](assets/engagement-level-indicator.png)
*Live Hub 介面，在右上角顯示參與者的參與情況。*

系統會利用三個因素計算參與度：

* **瀏覽器焦點**：學習者螢幕上的虛擬教室分頁或視窗是否啟用。

* **聊天活動**：學習者透過課程聊天訊息參與。

* **投票參與**：會議期間提交給民調的回應。

## 識別參與度與指標

參與者參與度使用根據學習者互動的顏色編碼指標。 以下是每個等級的意義：

| **參與度** | **色彩指示器** | **描述** |
|----|----|----|
| 高 | 綠色 | 學習者積極參與課程。 |
| 中等 | 黃色 | 學習者偶爾會與人互動，並保持適度參與。 |
| 低 | 紅色 | 學習者在課程中幾乎沒有互動或注意力減弱。 |
