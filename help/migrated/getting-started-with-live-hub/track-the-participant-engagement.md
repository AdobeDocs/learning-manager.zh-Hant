# 賽道參與者參與度

Live Hub 的參與者互動讓講師能即時掌握學習者在現場課程中的參與度。 它將瀏覽器焦點、聊天活動和投票參與合併成一個互動等級，顯示為綠色、黃色或紅色指標。 用它來發現注意力的下滑，並即時調整你的表達方式。

參與者參與度顯示了某一時間點主教室所有學習者的平均參與程度。 一旦有學習者加入，關卡就會自動刷新。

參與者參與度僅在現場會議中計算並顯示。

>[!NOTE]
>
> 只有教官能看到參與度計量表。 學習者無法取得這些資訊。

## 了解參與度的計算

你可以在 Live Hub 會話介面右上角查看互動程度。 它呈現為學習者參與度的即時指標。

![參與度指標](assets/engagement-level-indicator.png)
*Live Hub 介面，右上角顯示參與者參與度。*

系統利用三個因素計算參與度：

* **瀏覽器焦點**：學習者螢幕上的虛擬教室分頁或視窗是否啟用。

* **聊天活動**：學習者透過課程聊天中的訊息參與。

* **投票參與**：會議期間提交的投票回應。

## 識別參與程度與指標

參與者參與度使用基於學習者互動的顏色編碼指標。 以下是每個關卡的意義：

| **參與度** | **色彩指示器** | **描述** |
|----|----|----|
| 高 | 綠色 | 學習者積極參與課程。 |
| 媒介 | 黃色 | 學習者偶爾會互動，但參與度適中。 |
| 低 | 紅色 | 學習者在課程中幾乎沒有互動或注意力減弱。 |
