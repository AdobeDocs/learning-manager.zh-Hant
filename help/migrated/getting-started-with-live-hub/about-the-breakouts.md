# 關於越獄事件

分組討論室讓講師能將 Live Hub 課程拆分成較小的小組。 學習者會加入這些房間進行討論、活動或合作，活動結束後會自動回到主課程。 分組討論室適合腦力激盪、團體活動和專注學習。

講師可以創建並管理分組討論室，指派學習者，並依照指示引導活動。 課程期間，講師可監控教室活動、即時檢視討論摘要，並在需要時提供支援。

學習者在分配的教室內協作、參與討論，並透過共享指示與摘要保持對齊活動。

課程結束後，講師可透過課程報告及課程儀表板檢視分組討論與成果，促進更佳的分析與後續追蹤。

## 分組討論的好處

* **鼓勵合作**:Participants ，可以分成小組進行專注討論和活動。

* **即時教室可見**&#x200B;性：講師能監控各教室的參與度、參與度與協助需求，而不打斷參與者。

* **AI 驅動的討論洞見**：即時摘要幫助教師快速理解各教室的討論內容，並有效引導活動。

* **結構化活動指導**：提供指導學習者在分組活動中。

* **彈性的參與者管理**：參與者可輕鬆分配與調整，以支援不同的學習形式。

* **課後洞見與報告**：講師可在課堂儀表板中檢視摘要、報告及課程資料，分析成果並改進未來課程。

## 分組討論術語

這些術語說明分組討論的運作方式以及參與者在活動中的互動方式。

| **術語** | **描述** |
|----|----|
| **分組討論** | 虛擬教室中的臨時課程，參與者被分成較小的小組，進行專注的討論或活動。 |
| **分組討論室** | 這些小組是分組討論中較小的小組，學生會被分組參與特定活動。 |
| **分組說明** | 講師會在分組討論室中指派任務或討論。 |
| **突破報告** | 這是評估學習者在分組討論中參與度的指標，供講師用來監控與評估參與程度。 |

## 分組會議工作流程

分組討論環節遵循結構化流程，包括設置、現場協作及會議結束。

### 設置分組討論

在開始分組討論前，講師會根據課程需求建立並配置分組討論室。

* 定義分組討論室的數量。

* 可透過拖放參與者，自動或手動分配學習者到教室。

* 加入活動指引以引導學習者。

這種安排確保學習者在課程開始前就已組織並與活動對齊。

### 分組討論期間

分組討論開始後，學習者會被帶到分配的房間，共同參與指定的活動。

* 學習者在分組討論室中互動並參與其中。

* 講師可以監控教室活動、追蹤參與度，並回應協助請求。

* 講師可以即時查看討論摘要，並在需要時加入教室引導學習者。

此階段著重於合作與積極參與。

### 分組討論結束後

分組討論結束後，所有參與者會自動回到主教室。

* 學習者會回到主會話視圖。

* 講師可透過報告檢視整體活動、成果及課程摘要。

* 講師可以建立一個重複的課程，以重複使用相同的設定以供未來活動使用。

這標誌著分組活動的完成，並允許事後回顧。
