Live Hub 包含管理員、作者、講師與學習者三個角色，各自負責訓練流程的不同部分。 本文件依角色重新組織了原始 Live Hub FAQ 內容，讓每位受眾能快速找到最相關的問題。

## 行政長官

+++我該如何為我的 Adobe Learning Manager 帳號啟用 Live Hub？

以管理員身份登入，並進入 Learning > Live Hub 的 AI。 請開啟此帳號的 Enable Live Hub，以便讓 Live Hub 可用於虛擬教室訓練。 啟用後，作者可在 Adobe Learning Manager 內建立 Live Hub 會話。

+++

+++我可以讓 Live Hub 成為預設的虛擬教室服務提供者嗎？

是的。 啟用 Live Hub 後，開啟 Live Hub 作為預設的 Live Training 工具。 在建立虛擬教室模組時，Live Hub 會被預先選擇，但如果需要，仍可選擇其他提供者。

+++

+++管理員可以啟用哪些 AI 助理來進行 Live Hub 會話？

管理員可在 Live Hub 啟用 AI，並選擇作者與講師可用的 AI 助理。 可協助的助理包括：

* 投票助理：利用 AI 生成投票。
* 問答助理：協助篩選學習者問題及草擬回應。
* 分組討論監控助理：負責監督分組討論。
* 錄音主題產生器：從錄音中建立結構化主題與筆記。
* 教練尋找助理：推薦適合使用 AI 課程的教練。

+++

## 作者

+++我的帳號可以使用 Live Hub 嗎？

Live Hub（測試版）將於 2026 年 8 月起開放。 管理員可以啟用或停用 Adobe Learning Manager 帳號的 Live Hub。 若啟用 Live Hub，作者可在建立虛擬教室模組時選擇其為即時訓練提供者。 如果 Live Hub 選項無法使用，請聯絡你的管理員，為你的帳號啟用此功能。

+++

+++我該如何建立一個 Live Hub 課程？

登入 Adobe Learning Manager 並選擇「建立課程」。 在課程目錄頁面，選擇新增，輸入課程名稱與描述，然後將模組加入課程目錄。 將模組設定為虛擬教室，並選擇 Live Hub 作為教學工具。 Live Hub 必須在您的 Adobe Learning Manager 帳號啟用後，才會顯示為可用的即時訓練提供者。 如果您在可用選項列表中未看到 Live Hub，請聯絡您的管理員。

+++

+++我該如何將課程設定為 Live Hub 會話？

作者可以建立課程並新增虛擬教室模組。 在模組設定中，選擇 Live Hub 作為現場訓練提供者，然後輸入所需的課程細節，如標題、說明、時間表及時區。 儲存模組後在 Live Hub 排程。

>[!NOTE]
>
>Live Hub 必須由您的 Adobe Learning Manager 帳號管理員啟用，才能將其列為可用的即時訓練提供者。

+++

+++我可以在建立課程時新增講師嗎？

是的。 選擇 Live Hub 後，將一位或多位講師加入課程，然後選擇新增>儲存。

+++

+++我該如何發佈 Live Hub 課程？

完成課程設定後，選擇儲存>發佈。 課程一旦發布，即可開放學習者註冊及排課時間。

+++

## 講師

### 加入會議

+++我該如何以講師身份加入 Live Hub 課程？

登入 Adobe Learning Manager，並在即將到來的課程中找到該課程。 選擇會話網址以開啟預加入畫面，然後選擇加入以進入會話。

+++

+++我可以在參加者抵達前加入課程嗎？

是的。 講師可以在預定開始時間前加入課程，準備教室、上傳 AI 答案參考內容、設定設定，並確認一切準備就緒後才進入。

+++

+++在遊戲開始前，我可以設定什麼？

課程開始前，講師可透過設定學習者權限、製作投票與測驗、設置分組討論室、連接 Miro 進行協作，以及上傳參考資料以支援 AI 驅動的問答，來準備虛擬教室。

+++

### 學習者權限與隱藏字幕

+++我該如何允許參與者共享螢幕並使用白板？

在會議室，從控制列選擇設定，然後選擇參與者權限。 啟用分享畫面和使用白板，然後選擇完成來套用變更。

+++

+++我應該什麼時候設定參與者權限？

在課程開始前設定學習者權限，作為準備教室的一部分。 這確保參與者在加入時具備適當的協作與參與能力。

+++

+++我要怎麼開啟隱藏字幕？

從控制列選擇更多選項，選擇「字幕」，然後啟用「顯示字幕」。

+++

+++為什麼我應該使用隱藏式字幕？

隱藏字幕透過在課程中以文字形式顯示語音內容，提升無障礙性。 他們能幫助參與者更輕鬆地跟上討論，並在各種學習與聆聽環境中支持參與者。

+++

### 民調

+++產生 AI 驅動的破冰者投票需要哪些資訊？

要產生 AI 驅動的破冰遊戲投票，請提供模組名稱與模組描述。 Live Hub 利用這些資訊設計入門問題，幫助學習者在課程開始時投入。

+++

+++產生由 AI 驅動的知識檢查投票需要具備什麼條件？

AI 驅動的知識檢查投票會從會議文字稿產生。 在產生知識檢查投票前，請確保有轉錄資料且已擷取足夠的會話內容。 產生的問題是根據會議中討論的主題而定。

+++

+++我要如何建立投票？

打開「投票與測驗」面板，選擇「投票」標籤。 手動建立投票或用 AI 產生，然後選擇儲存。 投票會加入會話中，並可隨時啟動。

+++

+++我可以用 AI 來產生投票嗎？

是的。 Live Hub 能產生 AI 驅動的投票，幫助提升學習者在課程中的參與度。

* 選擇 Icebreaker 以產生由 AI 驅動的入門投票。
* 選擇知識檢定以產生投票，協助評估參與者對討論主題的理解程度。

+++

+++我可以自己創建投票問題嗎？

是的。 選擇「自建」以建立自訂投票，並有你自己的問題與回應選項。

+++

+++我該如何在遊戲過程中啟動投票？

在「投票與測驗」面板中，選擇「投票」標籤，然後建立新投票或選擇先前儲存的投票。 選擇「啟動」以讓參與者能取得投票。 參與者可即時提交回應，結果會隨著收到回應自動收集。

+++

+++我可以讓參與者看到投票結果嗎？

是的。 啟動投票時，啟用「向所有學習者顯示結果」，以便在課程中與參與者分享結果。

+++

+++我應該什麼時候使用投票？

利用投票鼓勵參與、收集回饋、發起討論，或在整個課程中評估學習者的理解度。 知識檢查投票對於在進入下一部分前，測量對關鍵主題的理解度特別有用。

+++

### 測驗

+++我要怎麼做一個小測驗？

打開「投票與測驗」面板，選擇「測驗」標籤。 選擇「建立新測驗」，選擇題型，新增問題和答案選項，辨識正確答案，然後選擇「完成」。

+++

+++支援哪些題型？

Live Hub 支援以下測驗題型：

* 選擇題：參賽者選擇一個正確答案。
* 多重答案：參與者選擇所有適用答案。

+++

+++我該如何在小考中加入更多題目？

在建立測驗時，選擇 + 新增問題以新增問題。 完成問題添加後，選擇完成。

+++

+++我該如何在遊戲過程中啟動測驗？

在投票與測驗面板中，選擇測驗標籤，找到你想使用的測驗，然後選擇啟動。 參與者可以即時回應測驗。

+++

+++我可以讓參加者查看測驗結果嗎？

是的。 啟動測驗時，啟用「顯示結果」給所有學習者，讓學生在課程中與參與者分享結果。

+++

+++什麼時候應該使用小考？

利用小測驗評估學習者的理解程度、強化關鍵概念，並在課程中衡量知識記憶力。 小考能幫助你找出可能需要額外解釋或討論的主題。

+++

### 白板

+++我該如何在 Live Hub 會話中建立白板？

從會話控制欄選擇「更多選項」，然後選擇「分享白板」>「新白板」。 白板會立即打開，所有參與者都能看到。

+++

+++我可以重新打開之前在會談中分享過的白板嗎？

是的。 選擇更多選項>分享白板，然後從可用白板列表中選擇該白板。 選定的白板會打開並對所有學習者開放。

+++

+++我可以允許參與者在白板上協作嗎？

是的。 打開白板選單並啟用「允許參與者繪畫」。 學習者接著可以在白板上畫畫、添加形狀、插入文字，並使用可用的註解工具。

+++

+++我可以儲存或匯出白板以備日後參考嗎？

是的。 打開白板選單，選擇匯出快照。 目前的白板內容會匯出成 PNG 圖片並下載到你的裝置。

+++

+++我可以在一次會議中管理多個白板嗎？

是的。 使用白板面板查看並管理會議期間建立的所有白板。 你可以從面板分享白板、刪除單一白板，或刪除所有白板。

+++

### 與Miro的合作

+++我可以用 Miro 做什麼？

Miro 提供一個協作工作空間，供腦力激盪、構思、規劃及其他互動活動，在 Live Hub 會議中進行。 參與者可以即時在共用的板子上共同作業。

+++

+++我要如何將 Miro 連接到 Live Hub 工作階段？

在會議室，選擇更多應用程式，然後選擇 Miro >登入 Miro。 會開啟登入視窗，讓你連結你的 Miro 帳號。

+++

+++使用 Miro 需要 Miro 帳號嗎？

是的。 您必須先用 Miro 帳號登入，才能將 Miro 連接到 Live Hub 會話並存取 Miro 看板。

+++

+++我要如何登入 Miro？

選擇「登入 Miro」後，選擇你想使用的帳號並完成登入流程。 連線後，你可以直接從會話中存取 Miro。

+++

### 分組討論室

+++分組討論室是用來做什麼的？

分組討論室讓你能將參與者分成較小的小組，進行討論、協作活動、解決問題練習及團隊學習。

+++

+++我該如何設計分組討論室？

打開分組討論面板，輸入分組會議的名稱，指定房間數量與時長，分配參與者，新增指示，然後選擇儲存。

+++

+++我該如何將參與者分配到分組討論室？

你可以選擇自動分配參與者，或是手動拖曳參與者到特定房間。

+++

+++每個分組討論室可以有不同的指示嗎？

是的。 選擇「單獨設定」房間，以提供每個分組房間的獨特指示。

+++

+++我該如何在課程中開始分組討論？

打開你設定的分組會議，選擇開始分組會議。 參與者會被帶到指定房間，開始合作。

+++

+++我可以加入分組討論室來協助參與者嗎？

是的，你可以從分組房間的控制選項中選擇加入。

+++

+++我該如何在不加入分組討論室的情況下監控討論？

在活躍的分組討論期間，選擇「檢查房間」以查看分組討論室中由 AI 生成的討論摘要。 摘要會隨著對話進行自動更新，幫助你監控學習者討論、評估與活動的契合度，並決定是否加入某個房間。

+++

+++分組討論結束後，我可以存取分組摘要嗎？

是的。 分組討論結束後，選擇「檢視報告」以檢視各房間摘要、參與者細節、活動指示及場次資訊。 分組分析也可在會談儀表板中提供，您可以在會談結束後檢視摘要並分析會堂結果。

+++

+++我該如何結束分組討論室？

若你設定分組活動的持續時間，分組時間結束後分組房間會自動結束，所有參與者返回主會議室。 你也可以隨時選擇結束分組結束活動。 參與者會收到五秒倒數計時，然後返回主會議室。

+++

+++我應該什麼時候使用分組討論室？

當參與者需要分組合作、參與討論、完成團隊活動或做練習，然後再與大眾分享成果時，可以使用分組討論室。

+++

+++分組討論可以延長到預定時間之外嗎？

是的。 教練可透過從分組控制中選擇延長時間2分鐘，延長活躍分組時間。 每個分組活動最多可延長兩次。 更新後的時長會立即生效，讓參與者能繼續討論與活動，不受干擾。

+++

### 問答與 AI 輔助回覆

+++我該如何提升 AI 生成答案的準確性？

在課程開始前，上傳相關的參考資料，幫助 AI 產生更準確且具情境感的回應。 在聊天面板中，選擇「上傳 AI 參考資料」，然後上傳你想讓 AI 用作參考內容的檔案。

+++

+++我在哪裡可以查看參與者的問題？

參與者在「Everyone」分頁發問的問題會自動收集到聊天面板的「問題」分頁，教師可在此檢視並回應。

+++

+++我該如何產生 AI 輔助回覆？

在聊天面板開啟「問題」分頁，將滑鼠移到問題上，選擇 AI 輔助回覆。 查看產生的回應，做必要的修改，然後選擇傳送。

+++

+++我可以在發送 AI 生成的回覆前編輯嗎？

是的。 AI 生成的回應是可編輯的。 你可以在發送前審查並修改內容，確保答案準確且適合你的參與者。

+++

+++為什麼我要上傳 AI 參考資料？

參考資料提供額外的背景，幫助 AI 生成更貼近會議內容的回答，減少手動回答常見問題的需求。

+++

+++AI 會自動回應學習者的問題嗎？

不。 AI 會產生建議回應供講師審閱。 講師決定是否編輯並將回應寄送給參與者。

+++

+++AI 輔助回覆是否適用於私人聊天或分組討論室中提出的問題？

不。 AI 輔助回覆僅適用於主會議室 Everyone 聊天室中發布的問題與訊息。 私人聊天或分組討論聊天中提出的問題不包含在 AI 驅動的答案生成中。

+++

+++哪些聊天訊息用於 AI 驅動的問題分類與回答生成？

AI 驅動的問題分類與答案生成，則是利用主會議室的 Everyone 聊天室中發布的訊息。 私人聊天和分組聊天室的訊息不會被這些 AI 功能處理。

+++

### 聊天與訊息

+++有哪些聊天分頁可以開放？

聊天面板包含以下分頁：

* 大家：與所有場次參與者分享訊息。
* 私人：與個別參與者一對一交換訊息。
* 問題：檢視並管理課程中提交的學習者問題。

+++

+++我可以在課程中與學習者進行私人對話嗎？

是的。 打開聊天面板的私人標籤，選擇一位參與者，輸入你的訊息，然後選擇發送。 私人對話僅限參與聊天的參與者觀看。

+++

### 錄音

+++我要怎麼錄製一場錄音？

在會話中，從控制列選擇更多選項，然後選擇錄製。 螢幕上會出現確認訊息，表示錄影已開始。

+++

+++錄音時會被逐字記錄嗎？

是的。 錄音開始時，Live Hub 會自動開始轉錄該會話內容。 確認訊息顯示錄音與轉錄工作已開始。

+++

+++為什麼我要錄音？

錄製課程讓參與者和講師在課程結束後能重新檢視內容。 錄影有助於複習討論、強化關鍵概念，並支持無法參加現場課程的參與者。

+++

### 內容分享

+++我該如何分享我的螢幕？

從控制列選擇「分享畫面」，選擇分享瀏覽器分頁、應用程式視窗或整個螢幕，然後選擇「分享」。 所選內容會對所有參與者開放。

+++

+++我在會談中可以分享什麼？

你可以根據想要呈現的內容，分享瀏覽器分頁、特定應用程式視窗，或整個螢幕。

+++

+++我可以註解共享內容嗎？

是的。 在分享螢幕時，使用 Annotate 來標示資訊、吸引注意重點，並與參與者即時協作。

+++

+++我可以保存螢幕上顯示的內容嗎？

是的。 從選項選單選擇匯出快照以擷取並儲存目前的共享視圖。

+++

+++我可以允許參與者分享他們的螢幕嗎？

是的。 若講師啟用分享螢幕權限，參與者可分享螢幕。 在演講時，參與者還能使用註解工具並匯出快照。

+++

+++我應該什麼時候使用螢幕分享？

使用螢幕共享來呈現投影片、示範應用程式、瀏覽網站、檢視文件，或在直播課程中引導參與者完成任務與工作流程。

+++

### 管理與會者

+++我可以從參加者小組中做些什麼？

與會者小組協助你監控參與並管理會議期間的參與者。 您可以查看與會者狀態與反應、管理舉手人數，並與參與者溝通。

+++

+++我該怎麼知道誰在場或缺席？

與會者小組會顯示已報名的參與者，並標示他們是否出席或缺席。 同時也會顯示學習者的反應和舉手狀態。

+++

+++我可以一次靜音所有學習者的麥克風嗎？

是的。 在參加者座談中，你可以靜音所有參與者的麥克風，以減少背景噪音並在會議期間保持專注。

+++

+++我可以一次放下所有舉起的雙手嗎？

是的。 與會者座談會包含同時放下所有舉起雙手的選項，這在問答環節後或討論結束後非常有用。

+++

+++我可以私訊參加者小組的學習者嗎？

是的。 如果講師啟用私人訊息，你可以利用參加者面板與個別學習者展開私人對話，而不會打擾其他參與者的課程進行。

+++

+++為什麼我應該在場次中使用參加者面板？

與會者面板提供學習者參與的集中視角，方便管理互動、回應參與訊號，並維持課程順暢進行。

+++

### 監控會話互動

+++我要怎麼看我的參與者有多投入？

使用課程教室頂端的參與者參與度指標，監控整體學習者參與度。

+++

+++參與者參與度指標代表什麼意思？

參與指標幫助講師了解整體學習者在課程中的參與度。 參與度是根據學習者的活動來計算，例如發言、參與聊天以及與課程互動。 個別參與分數會定期更新並彙整，以提供整體會話參與度。

交戰指示顯示以下其中一個等級：

* 高（綠色）：表示學習者參與度高。
* 中等（黃色）：表示學習者參與度中等。
* 低（紅色）：表示學習者參與度低。

每位學習者都會計算參與分數，並定期更新。 整個場次的參與度代表所有參與者在場次中的平均參與度。 教練不在計算範圍內。 學習者分數的映射方式如下：

* 0–30：低交戰
* 31–60：中度交戰
* 61–100：高參與度

此指標能快速反映整體參與情況，並協助教師調整活動以提升學習者的參與度。

+++

+++我在哪裡可以找到參與者參與度指標？

參與者參與度指示顯示在課程教室頂部，讓講師能在不中斷課程的情況下監控參與度。

+++

+++為什麼我應該監控參與者的參與度？

監控參與度有助於你了解參與者在場次中的積極參與程度。 參與洞察能幫助你決定何時引入投票、測驗和討論等活動，鼓勵參與者參與並保持參與。

+++

### 結束一場遊戲

+++我該怎麼為大家結束這場遊戲？

選擇離開，然後在確認對話框中選擇結束所有會議。 此舉結束所有參與者的會議。

+++

+++結束遊戲後會發生什麼事？

所有參與者都會被移除，並被導向到結束畫面。 接著，他們可以回到課程頁面。

+++

+++我應該什麼時候使用「結束會議」給所有人？

當訓練結束並希望同時關閉所有參與者的房間時，請使用「結束所有會議」。

+++

### 會話錄製與分析

+++我在哪裡可以找到療程結束後的錄影和分析？

課程結束後，你可以從會議總覽頁面存取會議錄影、逐字稿和分析資料。

+++

+++我要怎麼查看會話錄影？

前往過去的會話，選擇你想回顧的會話，然後在會話錄影區選「檢視」。 要修改錄影，請選擇編輯。

+++

+++我該如何開啟會話分析？

前往過去的會話，選擇所需的會話，然後選擇會話分析網址以開啟分析儀表板。

+++

+++會話分析包含哪些資訊？

會話分析提供關於會話活動與學習者參與度的洞察，包括：

* 會議摘要：查看會議詳情及錄影資訊。
* 互動：檢視投票、測驗、分組討論室、問答及反應活動。
* 參與者活動：在整個課程中監控學習者的參與與投入。
* 報告：下載會話報告與互動數據以供進一步分析。

+++

+++我可以在會談結束後查看會議記錄嗎？

是的。 錄音旁附有會議逐字稿，方便回顧討論及重溫特定主題。

+++

+++為什麼我要審查會話分析？

會話分析能幫助你了解參與者如何與內容互動，識別參與趨勢，衡量參與度，並評估訓練課程的成效。

## 學習者

### 課程註冊

+++我可以報名課程嗎？

是的。 如果課程設定為自助選課，你可以直接從目錄頁面選課。 註冊後，課程可透過「我的學習」開啟。

+++

+++我怎麼知道我已經註冊了？

註冊後，課程會加入你的 Adobe Learning Manager 學習計畫。 你也會收到應用程式內的通知。 根據你組織的通知設定，你也會收到電子郵件邀請。

+++

+++報名後可以在哪裡找到課程？

你可以在 Adobe Learning Manager 的 My Learnings 存取已註冊的課程。

+++

### 加入會議

+++我該如何以學習者的身份加入 Live Hub 課程？

登入 Adobe Learning Manager，然後進入「我的學習」。 打開已選修的課程，選擇開始>進入課程，然後選擇加入。

+++

### 隱藏字幕

+++我要怎麼開啟隱藏字幕？

從控制列選擇 CC 開啟隱藏字幕。 再次選擇 CC 來關閉它們。

+++

+++為什麼我應該使用隱藏式字幕？

隱藏字幕透過在課程中以文字形式顯示語音內容，提升無障礙性。 他們能幫助你更輕鬆地跟上討論，並支持你參與各種學習與聆聽的環境。

+++

### 參與課程

+++我該如何嘗試測驗或投票？

當講師在課程中發布測驗或投票時，該測驗會自動顯示在學習者的螢幕上。 請依照螢幕提示根據所提供問題類型提交你的回答。

+++

+++我可以查看民調結果嗎？

是的，如果講師在發起投票時啟用「向所有學習者顯示結果」，你可以在課程中看到與參與者分享的結果。

+++

+++我可以查看測驗結果嗎？

是的，如果講師在啟動測驗時啟用「向所有學習者顯示結果」，你可以在課程中查看與參與者分享的結果。

+++

+++為什麼我應該在遊戲過程中使用聊天？

聊天提供了方便的方式，讓你參與討論、提問並分享回饋，且不會打斷講者。 當麥克風使用有限或你想在簡報進行中發言時，它特別有用。

+++

+++我該如何在治療過程中提問？

請使用聊天面板中的「Everyone」分頁提問、分享評論及參與討論。 輸入您的訊息並選擇發送。 此分頁中發布的訊息對所有會議參與者皆可見。

+++

+++我可以在會談中進行私下對話嗎？

是的。 打開聊天面板的私人標籤，選擇一位參與者，輸入你的訊息，然後選擇發送。 私人對話僅限參與聊天的參與者觀看。

+++

+++我該如何在課程中向講師提問？

你可以用以下任一種方式提問：

* 請在「Everyone」標籤中發表你的問題，讓所有參與者都能看到。
* 如果你希望問題只對老師顯示，可以私訊給講師。

+++

+++我應該什麼時候使用私人聊天？

使用私人聊天處理個別的後續問題、澄清或與全體觀眾無關的對話。

+++

+++我可以分享我的螢幕嗎？

是的。 如果講師啟用分享螢幕權限，你可以分享你的螢幕。 在呈現時，你也可以使用註解工具並匯出快照。

+++

### 分組討論室

+++我可以查看分組討論的摘要嗎？

是的。 分組討論結束後，你可以查看你所在房間的 AI 報告。 報告包含偵測到的活動類型及小組討論重點的書面摘要。 在畫面右下角選擇分組（格子）圖示，選擇分組會議，然後選擇摘要。

+++

+++我可以查看其他分組討論室或我之前待過的房間的報告嗎？

不。 你只能查看你最近所在房間的報告。 如果講師在同一分組討論中將你移到另一個房間，只會顯示你最近一次房間的摘要，其他參與者房間的報告則不會對你顯示。

+++

### 會議結束後

+++我可以在會談結束後存取錄音嗎？

是的。 課程結束後，你可以從課程中存取錄影，前提是該課程已設定的權限和錄影設定。 你可以直接進入主題，觀看對應的錄影片段，並查看聚焦該主題的 AI 生成摘要，讓你更輕鬆地回顧特定討論和重點，而不必觀看完整錄影。

+++

+++錄製遊戲後還有哪些額外內容？

除了錄影外，Live Hub 還提供會議的逐字稿，方便回顧討論內容並找到特定資訊。 AI 生成的主題將錄音組織成關鍵討論區，並包含針對特定主題的摘要。 一個主題可以跨越錄音的多個非連續片段，讓你在不需手動搜尋整個錄音時段的情況下，就能查看該主題的所有相關時刻。

+++

+++課程結束後我可以提供回饋嗎？

是的。 在課程結束畫面，你可以分享對音訊和影片體驗的回饋。
