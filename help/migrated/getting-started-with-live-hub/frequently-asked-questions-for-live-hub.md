Live Hub 包含管理員、作者、講師與學習者等角色，各自負責訓練工作流程的不同部分。 本文件依角色分類整理 Live Hub 常見問題，讓每位受眾能快速找到與自己最相關的問題。

## 管理員

+++我該如何為我的 Adobe Learning Manager 帳戶啟用 Live Hub？

以管理員身份登入，並在 Learning > Live Hub 中導航至 AI。 為此帳戶啟用 Live Hub，以讓 Live Hub 可用於虛擬教室訓練。 啟用後，作者可在 Adobe Learning Manager 中建立 Live Hub 課程。

+++

+++我可以將 Live Hub 設為預設的虛擬教室提供者嗎？

是的。 啟用 Live Hub 後，將 Live Hub 設為預設的 Live Training 工具。 當您建立虛擬教室模組時，Live Hub 會預先被選取，但如有需要，您仍可選擇其他提供者。

+++

+++管理員可以在 Live Hub 工作階段啟用哪些 AI 助理？

管理員可以在 Live Hub 中啟用 AI，並選擇哪些 AI 助理可供作者與講師使用。 可選助理包括：

* 投票助理：利用 AI 生成投票。
* 問答助理：協助篩選學習者問題並草擬回答。
* 分組討論監控助理：監控分組討論。
* 錄製主題產生器：從錄製中建立結構化主題與筆記。
* 講師尋找助理：推薦適合使用 AI 課程的講師。

+++

## 作者

+++我的帳戶可以使用 Live Hub 嗎？

Live Hub 將於 2026 年 8 月起提供。 管理員可以為您的 Adobe Learning Manager 帳戶啟用或停用 Live Hub。 如果啟用了 Live Hub，作者在建立虛擬教室模組時可以選擇它作為即時訓練提供者。 如果 Live Hub 選項不可用，請聯絡您的管理員以啟用此功能。


+++

+++我該如何建立 Live Hub 課程？

登入 Adobe Learning Manager，然後選擇「建立課程」。 在課程目錄頁面，選擇新增，輸入課程名稱與描述，然後將模組新增至課程目錄。 將模組設定為虛擬教室，並選擇 Live Hub 作為教學工具。 您的 Adobe Learning Manager 帳戶必須啟用 Live Hub，之後它才會顯示為可用的線上訓練提供者。 如果您在可用選項清單中找不到 Live Hub，請聯絡您的管理員。

+++

+++我該如何將課程設定為 Live Hub 工作階段？

作者可以創建課程並新增虛擬教室模組。 在模組設定中，選擇 Live Hub 作為即時訓練提供者，然後輸入所需的課程細節，例如標題、描述、時間表及時區。 儲存模組以在 Live Hub 中排程工作階段。

>[!NOTE]
>
>Live Hub 必須由管理員為您的 Adobe Learning Manager 帳戶啟用，之後它才會顯示為可用的線上訓練提供者。

+++

+++我可以在建立課程時新增講師嗎？

是的。 選擇 Live Hub 後，將一位或多位講師加入課程，然後選擇「新增>儲存」。

+++

+++我該如何發佈 Live Hub 課程？

完成課程設定後，選擇「儲存>發佈」。 課程一旦發布，即可開放學習者報名及排課。

+++

## 講師

### 加入工作階段

+++我該如何以講師身份參加 Live Hub 課程？

登入 Adobe Learning Manager，並在「即將進行的課程」中找到該課程。 選擇會話網址以開啟加入前畫面，然後選擇加入以進入會話。

+++

+++我可以在參與者抵達前加入課程嗎？

是的。 講師可以在課堂預定開始時間前加入，準備教室、上傳 AI 答案參考的內容、設定設定，並在參與者加入前確認一切準備就緒。

+++

+++在會話開始前我可以設定什麼？

在課程開始前，講師可以透過設定學習者權限、建立投票與測驗、設置分組討論室、連接 Miro 進行協作，以及上傳參考資料，以支援課程中的 AI 問答。

+++

### 學習者權限與隱藏字幕

+++我該如何允許參與者分享螢幕並使用白板？

在工作階段房間中，從控制列選擇「設定」，然後選擇「參與者權限」。 啟用「共用畫面」和「使用白板」，然後選擇「完成」以套用變更。

+++

+++我應該在什麼時候設定參與者權限？

在課程開始前設定學習者權限，作為準備教室的一部分。 這確保參與者在加入時具備適當的協作與參與能力。

+++

+++我該如何開啟隱藏字幕？

從控制列選擇「更多選項」，選擇「字幕」，然後啟用「顯示字幕」。

+++

+++為什麼我應該使用隱藏字幕？

隱藏字幕透過在會話中以文字形式顯示語音內容，提升無障礙性。 它們能幫助參與者更輕鬆跟上討論內容，並在各種學習與聆聽環境中提供支援。

+++

### 民調

+++生成一個由 AI 驅動的破冰調查需要哪些資訊？

若要產生由 AI 驅動的破冰投票，請提供模組名稱與模組說明。 Live Hub 利用這些資訊製作入門問題，幫助學習者在課程開始時投入其中。

+++

+++產生 AI 驅動的知識檢查投票需要什麼？

AI 驅動的知識檢查投票是從會議記錄中產生的。 在產生知識檢查投票前，請確保有轉錄資料，且已擷取足夠的會話內容。 生成的問題是根據本次課程中討論的主題而定。

+++

+++我該如何建立投票？

開啟「投票與測驗」面板，並選擇「投票」標籤。 手動建立投票或使用 AI 生成投票，然後選擇儲存。 投票會加入會話中，並在需要時啟動。

+++

+++我可以用 AI 來產生投票嗎？

是的。 Live Hub 能生成 AI 驅動的投票，幫助提升學習者在課程中的參與度。

* 選擇 Icebreaker 以產生由 AI 驅動的入門投票。
* 選擇「知識」檢查以產生投票，以評估參與者對討論主題的理解程度。

+++

+++我可以自己設計投票問題嗎？

是的。 選擇「自行建立」以建立自訂投票，並提供您自己的問題與回答選項。

+++

+++如何在會話中發起投票？

在「投票與測驗」面板中，選取「投票」標籤，然後建立新的投票或選取先前儲存的投票。 選擇「啟動」以讓參與者可以查看投票。 參與者可以即時提交回應，結果會隨著收到回應自動收集。

+++

+++我可以讓參與者看到投票結果嗎？

是的。 啟動投票時，啟用「向所有學習者顯示結果」功能，以便在課程中與參與者分享結果。

+++

+++我應該什麼時候使用投票？

利用投票鼓勵參與、收集回饋、啟動討論，或評估學習者在整個課程中的理解程度。 知識檢查調查對於在進入下一節前，測量對關鍵主題的理解度特別有用。

+++

### 測驗

+++我要怎麼製作測驗？

開啟「投票與測驗」面板，並選擇「測驗」標籤。 選擇「建立新測驗」，選擇題型，新增題目與答案選項，找出正確答案，然後選擇「完成」。

+++

+++支援哪些題型？

Live Hub 支援以下測驗題型：

* 多項選擇：參與者選擇一個正確答案。
* 多重答案：參與者選擇所有適用答案。

+++

+++我要如何在測驗中新增更多題目？

在建立測驗時，選擇「新增問題」以新增更多題目。 完成新增問題後，選擇「完成」。

+++

+++我該如何在課程中啟動測驗？

在「投票與測驗」面板中，選取「測驗」標籤，找到你想使用的測驗，然後選擇「啟動」。 參與者可以即時回應測驗。

+++

+++我可以讓參與者查看測驗結果嗎？

是的。 啟動測驗時，啟用「向所有學習者顯示結果」功能，以便在課程中與參與者分享結果。

+++

+++我應該什麼時候使用小測驗？

利用測驗評估學習者的理解程度、強化關鍵概念，並衡量課程中的知識記憶力。 測驗能幫助你找出可能需要額外解釋或討論的主題。

+++

### 白板

+++如何在 Live Hub 工作階段建立白板？

從工作階段控制列選擇「更多選項」，然後選擇「分享白板」>「新增白板」。 白板會立即打開，對所有參與會議的參與者可見。

+++

+++我可以重新開啟之前在會議中分享過的白板嗎？

是的。 選擇「更多選項」>「共用白板」，然後從可用白板清單中選擇白板。 所選白板會開啟，並對所有學習者可見。

+++

+++我可以允許參與者在白板上協作嗎？

是的。 開啟白板選單並啟用「允許參與者繪圖」。 學習者接著可以在白板上繪圖、添加形狀、插入文字，並使用可用的註解工具。

+++

+++我可以儲存或匯出白板以備日後參考嗎？

是的。 開啟白板選單並選擇匯出快照。 目前的白板內容會匯出為 PNG 影像並下載到您的裝置。

+++

+++我可以在一次會話中管理多個白板嗎？

是的。 使用白板面板檢視並管理本次工作階段建立的所有白板。 在面板中，您可以分享白板、刪除單一白板，或刪除所有白板。

+++

### 與 Miro 的合作

+++我可以用 Miro 做什麼？

Miro 提供一個協作式的工作空間，讓大家在 Live Hub 會議期間進行腦力激盪、構思、規劃及其他互動活動。 參與者可以即時在共用看板上共同作業。

+++

+++我該如何將 Miro 連接到 Live Hub 工作階段？

在會議室中，選擇「更多應用程式」，然後選擇 Miro >「登入 Miro」。 會開啟登入視窗，讓你連結 Miro 帳戶。

+++

+++我需要 Miro 帳號才能使用 Miro嗎？

是的。 您必須先使用 Miro 帳號登入，才能將 Miro 連接到 Live Hub 工作階段並存取 Miro 看板。

+++

+++我要如何登入 Miro？

選擇「登入 Miro」後，選擇您想使用的帳戶並完成登入流程。 連線後，您可以直接從工作階段存取 Miro。

+++

### 分組討論室

+++分組討論室是用來做什麼的？

分組討論室讓你可以將參與者分成較小的小組，進行討論、協作活動、問題解決練習以及團隊學習。

+++

+++我該如何建立分組討論室？

開啟分組討論面板，輸入分組討論場次的名稱，指定房間數量與時長，指派參與者，新增指示，然後選擇儲存。

+++

+++我該如何分配參與者到分組討論室？

您可以選擇「自動指派」以自動分配參與者，或手動將參與者拖曳至特定房間。

+++

+++每個分組討論室可以有不同的指示嗎？

是的。 選擇「為房間個別設定」，以為每個分組討論室提供獨特的指示。

+++

+++我該如何在遊戲過程中開始分組討論？

開啟您設定的分組會議，然後選擇「開始分組」。 參與者會被移到指定的房間，並開始合作。

+++

+++我可以加入分組討論室來協助參與者嗎？

是的，你可以從分組討論室的控制選項中選擇「加入」來加入該房間。

+++

+++我要如何在不加入討論室的情況下監控討論？

在進行中的分組討論中，選擇「檢查房間」以檢視分組討論室中由 AI 生成的討論摘要。 摘要會隨著對話進行自動更新，幫助你監控學習者討論、評估與活動的契合度，並決定是否加入某個房間。

+++

+++分組討論結束後，我還能存取分組摘要嗎？

是的。 分組討論結束後，選擇「檢視報告」以檢視各房間摘要、參與者詳細資訊、活動指示及場次資訊。 分組分析也可在會話儀表板中取得，您可以在會話結束後檢視摘要並分析會話結果。

+++

+++我該如何結束分組討論室？

如果您為分組活動設定時長，分組討論室會在分配時間結束時自動結束，所有參與者返回主會議室。 您也可以在任何時間選擇「結束分組」來結束活動。 參與者會獲得五秒的倒數計時，然後返回主會議室。

+++

+++我應該什麼時候使用分組討論室？

當參與者需要在小組中合作、參與討論、完成團隊活動或練習，然後再與大眾分享成果時，使用分組討論室。

+++

+++分組討論可以延長到原定時間之外嗎？

是的。 講師可從分組控制項中選擇「延長時間2分鐘」來延長進行中的分組討論時間。 每場分組活動最多可延長兩次。 更新後的持續時間會立即生效，讓參與者能在不中斷的情況下繼續討論與活動。

+++

### 問答與 AI 輔助回覆

+++我該如何提升 AI 生成答案的準確度？

在課程開始前，上傳相關參考資料，協助 AI 生成更準確且具情境感的回應。 在聊天面板中，選擇「上傳 AI 參考資料」，然後上傳您希望 AI 作為參考內容的檔案。

+++

+++我在哪裡可以查看參與者的問題？

參與者在「所有人」標籤中提出的問題會自動被收集到聊天面板的「問題」標籤中，講師可以在那裡檢視並回應。

+++

+++我該如何生成一份 AI 輔助回覆？

在聊天面板中開啟「問題」標籤，將滑鼠移到問題上，選擇「AI 輔助回覆」。 檢視產生的回應，進行必要的變更，然後選擇「傳送」。

+++

+++我可以在寄出 AI 生成的回覆前編輯它嗎？

是的。 AI 生成的回應是可編輯的。 您可以在寄出前檢視並修改內容，以確保答案準確且適合參與者。

+++

+++為什麼我要上傳 AI 參考資料？

參考資料提供額外的背景資訊，幫助 AI 生成更貼近課程內容的回答，減少手動回答常見問題的需求。

+++

+++AI 會自動回應學習者的提問嗎？

沒有。 AI 會生成建議的回應，供講師審閱。 講師會決定是否編輯並將回應內容發送給參與者。

+++

+++AI 輔助回覆是否適用於私人聊天或分組討論室中提出的問題？

沒有。 AI 輔助回覆僅適用於主會議室「Everyone」聊天室中發布的問題與訊息。 在私人聊天或分組聊天室聊天中提出的問題，不包含在 AI 驅動的答案生成中。

+++

+++哪些聊天訊息用於 AI 驅動的問題分類與答案生成？

AI 驅動的問題分類與答案生成，利用主會議室「Everyone」聊天室中發布的訊息。 來自私人聊天室和分組聊天室的訊息不會被這些 AI 功能處理。

+++

### 聊天與訊息

+++我有哪些聊天分頁可供使用？

聊天面板包含以下標籤：

* 所有人：與所有場次參與者分享訊息。
* 私人：與個別參與者一對一交換訊息。
* 問題：檢視並管理課程中提交的學習者問題。

+++

+++我可以在課程中與學習者進行私下對話嗎？

是的。 在聊天面板中開啟「私人」標籤，選取一位參與者，輸入您的訊息，然後選擇「傳送」。 私人對話僅對參與聊天的參與者可見。

+++

### 錄製會話

+++我要怎麼錄製一個會話？

在工作階段中，從控制列選擇「更多選項」，然後選擇「錄製」。 會出現確認訊息，表示錄製已開始。

+++

+++錄音時會被逐字記錄嗎？

是的。 錄製開始時，Live Hub 會自動開始轉錄該工作階段。 會出現確認訊息，表示錄音與轉錄已開始。

+++

+++為什麼我要錄製一個會議？

錄製課程讓參與者和講師在課程結束後能重新檢視內容。 錄影對於複習討論、強化關鍵概念，以及協助無法參加現場會議的參與者都很有幫助。

+++

### 分享內容

+++我該如何分享我的螢幕？

從控制列選擇「共用畫面」，選擇要分享瀏覽器索引標籤、應用程式視窗或整個螢幕，然後選擇「分享」。 所選內容將對所有參與者可見。

+++

+++在一次會談中我可以分享什麼？

您可以分享瀏覽器分頁、特定應用程式視窗，或整個螢幕，視您想呈現的內容而定。

+++

+++我可以為共用內容做註解嗎？

是的。 在分享螢幕時，使用 Annotate 來標示資訊、吸引注意重點區域，並與參與者即時協作。

+++

+++我可以儲存螢幕上顯示的內容嗎？

是的。 從選項選單中選擇匯出快照，以擷取並儲存目前的共用檢視。

+++

+++我可以允許參與者分享他們的螢幕嗎？

是的。 如果講師啟用「分享螢幕」權限，參與者即可分享螢幕。 在簡報時，參與者也可以使用註解工具並匯出快照。

+++

+++我應該什麼時候使用螢幕分享？

使用螢幕共享功能在直播中展示投影片、示範應用程式、瀏覽網站、檢視文件，或引導參與者完成任務與工作流程。

+++

### 管理與會者

+++我可以從與會者面板中做些什麼？

與會者面板協助您監控參與並管理會議期間的參與者。 您可以查看與會者的狀態與反應、管理舉手，並與參與者溝通。

+++

+++我要怎麼知道誰在場或缺席？

與會者面板會顯示已報名的參與者，並指示他們是否出席或缺席。 它也會顯示學習者的反應以及舉手狀態。

+++

+++我可以一次靜音所有學習者麥克風嗎？

是的。 在「與會者」面板中，您可以為所有參與者靜音麥克風，以減少背景噪音並在會議期間保持專注。

+++

+++我可以一次放下所有舉起的手嗎？

是的。 與會者面板包含同時放下所有舉起雙手的選項，這在問答環節後或討論結束時非常有用。

+++

+++我可以從與會者面板向學習者發送私訊嗎？

是的。 如果講師啟用私人訊息，您可以使用「與會者」面板與個別學習者展開私人對話，而不會打擾其他參與者的課程進行。

+++

+++為什麼我應該在場次中使用「與會者」面板？

與會者面板提供學習者參與的集中檢視，讓管理互動、回應互動訊號並維持課程順暢進行變得更簡單。

+++

### 監控會話參與度

+++我要怎麼看出我的參與者有多投入？

使用課程房間頂端的參與者參與度指標，監控整個課程中學習者的整體參與情況。

+++

+++參與者參與度指標代表什麼意思？

參與度指標幫助講師了解整體學習者在課程中的參與度。 參與度是根據學習者活動來計算，例如發言、參與聊天以及與課程互動。 個別參與分數會定期更新並彙總，以提供整體會話參與度。

參與指標會顯示下列其中一個等級：

* 高（綠色）：表示學習者參與度高。
* 中等（黃色）：表示學習者參與度中等。
* 低（紅色）：表示學習者參與度較低。

每位學習者都會計算參與度分數，並定期更新。 整個場次的參與程度代表所有參與者在該場次中的平均參與度。 講師不在計算範圍之外。 學習者分數的映射方式如下：

* 0–30：低互動
* 31–60：中度參與
* 61–100：高度參與度

此指標能快速呈現整體參與狀況，並協助教師調整活動以提升學習者的參與度。

+++

+++我在哪裡可以找到參與者參與度指標？

參與者參與度指示器會出現在課程教室頂端，讓講師能在不中斷課程的情況下監控參與度。

+++

+++為什麼我要監控參與者的參與度？

監控參與度有助於你了解參與者在會話中有多積極參與。 參與度洞察能幫助你決定何時引入投票、測驗和討論等活動，以鼓勵參與者參與並保持參與。

+++

### 結束工作階段

+++我該怎麼為大家結束這場遊戲？

選擇「離開」，然後在確認對話框中選擇「全部結束工作階段」。 這代表所有參與者的本場次結束。

+++

+++結束遊戲後會發生什麼事？

所有參與者都會從本次工作階段移除，並被重新導向至工作階段結束畫面。 接著，他們可以回到課程頁面。

+++

+++我應該在什麼時候使用 End Session for All？

當訓練課程結束且您想同時關閉所有參與者的房間時，請使用「結束課程」給所有人。

+++

### 會話錄製與分析

+++我在哪裡可以找到一次療程結束後的錄影和分析資料？

課程結束後，您可以從課程總覽頁面存取課程錄製、逐字稿及分析資料。

+++

+++我要如何查看會話錄製？

前往「過去的會話」，選擇您想要檢視的會話，然後在「會話錄製」區段中選擇「檢視」。 若要修改錄音，請選擇「編輯」。

+++

+++我要如何開啟會話分析？

前往「過去的工作階段」，選擇所需的工作階段，然後選擇「工作階段分析」網址以開啟分析儀表板。

+++

+++會話分析包含哪些資訊？

課程分析提供對課程活動與學習者參與度的洞察，包括：

* 課程摘要：檢視課程詳細資訊及錄製資訊。
* 互動：檢視投票、測驗、分組討論、問答及反應活動。
* 參與者活動：在整個課程中監控學習者的參與與投入。
* 報告：下載會話報告與互動資料以進行進一步分析。

+++

+++我可以在課程結束後查看會議記錄嗎？

是的。 會議逐字稿與錄音一同提供，方便回顧討論內容並重溫特定主題。

+++

+++為什麼我應該檢視會話分析？

課程分析幫助您了解參與者如何與內容互動、識別參與趨勢、衡量參與度，並評估訓練課程的成效。

## 學習者

### 課程報名

+++我可以報名修課嗎？

是的。 如果課程設定為自助報名，您可以直接從目錄頁面報名。 報名後，課程將可在「我的學習」中開放。

+++

+++我怎麼知道自己已經註冊了？

註冊後，課程會加入您在 Adobe Learning Manager 中的學習計畫中。 你也會收到應用程式內的通知。 根據您組織的通知設定，您也會收到電子郵件邀請。

+++

+++報名後我在哪裡可以找到課程？

您可以在 Adobe Learning Manager 的「我的學習」中存取已報名的課程。

+++

### 加入工作階段

+++我該如何以學習者身分加入 Live Hub 課程？

登入 Adobe Learning Manager，然後前往「我的學習」。 開啟已報名的課程，選擇「開始」>「前往課程」，然後選擇「加入」。

+++

### 隱藏字幕

+++我該如何開啟隱藏字幕？

從控制列選擇 CC 以開啟隱藏字幕。 再次選擇 CC 以關閉它們。

+++

+++為什麼我應該使用隱藏字幕？

隱藏字幕透過在會話中以文字形式顯示語音內容，提升無障礙性。 他們能幫助你更輕鬆地跟上討論內容，並支持你參與各種學習與聆聽的環境。

+++

### 在會議中參與

+++我該如何嘗試測驗或投票？

當講師在課程中發布測驗或投票時，該測驗會自動顯示在學習者的螢幕上。 依照螢幕上的提示，根據所提供問題類型提交你的回答。

+++

+++我可以查看民調結果嗎？

是的，如果講師在啟動投票時啟用「向所有學習者顯示結果」，你就能在課程中看到與參與者分享的結果。

+++

+++我可以查看測驗結果嗎？

是的，如果講師在啟動測驗時啟用「向所有學習者顯示結果」，您可以查看課程中與參與者分享的結果。

+++

+++為什麼我應該在會話中使用聊天？

聊天提供了一種方便的方式，讓你能參與討論、提問並分享回饋，而不打斷講者。 當麥克風存取受限，或你想在簡報進行中貢獻時，它特別有用。

+++

+++在治療過程中，我該如何提問？

使用聊天面板中的「所有人」標籤來提問、分享留言並參與討論。 輸入您的訊息並選擇「傳送」。 此標籤中張貼的訊息對所有工作階段參與者可見。

+++

+++我可以在治療過程中進行私人對話嗎？

是的。 在聊天面板中開啟「私人」標籤，選取一位參與者，輸入您的訊息，然後選擇「傳送」。 私人對話僅對參與聊天的參與者可見。

+++

+++我該如何在課程中向講師提問？

您可以用以下任一方式提問：

* 請在「所有人」標籤中發佈您的問題，讓所有參與者都能看到。
* 如果你希望問題只對老師看見，請私訊給講師。

+++

+++我應該什麼時候使用私人聊天？

使用私人聊天處理個別後續問題、澄清或與全體觀眾無關的對話。

+++

+++我可以分享我的螢幕嗎？

是的。 如果講師啟用「分享螢幕」權限，您可以分享您的螢幕。 在呈現時，您也可以使用註解工具並匯出快照。

+++

### 分組討論室

+++我可以查看我的分組討論摘要嗎？

是的。 分組討論結束後，你可以查看由 AI 生成的報告，針對你所在的房間。 報告包含偵測到的活動類型，以及您團隊討論的關鍵重點的書面摘要。 選取畫面右下角的分組（網格）圖示，選擇分組工作階段，然後選擇摘要。

+++

+++我可以查看其他分組討論室或我之前參加過的房間的報告嗎？

沒有。 您只能查看最近所在房間的報告。 如果講師在同一場分組討論中將你移到不同房間，系統只會顯示你最近一次房間的摘要，其他參與者房間的報告則永遠不會對你顯示。

+++

### 療程結束後

+++我可以在療程結束後存取錄影嗎？

是的。 課程結束後，您可以從課程中存取錄影，但須依照課程所設定的權限與錄製設定。 你可以直接瀏覽到某個主題，檢視錄影中對應的片段，並檢視以該主題為重點的 AI 生成摘要，讓你在不必看完整段錄影的情況下，更容易重溫特定討論與重點。

+++

+++錄製後還有哪些額外內容可供使用？

除了錄影之外，Live Hub 還提供會議的逐字稿，方便檢視討論內容並尋找特定資訊。 AI 生成的主題將錄音整理成關鍵討論區，並包含針對特定主題的摘要。 一個主題可以跨越錄音中多個非連續的片段，讓您在不需手動搜尋整個錄音階段的情況下，就能查看該主題的所有相關時刻。

+++

+++課程結束後我可以提供回饋嗎？

是的。 在工作階段結束畫面，您可以分享對音訊與視訊體驗的回饋。
