# 關於與會者座談會

現場中心的與會者面板讓講師能查看學習者並管理課程中的互動。 它提供所有與會者的集中視圖，並協助講師即時監控參與與參與度。

面板會顯示與會者姓名、角色及互動狀態，方便辨識誰已出席或尚未加入。 講師可利用面板管理參與者權限、監控參與度，並控制學習者互動，如麥克風使用、反應及舉手。

## 主要優點

* **提升會議能見度**：將所有參加者集中顯示，方便查看已加入者。

* **輕鬆**&#x200B;管理參與：提供快速存取與會者控制功能，協助講師管理課程中學習者互動。

* **支援學習者互動**：透過反應、舉手及私人訊息等功能促進互動。

* **記錄出席情況**：顯示目前在場的學習者及已註冊但尚未加入課程的學習者。

## 角色與權限

參加者座談會在現場中心課程中，對講師與學習者皆開放。 可用的動作會依使用者角色而異。
