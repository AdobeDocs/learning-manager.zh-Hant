# 作為學習者使用白板

白板在 Live Hub 會話中提供共享的視覺工作空間。 當講師啟用白板存取時，你可以在共享畫布上繪圖、添加形狀和文字，並擦除內容。 利用白板說明想法、解決問題，並參與即時協作活動。

本文說明如何以學習者身份使用 Live Hub 的白板。

## 用白板

當 Instructor 允許學習者編輯白板時，你可以在線上課程中與白板互動。 在這場遊戲中，你可以：

* 用記號筆工具在白板上畫畫。

* 加入形狀和文字以創造或貢獻內容。

* 從白板上抹去畫作、形狀或物件。
