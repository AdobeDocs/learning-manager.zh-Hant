# 查看會話儀表板

Live Hub 的會話儀表板提供學習者參與度、參與度及會話表現的洞察。 它幫助講師回顧學習者在課程中的互動並評估其成效。

儀表板整合了出席率、參與度及互動等關鍵指標，有助於未來會議的分析與決策。

## 主要優點

* **集中可視**&#x200B;性：從單一儀表板監控學習者的參與、出席及互動。

* **參與洞察**：了解學習者在課程中的互動方式，並識別參與模式。

* **績效分析**：利用參與與互動資料評估會談成效。

* **數據驅動改進**：利用儀表板的洞察提升未來課程與學習成果。

## 存取會話儀表板

請依照以下步驟查看 Live Hub 會話的會話儀表板：

1. 以講師身份登入 Adobe Learning Manager。

1. 從&#x200B;**您的課程中**&#x200B;選擇&#x200B;**過去的課程。**&#x200B;這會開啟 **「你過去的會談」** 頁面。

   ![過往場次導航](assets/past-sessions-navigation.png)
   *從「你的課程」中選擇「過去課程」以開啟「你的過去課程」頁面。*

1. 打開你想查看會話分析的課程。 <br> **會話總覽**&#x200B;頁面會出現。

1. 請前往 **Live hub** 區塊，選擇 **「檢視分析」頁面**。 <br> **分析**&#x200B;儀表板會開啟，顯示所選會話的詳細洞察。

   ![會話分析網址選項](assets/session-overview-page.png)
   *在 Live hub 區塊選擇「檢視分析」頁面以開啟分析儀表板。*

## 有哪些洞見可用

會話儀表板在多個分頁中呈現會堂資料，每個分頁聚焦於學習者參與與表現的特定面向。 這些觀點共同幫助講師分析出席率、參與度及互動模式。

![會話儀表板洞察概覽](assets/session-dashboard-insights-overview.png)
*會話儀表板呈現會話摘要、互動、參與者活動及報告分頁的資料。*

以下分頁可在會話儀表板中提供：

| **分頁** | **描述** |
|----|----|
| **會議摘要** | 提供現場與錄影表現的高階概覽，包括課程時長、註冊及加入學習人數、平均出席時長、隨時間的出席、參與者參與度，以及如總觀看次數與平均觀看時長等錄影洞察。 |
| **互動** | 依互動方式顯示參與者參與度，組織為投票、測驗、分組討論及其他互動，方便分析學習者如何參與互動活動。 |
| **參與者活動** | 提供參與者的詳細資訊，包括出席與互動數據，以協助追蹤個人參與度。 |
| **報告** | 允許你下載會話分析和離線資料。 |

欲了解更多資訊，請參閱 [會話儀表板](./components-of-the-session-dashboard.md) 的組件。
