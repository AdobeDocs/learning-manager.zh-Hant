# 了解隱藏字幕

隱藏字幕會在 Live Hub 課程中自動生成，並隨著與會者發言持續更新。 字幕會顯示在專用的顯示區域，並以講師在教室設定&#x200B;**中**&#x200B;選擇的語言顯示。

講師與參與者皆可查看說明文字。 每位與會者可以獨立顯示或隱藏字幕，而不會影響其他參與者的字幕設定。

只有講師可以更改字幕語言。 參與者只能以講師選擇的語言觀看字幕。 參與者無法更改字幕的語言。

## Live Hub 如何決定字幕語言

Live Hub 會根據以下優先順序自動選擇字幕語言：

1. **課程語言：** 如果支援課程語言作為字幕，Live Hub 會使用該課程語言。 對於多語言課程，如果目前課程實例使用的語言不支援隱藏字幕，Live Hub 會選擇第一個支援隱藏字幕的課程實例的語言。 請參閱 [ALM](../../migrated/languages-supported.md) 中支援的語言以取得更多資訊。
1. **帳戶語言：** 若課程語言不支援，Live Hub 會檢查帳戶語言，並在支援時使用。

>[!NOTE]
>
>如果課程語言或帳戶語言都不被支援，Live Hub 會選擇英文作為字幕語言。 此外，字幕預設為關閉，必須手動啟用。

## 隱藏字幕支援的語言

Live Hub 支援以下語言的隱藏字幕：

* 英語
* 法語
* 德語
* 中文
* 西班牙語
* 義大利語
* 日語
* 葡萄牙語
* 丹麥語
* 荷蘭語
* 芬蘭語
* 土耳其語
* 韓文
* 挪威語
* 瑞典語
* 俄語

## 隱藏字幕是如何運作的

在 Live Hub 工作階段中，隱藏字幕會自動產生。 字幕會顯示在專用面板中，並隨著參與者發言而持續更新。 講師與學習者皆可查看說明文字。

每位參與者都可以依自己喜好顯示或隱藏字幕。 變更此設定不會影響其他參與者。
