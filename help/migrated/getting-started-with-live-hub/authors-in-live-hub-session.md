# 作者在 Live Hub 會話中的角色

作為 Adobe Learning Manager 的作者，您負責創建並管理使用 Live Hub 提供即時、由講師主導的虛擬教室課程。 你要設定課程、設定課程、指派講師，並發布課程，讓課程準備好開始。

本文描述作者在使用 Live Hub 時的工作內容。

## 作者能做什麼

作為作者，您在建立 Live Hub 課程時需負責以下任務。

### 建立 Live Hub 課程

作者可以在課程建立流程中建立 Live Hub 課程。 你可以：

* 在課程中新增虛擬教室模組。
* 選擇 Live Hub 作為 Live Virtual Training 工具。
* 定義課程細節，如標題、描述和時長。

### 設定會話細節

作者可以定義 Live Hub 會議的進行方式。 你可以：

* 設定日期、時間與時區
* 設定會話長度

### 使用 Instructor Finder 指派教練

使用Instructor Finder根據課程類型尋找並指派講師。 你可以：

* 根據課程需求、技能及可用性，獲得 AI 驅動的教師推薦。
* 選擇一位或多位合格的講師參加該課程。
* 透過智慧建議和簡化的教師分配，加快課程設置速度。

### 發布與管理課程

設定完成後，作者可以完成課程的最終執行與管理。 你可以：

* 為學習者發布課程
* 如有需要，更新會話細節
* 管理課程結構與模組

欲了解更多資訊，請參閱 [「建立 Live Hub 會話](./create-a-live-hub-session.md) 」。
