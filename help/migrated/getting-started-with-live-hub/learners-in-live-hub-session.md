# 以學習者身份參與 Live Hub 課程

作為 Adobe Learning Manager 的學習者，你可以參加 Live Hub 課程，參加由講師主導的即時訓練。 你的角色是加入預定的課程，使用會議室的協作工具參與，並在結束後檢視錄影。

## 加入會議

請開啟您已報名的課程，並於預定日期與時間參加 Live Hub 課程：

1. 登入 Adobe Learning Manager，然後進入&#x200B;**「我的學習」。**

1. 選擇已註冊的課程。

1. 選擇 **開始** > **進入會話**，然後選擇 **加入**。

查看 [加入會議](./join-live-hub-session-as-a-learner.md) 以獲取更多資訊。

## 參與會議

在課程中，你會與講師及其他學習者使用課程工具合作。 你可以：

* 在「Everyone」分頁與所有人聊天，或在「私人」分頁私訊講師及其他學習者。 檢視 [以學習者身份使用聊天面板](./use-the-chat-panel-as-a-learner.md)

* 問問題讓講師回應。

* 舉手並回應。 查看 [舉手並發送回應](./raise-hand-and-send-reactions.md) 以獲取更多資訊。

* 回答 [講師發起的投票](./respond-to-a-poll.md) 與 [測驗](./attempt-a-quiz.md) 。

* 如果講師啟用了螢幕共享和白板存取，你可以[分享螢幕](./share-your-screen-as-a-learner.md)並與其他參與者在白板[&#128279;](./use-whiteboard-as-a-learner.md)上協作。

* 加入分組討論室參加團體活動，並在需要指導老師時選擇 **「尋求幫助** 」。 你也可以查看 AI 生成的報告，總結你房間的討論內容。 查看 [參加分組討論以](./participate-in-a-breakout-session.md) 獲取更多資訊。

## 會議結束後

課程結束後，打開課程頁面查看課程錄影及課程中分享的檔案。
