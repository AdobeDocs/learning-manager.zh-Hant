# 管理與會者座談會

使用 **參加者** 面板來檢視並管理 Live Hub 會議中的參與者。 面板會顯示即時與會者名單，包括已加入課程的學習者及已註冊但尚未加入的學習者。 同時也會顯示每位參加者的角色與互動狀態。

作為講師，你可以使用參加者面板來管理學習者參與、設定參加者權限，並管理課程中的互動。 你可以執行靜音麥克風、放下舉起的雙手、發送私人訊息，以及移除學習者等動作。

本文說明如何在 Live Hub 場次中存取參加者面板並管理學習者。

## 查看與會者座談

**參加者**&#x200B;座談會展示了所有參與者。要開啟它，請從控制列選擇 ![開啟-attendee-panel](./assets/open-attendees.svg) 。 面板會列出所有學習者，並隨著參與者加入或離開自動更新。

![與會者座談會概述](assets/attendees-panel-overview.png)
*Live Hub 介面顯示參加者面板。*

面板中提供以下選項：

| **選擇權** | **描述** |
|----|----|
| **搜尋** | 輸入搜尋&#x200B;****&#x200B;欄位即可找到參與者。你一打字，清單就會篩選。 |
| **現況** | 顯示目前正在課程中的學習者，以及他們的角色（例如講師）和麥克風狀態。 括號內的數字表示存在的數量。 |
| **未加入** | 顯示已註冊但尚未加入的學習者。 選擇箭頭展開列表。 |

## 與會者座談會場地

管理參加者偏好：

1. 在參加者&#x200B;**面板中**&#x200B;選擇&#x200B;**更多選項（⋯）。**

1. 您可以採取以下可行的措施：

   1. **所有手放下**：參與者請放下所有舉起的雙手。

   1. **靜音所有參與者**：靜音所有參與者的麥克風。

   1. **關閉所有參與者**&#x200B;的攝影機：關閉所有參與者的攝影機。

## 在課程中管理學習者

**參加者**&#x200B;面板讓你在課程中管理個別學習者。你可以在需要時為特定學習者調整互動並快速執行行動，例如靜音麥克風、舉手放下、發送私訊或瀏覽他們的個人檔案，幫助你維持有條理的學習環境。

更新學習者權限：

1. 在參加者&#x200B;**面板中切換到學習者**。

1. 選擇學習者名稱旁的 **「更多選項」（⋯）** 圖示。

   ![學習者更多選項選單](assets/learner-more-options-menu.png)
   *更多選項選單顯示參加者面板中學習者的行動。*

1. 請選擇以下其中一個行動：

| **行動** | **描述** |
|----|----|
| **靜音** | 關閉學習者的麥克風。 |
| **下手** | 移除學習者舉起的手指示。 |
| **發送私訊** | 開啟與學習者的私人聊天。 |
| **移除會話** | 將學習者從會話中移除。 |
| **查看個人資料** | 顯示學習者的個人資料資訊。 |
