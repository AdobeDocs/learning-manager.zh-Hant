# Live Hub 會話中管理員的角色

作為 Adobe Learning Manager （ALM） 的管理員，您可以配置並管理提供 Live Hub 培訓所需的關鍵元件。 這些功能有助於簡化講師指派、課程設置、品牌塑造及報告。

本文提供與 Live Hub 會話相關的管理員操作的高層次概述。 有關詳細設定步驟與工作流程，請參閱各章節的連結文章。

## Live Hub 的管理員功能

作為管理員，你可以利用以下功能設定並執行 Live Hub 訓練。 請選擇連結文章以了解詳細步驟。

| **能力** | **你能做的事** | **了解更多** |
|----|----|----|
| **啟用 Live Hub** | 啟用 Adobe Learning Manager 帳號的 Live Hub。 您也可以啟用 AI 輔助，在 Live Hub 課程中支援作者與講師，包括： <ul><li>投票助理</li><li>問答助理</li><li>分軌監控助理</li><li>錄製主題產生器</li><li>教官尋找助理</li></ul> | [啟用 Live Hub 功能](../administrators/feature-summary/enable-live-hub.md) |
| **管理講師檔案** | <ul><li>定義講師的角色與責任</li><li>分配技能與專長</li><li>設定可上班時間與教學偏好</li><li>透過 Instructor Finder 提供更智慧的推薦</li></ul> | [新增與管理講師](./instructor-management.md) |
| **加入大量技能** | <ul><li>大量增加技能</li><li>組織與更新技能組合</li><li>技能與課程要求相符</li></ul> | [創建與修改技能與等級](../administrators/feature-summary/skills-levels.md#add-skills-in-bulk) |
| **管理假期** | <ul><li>新增一個節日，或透過上傳 CSV 檔案一次匯入多個</li><li>為每個節日設定日期、名稱及可選描述</li><li>在「全部」、「即將到來」和「過去」分頁中檢視、搜尋並篩選假期</li><li>維持一個一致且全帳號的節日行事曆</li></ul> | [管理假期](./manage-holidays.md) |
| **設定品牌與色彩主題** | <ul><li>套用色彩主題</li><li>在各場次中維持一致的視覺認同</li><li>透過品牌化環境提升學習者體驗</li></ul> | [色彩主題](../administrators/feature-summary/themes.md#color-themes) |
