# 關於民調

投票功能讓講師能在現場課程中建立並啟動投票，實時收集學習者的回應。 你可以手動建立投票，選擇題型如選擇題、多選題或簡答題，或利用 AI 輔助選項如破冰調查和知識檢查投票快速生成投票。

學習者可以回應活躍的投票、更新答案，並查看共享的結果。 所有投票活動均由 **民調與問答** 小組管理。

## 主要優點

* **提升學習者參與**&#x200B;度：鼓勵學習者積極參與，讓學習者在課程中不僅僅聆聽，還能回答問題。

* **即時檢視理解**&#x200B;度：評估學習者對主題的理解程度，並找出可能需要進一步說明的部分。

* **以破冰活動**&#x200B;開始課程：在課程開始時使用投票來熱身參與者，鼓勵早期互動，並營造更具吸引力的學習環境。

* **即時收集回饋**：在持續課程的同時，即時收集學習者的意見、偏好或回饋，且不中斷持續的教學或內容分享。

## 角色與權限

**投票**&#x200B;功能在即時中心課程中，對講師與學習者皆可使用。可用的動作會依使用者角色而異。
