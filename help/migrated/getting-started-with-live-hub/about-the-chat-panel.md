# 關於聊天小組

Live Hub 的聊天面板讓講師與學習者在現場課程中能即時溝通。 它支持公開討論、私下對話及結構化的問題處理，幫助講師有效管理互動，同時保持學習者的參與度。

## 主要優點

* **提升互動**：促進教師與學習者之間的即時溝通。

* **結構化討論**：為每個人、私人和問題設置獨立分頁，讓對話更有條理。

* **高效提**&#x200B;問：AI 輔助協助教師快速識別並回應問題。

* **管理**&#x200B;管理：教師能管理並維持有成效的討論環境。

* **情境溝通**：回覆與提及功能確保對話清晰。

## 聊天面板分頁

聊天面板包含多個分頁，幫助管理 Live Hub 會話中不同類型的對話。

* **大家：使用此**&#x200B;分頁發送並查看所有參與者可見的訊息。 AI 也會從此分頁中發布的訊息中偵測學習者問題。

* **私人：**&#x200B;使用此分頁在課程中與特定參與者進行一對一對話。

* **問題**：此分頁顯示由 AI 從公開聊天中識別的問題。 講師能有效複習、分組並回應問題。

>[!NOTE]
>
> **問題**&#x200B;分頁僅供講師使用。

## 角色與權限

聊天面板對講師和學習者開放。 面板中可用的動作與控制會依使用者在虛擬教室中的角色而有所不同。
