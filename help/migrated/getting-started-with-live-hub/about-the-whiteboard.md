# 關於白板

白板是 Live Hub 課程中共享的數位畫布，教師與學習者可即時合作。 它就像教室白板，但線上使用：你可以自由手繪、添加形狀和文字、註解想法，並在多個黑板上組織內容，所有內容都能讓所有參與者看到。

白板能幫助你：

* 用視覺輔助工具解釋複雜的主題。

* 在現場課程中與學習者互動協作。

* 將內容組織於多個板塊和頁面上。

教師可以在Live Hub中共享白板，視覺化解釋概念、註解想法，並與學習者即時協作。 白板提供共用畫布，包含繪圖工具、形狀、文字、縮放控制及協作功能。 當講師啟用編輯權限時，學習者也能繪製、添加形狀並刪除內容。
