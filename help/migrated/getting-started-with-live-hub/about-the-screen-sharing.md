# 關於螢幕共享

螢幕共享讓講師能即時從裝置與參與者分享內容。 利用螢幕共享來展示應用程式、進行簡報、示範工作流程，並引導學習者完成任務。 當講師啟用螢幕共享時，學習者也可分享螢幕。

除了共享螢幕外，你還可以在分割視圖中並排顯示兩個內容，並在共享內容旁使用白板，並直接在螢幕上標註重點資訊，同時不中斷簡報。

## 主要優點

* **即時呈現**：直接從你的裝置分享應用程式、簡報和工作流程，讓學習者能即時跟上。

* **一次**&#x200B;顯示更多內容：在分割視圖中並排顯示最多兩個內容，例如螢幕共享和白板，且無需切換。

* **視覺化說明**：直接在共享內容上註解，以突顯重點、釐清概念並引導學習者的注意力。

* **結合工具**：在白板旁放置共享螢幕，在呈現時加入說明與筆記。

* **鼓勵參與**：讓學習者分享自己的螢幕來展示作品或支援討論，同時講師仍能完全掌控課程。

## 角色與權限

螢幕共享服務對講師與學習者皆開放。 可用的動作會依使用者角色而異。
