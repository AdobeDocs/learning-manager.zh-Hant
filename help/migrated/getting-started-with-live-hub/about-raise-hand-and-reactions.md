# 關於舉手與反應

講師和參與者可以在 Live Hub 課程中使用舉手和反應功能互動。 學習者舉手表示想說話，並發送反應以提供快速且非語言的回饋。 講師可以即時觀察反應與舉手動作，管理參與度，且不會中斷課程流程。

## 主要優點

舉手與反應功能帶來以下好處：

* **鼓勵參與：讓學習者在不中斷課程的情況下，主動**&#x200B;表示想發言或提問。

* **快速收集回饋**：讓學習者能以豎起大拇指、鼓掌或思考等反應回應，讓教師即時掌握現場氣氛。

* **管理互動：**&#x200B;允許講師放下個別學習者的手或所有舉起的手，以保持討論有條理。

* **保持不干擾**&#x200B;性：透過即時出現的視覺提示與反應，支持參與感，且不中斷流程。

## 角色與權限

講師與學習者皆可在 Live Hub 會議中舉手並發送反應，但可用的行動依使用者角色而定。
