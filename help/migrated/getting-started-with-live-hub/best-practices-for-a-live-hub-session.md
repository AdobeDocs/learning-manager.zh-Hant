# Live Hub 工作階段的最佳實務

Adobe Learning Manager 中的 Live Hub 課程將講師與學習者即時結合，提供互動功能，如聊天、投票、測驗、白板、分組討論室、錄影及分析等。 這份配套指南著重於管理員、作者與講師可採取的實務，以創造順暢、有趣且有效的學習體驗。

每場 Live Hub 課程都會經過三個階段。 本指南遵循相同的節奏，決定一場遊戲成功與否的大部分努力，都在有人加入房間之前就已經完成。

## 為課程做準備

充分的準備有助於確保線上教室的流暢且引人入勝。 在學習者加入之前，請先設定課程、準備活動，並確認您的教室已準備好交付。

### 啟用 Live Hub 功能

在作者建立 Live Hub 課程之前，管理員必須先為 ALM 帳戶啟用 Live Hub 功能。 請先確認此設定已啟用，以免課程建立、報名及排程後續被阻擋。

確認您的帳戶授權或訂閱方案包含 Live Hub。 如果在管理員設定中沒有出現此選項，請先向 Adobe 支援確認授權，再進行進一步故障排除。

啟用此功能後，請通知作者與講師，讓他們能立即開始設計課程並準備課程。

### 設計課程以求清晰

作為作者，在建立課程時，請使用清晰且具描述性的標題，幫助學習者理解課程的目的。 加入簡潔的描述，說明學習者可以預期學習或完成的內容。

定義課程所培養的技能，並給予適當的技能等級與學分價值。 精準的技能映射幫助學習者發現相關訓練並提升報告準確性。

在設計課程時指派講師，讓他們有足夠時間複習內容、準備活動並熟悉教室的佈置。

### 提前為學習者報名

請提前為學習者報名，以便在課程開始前給予足夠通知。 根據您的 Adobe Learning Manager 設定，學習者會在平台及電子郵件中收到通知。

對於開放式訓練課程，建議啟用自我報名功能，讓學習者能直接從課程目錄註冊，並透過 **My Learnings** 存取課程內容。

在發佈課程之前，請確認您的帳戶已啟用學習者通知，以確保邀請與提醒能成功送達。

### 在會話開始前加入會議室

作為講師，請至少在預定開始時間前10至15分鐘加入教室。 這讓您能驗證音訊與視訊裝置、測試螢幕共享，並在學習者到來前解決任何技術問題。

利用這段準備時間設定會議室設定、檢視活動，並確保所有工作階段資源皆可用。

### 設定參與者權限

在工作階段開始前檢視參與者的權限。 僅在活動需要時啟用螢幕共享與白板存取等功能。

事先設定權限有助於在課程中保持專注，並減少在學習者等待時調整所造成的中斷。

### 準備投票與測驗

在課程開始前建立投票和測驗，以便在需要時隨時可用。

可以考慮先做破冰投票，鼓勵參與並幫助學習者從課程一開始就投入。 你也可以設計與學習目標相符、強化關鍵概念的知識檢定題目。

如果需要在場次中提升參與度，請準備額外的投票或測驗題目以啟動。

### 設定協作工具

如果您打算使用第三方協作工具，例如 Miro，請在學習者加入課程前登入並設定它們。

事先連線並驗證協作工具，有助於避免在直播時因登入提示或帳號驗證而中斷。

### 設定分組討論室

如果您的訓練包含分組討論活動，請在課程開始前建立並設定分組討論室。

定義房間數量、設定持續時間，並為每項活動提供明確指示。 如果不同群組需要不同的任務，請加入房間專屬的指示。

根據您的訓練需求選擇參與者分配方式：

* **自動指派**：自動分配參與者至分組討論室。

* **手動分配**：允許講師將參與者分配到特定教室。

### 上傳 AI 參考資料

如果您的課程使用人工智慧輔助問答功能，請在課程開始前上傳相關資料。

新增簡報投影片、文件或其他學習者必須參考的原始資料。 提供相關內容有助於 AI 產生更準確、與會話目標相符的回應。

保持上傳的教材為最新，並只包含與訓練課程相關的內容。

## 在會議期間

課程開始後，專注於清楚傳達內容、鼓勵參與，並適應學習者的參與。 利用現有的協作與促進工具，打造互動式學習體驗。

### 開始錄音與轉錄

請在課程開始時開始錄製，以完整記錄學習體驗以便日後播放。 錄音還會產生一份逐字稿，讓學習者在課後複習重要討論與概念。

告知學習者課程正在錄影，以便在討論開始前清楚表達期望。

### 有效分享內容

分享內容時，盡可能只分享簡報所需的應用程式視窗或瀏覽器分頁。 限制可見內容有助於學習者保持專注，並防止無關資訊出現在螢幕上。

使用註解工具突顯重要資訊、強調關鍵概念，並在簡報時引導學習者的注意力。 您也可以儲存已註解內容的快照以供日後參考。

若學習者需要呈現或示範內容，請依需要授予螢幕共享權限。 分享內容的參與者也可以使用可用的註解與快照工具來支援他們的簡報。

### 管理討論與問題

利用聊天室與問答區組織對話並有效回應學習者問題。

* **所有人：用於**&#x200B;開放討論和團體對話。

* **問題**：用於收集並回應學習者的問題。

* **私人：**&#x200B;用於一對一溝通且不會打斷會話。

如果有 AI 輔助回答，請利用它們生成問題的草稿答案。 在發文前請先檢視並編輯回應內容，以確保內容準確且適合你的受眾。

鼓勵學習者透過聊天參與，特別是在大型會議中，麥克風使用可能有限。 在會議中回應問題與意見，以促進參與與參與。

### 監控參與度

使用 **「與會者** 」面板追蹤參與者在場次中的活動。 面板協助您辨識出席者、查看舉手與反應，並在必要時私下與學習者溝通。

你也可以使用全房間的控制方式，例如靜音所有麥克風或清空舉起的雙手，來協助管理活動之間的轉換。 僅在維持有組織的學習環境所需時使用這些控制項。

### 利用投票和測驗提升參與度

在課程進行期間進行投票與測驗，以檢查理解度並鼓勵參與。

考慮使用：

* **用來** 評估學習者在教授概念後理解程度的小測驗。

* ****&#x200B;投票用來收集意見、收集回饋或引導團隊決策。

分享投票或測驗結果有助於引發討論，並提供澄清誤解的機會，然後再進入下一個主題。

### 監控參與者的參與度

使用 **會議室頂端的參與者參與** 度指標，即時追蹤整體參與者的參與度。 運用這些見解調整節奏、鼓勵互動，或調整活動，讓參與者在整個課程中保持專注。

| **參與度** | **指標** | **建議行動** |
|----|----|----|
| **高** | 綠色 | 繼續目前的活動。 可以考慮加入討論、測驗或分組活動，以提升學習者的參與度。 |
| **中等** | 黃色 | 透過提問、發起投票或透過聊天鼓勵參與，重新激發學習者的參與。 |
| **低** | 紅色 | 變更活動格式。 可以考慮使用投票、分組活動、討論提示或調整進度，重新吸引學習者的注意力。 |

### 促進分組討論活動

當學習者準備好開始小組活動時，啟動分組討論室。 若分組教室在課程開始前已設定好，學習者可被移至指定房間，且干擾極小。

透過在不同教室間移動、回應學習者求助請求，以及檢視 AI 生成的房間摘要，來監控分組活動。 摘要概述每個教室內的討論內容，幫助您評估學習進度、找出可能需要指導的教室，並決定何時加入對話。 摘要會在分組討論過程中自動更新，隨著討論進展而更新。

如果參與者使用 **「尋求協助** 」選項，請加入房間提供指導或回答問題。 你也可以在分組討論室中使用聊天、螢幕分享和白板等協作工具，來支援團體活動。

活動結束後，結束分組討論，將所有參與者帶回主教室。 回顧活動內容，並邀請各組與全班分享關鍵重點。 課程結束後，請檢視分組報告或會議儀表板，以取得各房間的摘要、參與者詳細資訊及其他分組見解。

## 療程結束後

課程結束後，檢視錄影與課程分析，以支持學習者、衡量參與度並改善未來的教學表現。

### 結束所有參與者的課程

當會話結束後，請結束所有參與者的房間。 這確保所有人能一起離開課程，並被引導到完成畫面，在那裡他們可以回到課程並對自己的學習經驗給予回饋。

鼓勵學習者在離開課程前提交回饋。 學習者的回饋能幫助你找出技術問題、精進引導技巧，並改善未來的課程。

### 發佈錄音

課程結束後，請從 **課程** > **概覽** 頁面存取錄影，並在與學習者分享前檢視。

使用編輯工具移除設定活動、暫停或其他非必要內容，讓學習者能專注於教學材料。

錄製過程中產生的逐字稿，讓內容變得可搜尋且更容易存取，方便日後重溫課程的學習者。

### 分析會話效能

檢視課程分析，了解學習者的參與並找出改進機會。

利用可用的分析檢視來評估會話的不同面向：

| **分析領域** | **描述** |
|----|----|
| **課程摘要** | 檢視出席情況、課程時長、錄音可用性及整體課程細節。 |
| **互動** | 評估學習者在投票、測驗、分組討論室、問答、反應及其他互動活動中的參與情況。 |
| **參與者活動** | 了解個別學習者的參與程度，並判斷是否需要額外支援。 |
| **報告** | 下載會議與互動報告，用於記錄、分析或與利害關係人分享。 |

檢視這些洞見有助於你判斷哪些活動最有效，以及學習者可能遇到的挑戰。

### 將所學經驗應用於未來的課程

利用分析與學習者回饋來優化未來的交付。

例如，如果某項活動的參與度下降，未來的課程可以考慮調整形式、節奏或時間安排。 如果某個調查引發了熱烈討論，或是分組討論活動證明有價值，就把類似的方法融入未來的訓練中。

持續改進有助於隨著時間創造更有趣且更有效的學習體驗。

### 與學習者進行後續追蹤

課程結束後檢視參與者的活動，並找出可能需要額外支援的學習者。

請考慮將錄音、成績單、課程資源或任何後續評量分享給錯過課程或未能完全參與的學習者。 提供這些資源的存取，有助於學習者與課程目標保持一致，並在現場活動結束後持續學習。
