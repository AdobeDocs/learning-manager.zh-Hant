# Live Hub（Beta）會話的最佳實務

Adobe Learning Manager 中的 Live Hub 課程將講師與學習者即時連結，提供互動功能，如聊天、投票、測驗、白板、分組討論室、錄影及分析功能。 本配套指南聚焦於管理員、作者與講師可採用的做法，以打造順暢、引人入勝且有效的學習體驗。

每個 Live Hub 課程都經過三個階段。 這份指南遵循相同的節奏，決定一場遊戲成功的關鍵大部分努力都在有人加入房間之前完成。

## 準備開始

充分的準備有助於確保線上教室的順利且引人入勝。 在學員加入前，請先設定課程、準備活動，並確認房間已準備好送達。

### 啟用 Live Hub 功能

在作者建立 Live Hub 課程之前，管理員必須先啟用 ALM 帳號的 Live Hub 功能。 先確認此設定已開啟，避免課程創建、註冊及排課後續被阻擋。

請確認你的帳號授權或訂閱方案是否包含 Live Hub。 如果管理員設定中沒有這個選項，請先向 Adobe 客服確認權限，再進行進一步排查。

啟用此功能後，通知作者與講師，讓他們能立即開始設計課程並準備課程。

### 課程設計以求清晰

作為作者，在創建課程時，請使用清晰且具描述性的標題，幫助學習者理解課程的目的。 加入簡潔的描述，說明學習者可以預期學習或達成的目標。

定義課程所培養的技能，並給予適當的技能等級與學分價值。 準確的技能映射幫助學習者發現相關訓練並提升報告的準確性。

在設計課程時指派講師，讓他們有足夠時間複習內容、準備活動並熟悉教室的佈置。

### 提前報名學習者

提前為學員報名，以便在課程開始前給予足夠通知。 根據你的 Adobe Learning Manager 設定，學習者會在平台上及電子郵件中收到通知。

對於開放式培訓課程，建議啟用自助報名功能，讓學習者能直接從課程目錄註冊，並透過 **My Learning** 存取課程內容。

在發布課程前，請確認你的帳號已啟用學習者通知，以確保邀請和提醒能順利送達。

### 在課程開始前加入房間

作為講師，請至少在預定開始時間前10到15分鐘加入教室。 這讓你能驗證音訊和視訊裝置，測試螢幕共享，並在學員到來前解決任何技術問題。

利用這段準備時間設定教室環境、檢視活動，並確保所有課程資源皆可用。

### 設定參與者權限

在課程開始前，請檢視參與者的權限。 只有在活動需要時才啟用螢幕共享和白板存取等功能。

事先設定權限有助於在課程中保持專注，並減少因等待時調整而造成的中斷。

### 準備投票和測驗

在會議開始前製作投票和測驗，以便在需要時隨時可用。

建議先進行破冰調查，鼓勵參與並幫助學習者從課程一開始就投入。 你也可以設計與學習目標相符並強化關鍵概念的知識檢查題目。

如果需要提升參與度，可以準備額外的投票或小測驗問題。

### 建立協作工具

如果你打算使用第三方協作工具，例如 Miro，請在學習者加入課程前登入並設定它們。

事先連接並驗證協作工具，有助於避免直播時因登入提示或帳號驗證而中斷。

### 配置分組討論室

如果你的訓練包含分組討論活動，請在課程開始前建立並設定分組討論室。

定義房間數量、設定時長，並為每項活動提供明確指示。 如果不同組別需要不同的任務，可以加入房間專屬的指示。

根據您的訓練需求選擇參與者分配方式：

* **自動分配**：自動分配參與者至分組討論室。

* **手動分配**：允許講師將參與者分配到特定房間。

### 上傳 AI 參考資料

若您的課程使用AI輔助問答功能，請在課程開始前上傳相關資料。

新增簡報投影片、文件或其他學生需要參考的來源資料。 提供相關內容有助於 AI 產生更準確、符合會話目標的回應。

保持上傳教材的最新，並只包含與培訓課程相關的內容。

## 會議期間

課程開始後，專注於清楚傳達內容、鼓勵參與，並適應學習者的參與。 善用現有的協作與促進工具，創造互動式學習體驗。

### 開始錄音與轉錄

從課程開始時開始錄音，以完整記錄學習過程，方便日後播放。 錄音還會產生逐字稿，讓學習者在課後複習重要討論與概念。

告知學習者課程正在錄音，以便在討論開始前清楚期望。

### 有效分享內容

分享內容時，盡量只分享簡報所需的應用程式視窗或瀏覽器分頁。 限制可見內容有助於學習者保持專注，並防止螢幕上出現無關資訊。

使用註解工具來突顯重要資訊、強調關鍵概念，並在簡報時引導學習者的注意力。 你也可以儲存註解內容的快照以備日後參考。

若學習者需要呈現或示範內容，請依需求授予螢幕共享權限。 分享內容的參與者也能利用現有的註解與快照工具來支持他們的簡報。

### 管理討論與提問

利用聊天室和問答區組織對話並有效回應學習者問題。

* **大家**：用於開放討論和團體對話。

* **問題**：用來收集並回答學習者的問題。

* **私人：**&#x200B;用於一對一溝通且不打斷會話。

若有 AI 輔助回答，請利用它們生成問題的草稿答案。 在發文前請審閱並編輯回應，以確保其準確且適合你的受眾。

鼓勵學習者透過聊天參與，尤其是在大型會議中麥克風使用可能受限時。 在場次中回應問題與意見，以促進參與與參與。

### 監督參與度

利用 **參加者** 面板追蹤參與者在場次中的活動。 小組協助你辨識出席者，觀察舉手與反應，並在必要時私下與學習者溝通。

你也可以使用全場控制，例如靜音所有麥克風或清理舉起的手，來幫助管理活動間的轉換。 這些控制措施僅在必要時使用，以維持有組織的學習環境。

### 利用投票和測驗來提升參與度

在課程中啟動投票和測驗，以檢查理解度並鼓勵參與。

考慮使用：

* **在教授一個概念後，透過** 測驗評估學習者的理解程度。

* **&#x200B;**&#x200B;投票用來收集意見、收集回饋或引導團體決策。

分享投票或測驗結果有助於引發討論，並提供澄清誤解的機會，然後再進入下一個主題。

### 監控參與者參與度

使用 **會議室頂端的參與者參與** 度指標，即時追蹤整體參與者參與度。 利用這些洞察調整節奏、鼓勵互動，或調整活動，讓參與者在整個課程中保持參與。

| **參與度** | **指標** | **建議行動** |
|----|----|----|
| **高** | 綠色 | 繼續進行目前的活動。 可以考慮加入討論、小測驗或分組活動，以提升學習者的參與度。 |
| **媒介** | 黃色 | 透過提問、發起投票或透過聊天鼓勵參與，重新吸引學習者參與。 |
| **低** | 紅色 | 改變活動形式。 可以考慮使用投票、分組討論活動、討論提示或調整進度來重新吸引學習者的注意力。 |

### 促進分組活動

當學習者準備好開始團體活動時，啟動分組討論室。 若分組教室在課程前已設定好，學習者可被移至指定房間，且干擾最小。

透過在教室間移動、回應學習者求助及檢視 AI 生成的教室摘要，來監控分組活動。 摘要概述了每個房間內的討論內容，幫助你評估學習進度、找出可能需要指導的房間，並決定何時加入對話。 摘要會隨著討論進展自動更新。

如果參與者使用 **「求助** 」選項，請加入房間提供指導或回答問題。 你也可以在分組討論室使用聊天、螢幕分享和白板等協作工具，來支持團體活動。

活動結束後，結束分組討論，讓所有參與者回到主教室。 回顧活動內容，並邀請小組分享主要收穫給全班同學。 課程結束後，請查看分組報告或會議儀表板，取得各房間摘要、參與者細節及其他分組見解。

## 會議結束後

課程結束後，檢視錄影與課程分析，以支持學習者、衡量參與度並改善未來的交付。

### 結束所有參與者的會議

當會議結束後，為所有參與者結束房間。 這確保所有人能一起離開課程，並被引導到完成畫面，回到課程並對學習經驗給予回饋。

鼓勵學習者在離開課程前提交回饋。 學習者回饋能幫助你識別技術問題、精進引導技巧，並改善未來的課程。

### 發布錄音

課程結束後，請從 **課程** > **概覽** 頁面存取錄影，並在分享給學習者前檢視。

使用編輯工具移除設定活動、暫停或其他非必要內容，讓學習者能專注於教學材料。

錄音時產生的逐字稿，透過讓內容可搜尋且更易於學習，成為日後回顧課程的學習者所能取得的額外學習資源。

### 分析會話效能

檢視課程分析以了解學習者的參與並找出改進機會。

利用可用的分析檢視來評估會議的不同面向：

| **分析領域** | **描述** |
|----|----|
| **會議摘要** | 檢視出席情況、課程時長、錄音可用性及整體課程細節。 |
| **互動** | 評估學習者參與投票、小測驗、分組討論、問答、反應及其他互動活動。 |
| **參與者活動** | 識別個別學習者的參與程度，並判斷是否需要額外支持。 |
| **報告** | 下載會話及互動報告，以便記錄、分析或與利害關係人分享。 |

回顧這些洞見能幫助你判斷哪些活動最有效，以及學習者可能遇到的挑戰。

### 將所學應用於未來的課程

利用分析與學習者回饋來優化未來的交付。

例如，若某項活動參與度下降，建議在未來的課程中調整形式、節奏或時間安排。 如果某項投票引發了強烈討論，或分組活動證明有價值，則應將類似方法融入未來的培訓中。

持續改進有助於隨著時間創造更有趣且有效的學習體驗。

### 與學習者後續跟進

課後檢視參與者的活動，並找出可能需要額外支持的學習者。

考慮與錯過課程或無法完全參與的學習者分享錄音、成績單、課程資源或任何後續評估資料。 提供這些資源的存取權有助於學習者與課程目標保持一致，並在現場活動結束後持續學習。
