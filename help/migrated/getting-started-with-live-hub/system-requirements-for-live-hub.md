# 系統需求

請使用以下系統需求在 Adobe Learning Manager 中配置並執行 Live Hub 會話。 Live Hub 使用與其運行的虛擬教室環境相同的瀏覽器、作業系統及硬體需求。

Live Hub 可在虛擬教室會話中使用，且不需另行安裝用戶端。

| 類別 | 需求 |
|---|---|
| **桌面瀏覽器** | 最新版本的 Google Chrome、Mozilla Firefox、Microsoft Edge 與 Safari |
| **行動瀏覽器** | Chrome Mobile、Safari Mobile 與三星網路 |
| **作業系統** | Windows 10 或更新版本，macOS 15 或更新版本 |
| **螢幕解析度** | 1920 × 1080、1366 × 768、768 × 1024（平板電腦）及 375 × 667（行動版） |
| **Windows 硬體** | 最低 8 GB 記憶體、8 核心處理器、Intel® Core™ i5 或以上 |
| **Mac 硬體** | 最低 16 GB 記憶體、4 核心處理器、3.2 GHz 或以上 |
| **網絡** | 建議穩定的寬頻連線，至少 5 Mbps 以享受即時音訊、視訊及 AI 驅動的 Live Hub 功能 |

>[!NOTE]
>
>Linux 瀏覽器、Chromebook 裝置、Firefox Mobile、Opera（桌面與行動版）、Internet Explorer 11 及較舊版本的瀏覽器均不支援。
