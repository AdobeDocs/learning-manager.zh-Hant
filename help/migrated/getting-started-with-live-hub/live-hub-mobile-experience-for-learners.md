# 以學習者身份在行動裝置上使用 Live Hub（測試版）

使用 Adobe Learning Manager 行動應用程式，從 iOS 或 Android 裝置加入並參與 Live Hub 課程。 在課程中，你可以與講師和參與者互動，回答投票和測驗，在分組討論室中協作，並直接從行動裝置存取共享內容。

>[!NOTE]
>
> 行動應用程式支援 Live Hub 的核心參與功能。 桌面版的部分功能在行動裝置上無法使用。 欲了解桌面版支援的完整功能清單，請參閱 [「Live Hub](./getting-started-live-hub.md) 入門」。

## 行動學習者的學習體驗

下表總結了行動應用程式中學習者可使用的 Live Hub 功能。

| **特色** | **行動體驗** |
|----|----|
| 加入會議 | 透過 Adobe Learning Manager 行動應用程式加入 Live Hub 課程。 |
| 音訊與影像 | 請開啟或關閉麥克風和攝影機，並選擇可用的音訊設備。 |
| 聊天與提問 | 參與聊天對話並在會議中提出問題。 |
| 反應與舉手 | 發送反應並舉手與教練互動。 |
| 民調 | 回應會議期間發布的民調。 |
| 測驗 | 嘗試由講師發起的小測驗。 |
| 分組討論室 | 加入指定的分組討論室，與其他參與者合作，請求講師協助，並查看分組討論摘要。 |
| 白板與共享內容 | 瀏覽並互動會議中分享的內容。 |
| Miro 鍵盤 | 瀏覽教練分享的 Miro 滑板。 |
| 隱藏字幕 | 在會談過程中開啟或關閉隱藏字幕。 |
| 螢幕共享 | 瀏覽由講師或參與者分享的內容。 |
| 錄音室錄音 | 錄音在會談結束後開放時即可存取。 |

## 加入 Live Hub 會議

透過 Adobe Learning Manager 行動應用程式加入您預定的 Live Hub 課程。

加入前，您可以檢查相機、麥克風和音訊設備的設定，確保設定正確。

![行動版預加入畫面](assets/mobile-pre-join-screen.png)
*在加入 Live Hub 行動裝置前，請先檢查你的攝影機、麥克風和音訊裝置設定。*

>[!NOTE]
>
> 虛擬背景和背景模糊效果在行動應用程式中不支援。

## 導航會話介面

加入會議後，主會議畫面會顯示參與者的影片磚塊或共享內容，並包含溝通與參與的控制功能。

利用會話控制來：

* 請開啟或關閉你的麥克風。

* 開啟或關閉你的相機。

* 舉手。

* 發送反應。

* 存取聊天室與提問。

* 參與投票和小測驗。

* 參加分組討論活動。

* 離開會議。

## 請使用隱藏字幕

隱藏字幕幫助你在會話中追蹤語音內容。

你可以在參加 Live Hub 課程時隨時開啟或關閉字幕。

>[!NOTE]
>
> 手機應用程式中不支援字型大小與顯示樣式等標題格式選項。

## 在聊天室提問

使用聊天面板與講師及其他參與者溝通。

你可以：

* 在會話聊天室發訊息。

* 查看講師與參與者的訊息。

* 在會議中提出問題。

* 請審閱講師提供的回答。

## 回應民調

當講師發起投票時，該投票會自動顯示在課程中。

![行動回應投票](assets/mobile-respond-to-poll.png)
*直接在 Adobe Learning Manager 行動應用程式中回應投票。*

你可以直接從手機應用程式提交回應。 根據投票的設定，你也可能在回應後查看投票結果。

## 嘗試測驗

當講師啟動測驗時，你可以在行動裝置上完成測驗，無需離開課程。

測驗結果與答案可見度取決於講師設定的設定。

## 參與分組討論

若分組討論室在課程中被使用，講師會指派你到某個房間。

![行動分組討論室視圖](assets/mobile-breakout-room-view.png)
*分組討論室視圖，展示行動裝置上的協作選項。*

在分組討論室中，你可以：

* 與其他參與者合作。

* 參與分組討論活動。

* 請向教官請求協助。

* 有分組摘要時請先檢視。

分組討論室的分配與時間由講師負責。

## 查看共享內容

在課程中，講師可能會分享簡報、白板、Miro看板或其他內容。 你可以直接在行動應用程式中查看分享內容，並追蹤討論和活動。

![行動裝置檢視共享內容](assets/mobile-view-shared-content.png)
*直接在行動應用程式中查看講師分享的內容。*

## 離開一場遊戲

當你準備退出會話時，選擇 **離開**。

![行動休假時段](assets/mobile-leave-session.png)
*選擇離開以從行動應用程式中退出會話。*

離開後，系統會提示您對這次會談的經驗提供回饋。
