# 關於測驗

Live Hub 中的測驗功能讓講師能在現場課程中建立並進行測驗，以評估學習者的理解程度。 你可以在課程開始前或期間建立測驗，啟動以即時收集回應，並在課程儀表板中監控學習者的回應結果。

>[!NOTE]
>
> Live Hub 會話中的測驗與 Adobe Learning Manager 的測驗製作工具&#x200B;**所建立**&#x200B;的不同。

## 主要優點

測驗功能提供以下好處：

* **評估學習成果**：評估學習者在教學後對關鍵概念的理解與記憶程度。

* **進行結構化評量**：設計多題小測驗，超越單一題目檢查，評估學習者在主題或模組上的表現。

* **追蹤個人表現**：即時測驗結果幫助講師快速了解整個團隊的表現，並找出可能需要進一步說明的部分。

* **提升參與度**：透過互動式評量鼓勵積極參與。
