# 使用未登入的選單網址進行自我註冊

自我註冊檔案讓外部使用者，例如合作夥伴或多個組織成員，能在 Adobe Learning Manager 中建立自己的帳戶。 您現在可以為每個自我註冊設定檔分享一個未登入的選單 URL。 選單內建於 Experience Builder 中。

當使用者從該 URL 所到達的頁面選擇 **「註冊」** 時，Adobe Learning Manager 會將他們加入該 URL 所屬的個人檔案中。 這讓您能將來自不同組織的使用者（例如不同代理商或合作夥伴公司）分別保存在不同的個人檔案中。

過去，未登入的頁面 URL 總是會為品牌設定&#x200B;**中所選**&#x200B;的個人檔案新增新使用者。未登入選單的網址消除了這個限制：每個個人檔案都有自己的網址，且所有網址都會開啟相同的登陸頁面。

## 開始之前

1. 在 Experience Builder 中建立「未登入」選單，並在品牌設定&#x200B;**中**&#x200B;選擇登陸頁。所有個人檔案網址都會開啟此首頁。

1. 在 **「使用者** > **外部**」中建立自我註冊設定檔。 每個個人檔案都有自己的群組 ID 和存取金鑰，使用者需要註冊。

## 複製個人檔案的註冊 URL

1. 選擇 **「使用者** > **外部** 」，然後選擇 **「自我註冊**」。

1. 在 **「要複製** 的登陸頁 URL」欄位中，勾選 **「未登入** 」以設定個人檔案。

   ![要複製的登陸頁 URL 用於自我註冊個人資料](assets/Use-a-non-logged-in-menu-URL-for-self-registration-image1.png "要複製的登陸頁 URL")

1. 複製 URL 並與您想邀請的使用者分享。

**「要複製**&#x200B;的登陸頁 URL」清單包含以下選項：

* **註冊**：標準註冊網址
* **未登入首頁（舊版）：**&#x200B;舊版未登入首頁的網址
* **未登入選單**：Experience Builder 中未登入選單的 URL

## 使用者看到什麼

1. 使用者開啟該 URL，並會跳到您在品牌設定&#x200B;**中**&#x200B;選擇的未登入登陸頁面。

1. 使用者選擇 **「註冊** 」，並輸入該個人檔案的群組 ID 與存取金鑰。

1. 使用者輸入姓名、電子郵件地址及密碼，然後完成註冊。

Adobe Learning Manager 會將使用者新增至該 URL 所屬的個人檔案中。 您可以在該設定檔下看到該設定檔下的新&#x200B;**使用者，>******&#x200B;外部使用者。

>[!NOTE]
>
>每個個人檔案網址都會顯示相同的登陸頁面。 只有使用者被加入的個人檔案不同。

## 寄送包含網址的歡迎電子郵件

1. 選擇 **「外部** 使用者」> **「外部** 」，並選擇自我註冊設定檔。

1. 在 **「要複製** 的登陸頁 URL」清單中，選擇您想包含在電子郵件中的 URL。

   ![首頁網址清單，附郵件與複製圖示](assets/Use-a-non-logged-in-menu-URL-for-self-registration-image2.png "首頁網址清單")

1. 選取郵件圖示以發送電子郵件。 或者，選取複製圖示以複製 URL。

Adobe Learning Manager 會使用 **「建立檔案（外部/合作夥伴）** 」範本發送電子郵件。 電子郵件包含您所選擇的唯一 URL、個人檔案的座位限制，以及 URL 到期日。 將 URL 分享給您想邀請的使用者。

## 從舊版未登入首頁移動

此清單的早期版本顯示了「未登入&#x200B;**」選項**。現在它的名字 **是「未登入首頁（舊版）**」。

舊有的非登入首頁將在未來版本中被淘汰。 如果你使用它，請移到 Experience Builder 的「未登入」選單，以保留相同的功能。
