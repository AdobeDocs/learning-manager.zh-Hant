# 概觀

Experience Builder 讓管理員能在平台上打造量身打造的學習者體驗，銜接原箱即用原生介面與完全無頭解決方案之間的差距。 它允許使用多種小工具設計自訂頁面，靈活的選單配置，以及透過 CSS 和 JavaScript 進行進階品牌塑造。 此方法相較於無頭組裝縮短上市時間與實施成本，同時仍提供深度品牌與版面客製化。

## 你可以自訂的部分

**頁腳**

你有兩個基腳選項。 你可以使用預設頁尾，該頁尾在一般管理設定中已設定，或者選擇自訂頁尾。 自訂選項允許你輸入自己的 HTML 和 CSS，讓你完全掌控頁腳的設計與內容，以符合你的品牌。

請參閱本節以獲取更多資訊。

**全域 CSS 與 JS 配置**

透過注入自訂的 CSS 和 JavaScript，自訂學習器應用程式的外觀與功能。 這讓品牌能精確建立、動態介面變更，以及進階互動功能。 此外，透過注入自訂的 CSS 和 JavaScript，客製化學習器應用程式的外觀與功能。 這讓品牌能精確建立、動態介面變更，以及進階互動功能。

請參閱本節以獲取更多資訊。

**球場瓦片**

全域配置整個帳戶學習物件卡片上顯示的細節。 你可以顯示或隱藏元素，例如作者姓名、技能名稱、評分、描述以及報名按鈕。 然而，像標題、圖片、價格和進度條等核心元資料無法被移除。

請參閱本節以獲取更多資訊。

**小工具**

在體驗建構器中，透過選擇多種小工具類型（例如行事曆、分類、課程與路徑、自訂內容框、遊戲化、HTML、iFrame、社交學習、我的學習）來自訂小工具，並設定其屬性、版面配置與內容。 小工具支援自訂標題、描述、圖片、動作，有時還能進階選項，如注入 HTML、CSS 和 JavaScript，提供動態或 API 驅動的體驗。

請參閱本節以獲取更多資訊。

## 使用案例

**建立以角色為基礎、個人化學習入口網站**

在同一帳號內，為不同學習者提供不同的體驗，例如為特定受眾建立自訂頁面和選單，或是精選學習條帶。

此外，指定已發佈的自訂頁面作為特定使用者群的登陸頁面。 這確保該群組的學習者登入時，會立即被導向相關且客製化的體驗，而非預設首頁。

**建立針對事件的學習頁面**

Experience Builder 非常適合為企業活動或時效性計畫打造臨時且專注的學習體驗。

* **企業活動**：像「設計高峰會」這類活動，管理員可以為設計團隊建立專屬的新頁面。 這些頁面可能包含場次資訊、講者名單及活動前訓練資料。 行事曆小工具在這裡特別實用，因為它可以加入頁面，顯示即將到來的場次，並讓參加者註冊及追蹤。
* **限時活動**：建立一個臨時活動，例如為期兩個月的「銷售啟動活動」。 在此期間，客製化首頁與選單僅對銷售團隊開放，包含「銷售啟動2026」等橫幅及新財政年度策略專屬課程。 兩個月後，入口網站可以恢復為所有人的標準體驗。 這讓能夠建立針對性的「微學習活動」。

**發展品牌客戶學院**

Experience Builder 讓企業能建立符合品牌的客戶培訓入口網站，而無需完全無頭實施的高昂成本與漫長開發時間。

為了最大化彈性，例如 HTML 小工具允許你嵌入自訂的 HTML、CSS 和 JS 程式碼，用於推薦信或獨特風格的橫幅等元素。 這讓你對品牌體驗有更多掌控。

**整合自訂內容**

設定選單出現在不同位置（左邊欄、上方導覽、頁首下方），並控制頁面可見性，以簡化使用者旅程。

* **建立豐富內容區塊**：內容框小工具讓你輕鬆建立包含標題、描述、圖片及行動呼籲（CTA）的區塊，引導學習者或突顯關鍵資訊。
* **鼓勵合作與競爭**：你可以新增社交學習小工具來顯示貼文和留言，或遊戲化小工具直接在自訂頁面上顯示排行榜和分數，促進互動。
* **組織內容以便輕鬆導航**：使用分類小工具將目錄、產品或角色以磁磚條狀顯示，為學習者提供清晰且視覺化的導覽路徑，指向不同內容區域。
整合外部工具
* **嵌入外部應用程式**：iFrame 小工具允許您直接將外部網頁應用程式或網頁嵌入自訂頁面中，為學習者創造更流暢的體驗。
* **用 API** 建立動態元件：HTML 小工具允許你加入 JavaScript，讓使用者能與例如學習者 API 互動。 透過這種方法，你可以在原生學習管理器環境中創造經驗，而不必另建新應用程式。
