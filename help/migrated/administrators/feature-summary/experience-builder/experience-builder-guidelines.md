# 體驗建構者的指引與限制

Experience Builder 是一款強大的工具，旨在幫助使用者輕鬆建立動態且引人入勝的網頁。 為了確保最佳效能、可用性與安全性，在配置頁面、使用小工具及自訂版面時，務必遵循特定的指引與建議。 本文件詳細概述了使用者在使用 Experience Builder 時應注意的重要注意點與重點。

此處所概述的資訊涵蓋了頁面與小工具設定、自訂選項、自訂程式碼處理及安全考量等關鍵面向。 遵循這些建議，使用者能最大化體驗建構器專案的效率，避免常見陷阱，並順利適應更新與變更。

## 頁面與小工具設定

### 最大頁數

你可以在體驗建構器中建立最多 1000 頁。 這是上限，但建議有策略地規劃頁面，以避免不必要的複雜性。

### 每頁小工具數

* **硬性限制**：單頁最多可新增 25 個小工具。
* **建議限制**：為提升效能，建議每頁使用不超過 10 個小工具。
* **基於 API 的小工具**：依賴 ALM API 的小工具（例如課程與路徑、分類、我的學習、社交學習、行事曆、合規、排行榜）應限制每頁 10 個。
* **獨立元件**：像 HTML 和 Content box 這類不依賴 ALM API 的小工具，最多可使用至 25 個小工具。

### 一次性小工具

某些小工具，如行事曆、社交學習、合規和排行榜，每頁只能使用一次。 多次使用可能會造成效能問題，尤其是像行事曆這類需要大量資源載入會話的小工具。

### 小工具尺寸指引

像是行事曆、排行榜、社群和合規等小工具，應置於頁面寬度至少三分之一的版面中。 單張卡片小工具最適合此寬度，以確保最佳顯示效果。 像日曆和合規（擴展檢視）這類小工具是為半寬版面設計，以提供更好的使用者體驗。 對於其他版面大小，小工具會根據可用空間做出回應調整，並維持可用性。

在這些建議大小指引內使用小工具，提升整體用戶互動。

## 客製化指引

### 預設像素距離

**垂直距離**：元件間的預設垂直距離為 80 像素。
**水平距離**：元件間的預設水平距離為 20 像素。

### 自訂 CSS

使用者可透過自訂 CSS 覆蓋預設距離及其他視覺屬性。

客製化步驟：

* 檢查頁面元素以辨識 CSS 類別。
* 可在全域層級、元件層級或頁面層級套用變更。

例如，為了減少小工具間的垂直距離，可以修改相關類別的 CSS 屬性。

## 選單位置

選單可以放在頁面的上方或左側。 還可以用自訂 CSS 做進一步調整。

## 專屬功能推薦

### 社交學習與遊戲化小工具

* 若這些功能被停用，管理員必須手動從頁面中移除相應的小工具。
* 關閉這些功能後，頁面應重新設計，以確保功能完整且視覺完整。

## 處理自訂程式碼

### 更新的影響

* 在 Experience Builder 更新後，注入後端的現有自訂程式碼（HTML、CSS、JS）可能無法如預期運作。
* 使用者必須重寫程式碼以配合新的使用者介面變更，例如更新的類別名稱。

### 前端支援

* 直接在管理入口網站使用 HTML 小工具或帳號層級的 CSS/JS 區塊新增自訂程式碼。

### 免責聲明

* 自訂程式碼在未來版本中可能無法如預期運作，需要調整。 每次更新後都要準備好更新他們的程式碼。

## 一般建議

### 效能考量

* 避免超過建議的小工具限制，以防止效能下降。
* 在同一頁面上多次使用資源密集型元件（例如行事曆），會大幅影響頁面載入時間。

### 安全考量

* **HTML 小工具**：你必須確保程式碼能處理像跨站腳本攻擊（XSS）這類安全問題，因為這超出 Experience Builder 的控制範圍。
* **自訂頁尾**：使用 HTML 或 CSS 自訂頁腳時，請確保程式碼符合安全最佳實務。

### 重大變更

經驗建構器的更新可能會帶來自訂功能上的重大變更。 你必須：

* 調整程式碼以符合新的 UI 元素。
* 每次更新後測試自訂功能。

## 附加說明

### 自訂 CSS 實作

* 你可以檢查頁面元素、複製 CSS 類別，並將它們所需的屬性套用到全局自訂版面、widget 層級或頁面層級。

### 小工具 ID 與頁面 ID

每個小工具和頁面都有可用於特定 CSS 變更的獨特 ID。 這允許在不同層級進行客製化：

* 全域層級：在所有頁面套用 CSS 變更。
* 元件層級：對特定元件套用 CSS 變更。
* 頁面層級：對特定頁面內的所有小工具套用 CSS 變更。
