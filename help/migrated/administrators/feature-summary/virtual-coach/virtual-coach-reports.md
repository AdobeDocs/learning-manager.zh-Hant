# 虛擬教練報告

作為管理員，您可以查看兩份與虛擬教練相關的報告。 它們分別是 **學習者使用摘要** 和 **課程細節**。

![](/help/migrated/administrators/feature-summary/assets/virtual-coach-report1.png)

## 學習者使用摘要

學習者使用摘要包含所有註冊於該帳戶的學習者的每月使用詳情。 這些使用細節包含對使用與學習模式的洞察。

### 產生學習者使用摘要

要產生學習者使用摘要：

1. 以管理員身份登入。
2. 可瀏覽管理&#x200B;****>**報告**> **AI 報告**。
3. 在 **虛擬教練** 區塊中，選擇 **學習者使用摘要**。 **虛擬教練學習者使用資料**&#x200B;彈窗會顯示。
4. 選擇 **開始日期** 和 **結束日期**。
5. 選擇 **繼續**。 報告會以.csv檔案形式產生。 你可以在 **檔案總管的下載** 資料夾中找到已下載的.csv檔案。

   ![](/help/migrated/administrators/feature-summary/assets/virtual-coach-report2.png)

   ![](/help/migrated/administrators/feature-summary/assets/virtual-coach-report-learn-usage-6.png)

## 會議詳情

**課程詳情**&#x200B;報告包含過去90天內所有註冊於該帳戶的學習者的課程詳情。這些使用細節包含對使用與學習模式的洞察。

### 產生會話細節

要產生會話詳情報告：

1. 以管理員身份登入。
1. 可瀏覽管理&#x200B;****>**報告**> **AI 報告**。
1. 在 **虛擬教練** 區塊中，選擇 **課程詳情**。 **「產生檢舉請求**」彈窗出現。
1. 選擇 **確定**。 報告會以.csv檔案形式產生。 你可以在 **檔案總管的下載** 資料夾中找到已下載的.csv檔案。

   ![](/help/migrated/administrators/feature-summary/assets/virtual-coach-report3.png)

   ![](/help/migrated/administrators/feature-summary/assets/virtual-coach-report-session-4.png)

>[!NOTE]
>
>Adobe Learning Manager 不會保留學習者的虛擬教練課程紀錄。 學習者可同時進行多場課程。 然而，學習者不得返回先前的虛擬教練課程。
