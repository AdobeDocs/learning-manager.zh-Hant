# 管理虛擬教練使用與帳單

啟用虛擬教練、監控每月活躍用戶（MAU）信用額度消費，並以 Adobe Learning Manager 管理員身份下載學習者表現報告。

## 為您的帳號啟用虛擬教練 {#activatevirtualcoach}

虛擬教練可作為 Adobe Learning Manager 的附加元件使用。 購買後，設定會產生一組啟用金鑰，並透過電子郵件發送給帳戶管理員。

1. 以管理員身份登入 Adobe Learning Manager。
2. 從 **左側導覽窗格進入帳單** 頁面。
3. 在 **虛擬教練** 區，輸入你收到的啟動金鑰。

   ![](/help/migrated/administrators/feature-summary/assets/virtual_coach12.png)
   *請在帳單頁面的虛擬教練區輸入您的啟用金鑰，即可啟用此功能。*

4. 選擇 **「申請」**。 虛擬教練已啟用於你的帳號。

啟用後，你會收到應用程式內通知，確認該功能已上線。 內容庫會自動&#x200B;**新增四個範例角色扮演情境，讓作者能立即開始。**

>[!NOTE]
>
>啟用金鑰會在配置過程中自動產生，並透過電子郵件分享。 如果你沒有啟用金鑰，請聯絡你的 Adobe Learning 經理或客戶成功經理。

## 查看MAU信用餘額

每月活躍用戶（MAU）積分計算每月使用虛擬教練的獨立學習者數量。

1. 請前往 **帳單** 頁面。
2. 在 **虛擬教練** 區塊中，選擇 **查看使用詳情**。

   ![](/help/migrated/administrators/feature-summary/assets/virtual-coach22.png)

3. 使用 **「選擇期間** 」下拉選單，選擇你想檢視的日期範圍。

   **整體使用**&#x200B;量表顯示：

   - **可取得**：購買的總 MAU 積分。
   - **已使用**：已消耗的信用點數。
   - **剩餘：合約**&#x200B;剩餘期間內可用的信用點數。

   **每月使用**&#x200B;量表顯示各曆月獨立活躍學習者的數量。

   ![](/help/migrated/administrators/feature-summary/assets/virtual-coach23.png)

4. 選擇 **下載詳細報告** 以匯出完整使用數據。

   ![](/help/migrated/administrators/feature-summary/assets/virtual-coach-report-mau-billing-5.png)

## MAU積分的消費方式

當學習者在曆月內啟動虛擬教練課程時，會消耗一個 MAU 積分。 同一位學習者在同一個月內完成的額外課程不會消耗額外的學分。 合約期結束時未使用的信用點數會過期且不會結轉。

| 劇本 | 消費的MAU數 |
|---|---|
| 一名學員在一月完成五堂課 | 1 |
| 同一位學習者在一月和二月都使用 Virtual Coach | 2 次（每月 1 次） |
| 每年一月各有100名學員完成一堂課 | 100 |

*MAU 學分會按每個日曆月的獨立學習者計算，無論每位學習者啟動多少次課程。*

**範例：單一學習者，多場課程。** Sarah 將於一月推出五場虛擬教練課程。 她這個月被算作單一獨立用戶，所以不管她練習多少次，都會消耗1個MAU。

**舉例來說：同一位學習者，持續好幾個月。** Sarah 在一月（3 次）和二月（2 次）使用虛擬教練。 每個日曆月份分別計算，因此會消耗2個MAU——1個代表1月，1個代表2月。

**舉例：同一月份有多位學習者。** 每人有100位銷售代表在一月啟動一場線上教練課程。 每個獨立學習者在該月計入一個 MAU，因此總共消耗了 100 個 MAU。

**舉例：團隊練習，持續時間。** 你那 50 人的團隊全年都在使用 Virtual Coach。 在每個月只有5人練習時，該月會消耗5個MAU;如果一個月全部50人都練習，則不會有超過當月回歸學習者消費的額外MAU，因為每個學習者每個月只計算一次，不論他們在該月內練習多少次。

想了解虛擬教練報告，請前往[虛擬教練報告。](/help/migrated/administrators/feature-summary/virtual-coach/virtual-coach-reports.md)
