# 啟用你的帳號成績冊可見性

## 概觀

在作者向課程學習者展示成績簿之前，管理員必須在帳號層級啟用成績簿可見性設定。 此設定如同主開關：關閉時，無論各課程如何配置，學習者都無法看到任何課程的成績本。

## 這個設定控制什麼

**在「設定**」>**一般**&#x200B;中，成績簿可見&#x200B;**&#x200B;**&#x200B;性設定決定作者是否被允許在課程層級向學習者公開成績本。

| 設定狀態 | 影響 |
| --- | --- |
| 啟用 | 作者可透過 **課程編輯器中的「向學習者** 顯示成績簿」選項，控制各課程成績冊的可見性。 學習者在作者啟用的課程中會看到 **成績簿** 標籤。 |
| 失能 | 學習者無法在任何課程中看到成績單。 如果關閉，課程設定將無法向學習者顯示成績單。 |


這表示帳戶層級與課程層級的設定是協同運作的。 兩者都必須啟用，學習者才能看到成績簿。

## 啟用成績簿的可見性

1. 以管理員身份登入 Adobe Learning Manager。
2. 在左側導覽中，選擇 **設定**。
3. 選擇 **將軍**。
4. 請滑到 **成績簿可視** 性區塊。
5. 選擇 **「啟用學習者成績簿檢視** 」勾選框。

   ![](assets/gradebook-admin-1.png)

作者現在可以依課程設定成績冊的可見性。

## 對作者工作流程的影響

啟用此帳戶層級設定後， **課程編輯器中的「向學習** 者顯示成績簿」切換功能即可使用。 作者會使用此切換鍵，根據課程決定學習者是否能看到 **成績簿** 分頁。

當此帳號層級設定被停用時：

* **課程編輯器中「對學習**&#x200B;者的展示成績簿」切換仍可能顯示，但任何課程層級的設定都會被覆蓋。學習者不會看到成績本。
* 成績簿成績和加權計算仍持續在背景執行，方便管理員報告。
* 管理員及自訂管理員仍可下載包含成績簿資料的學習者成績單。

>[!NOTE]
>
>在帳號層級關閉此設定並不會刪除任何成績簿的設定或成績。 如果你重新啟用，所有先前設定的課程等級成績簿設定會立即恢復。

## 兩個設定的互動方式

| 帳戶層級設定 | 課程層級設定 | 學習者所見 |
| --- | --- | --- |
| 啟用 | 向學習者展示成績簿： **開** | **成績簿** 分頁在課程播放器中可見 |
| 啟用 | 向學習者顯示成績簿： **關閉** | 沒有成績簿分頁;成績僅內部計算 |
