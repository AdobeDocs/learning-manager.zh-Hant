# 徽章

徽章是員工完成課程後可獲得的成就指標。 Adobe Learning Manager 引入了最新的電子學習概念之一，稱為 Badges。 全球的專業人士將這些徽章視為特定技能或學習成就的象徵。

你可以定義徽章，作為激勵用戶的動力。

管理者可為學習者創建徽章，具體如下：

1. 以管理員身份登入 Adobe Learning Manager。
2. 在左側窗格選擇 **[!UICONTROL Badges]** 。 會顯示學習者的徽章清單。

   >[!NOTE]
   >
   >預設情況下，會提供少數範例徽章清單。

3. 請在頁面右上角選擇 **[!UICONTROL Add]** 。 **[!UICONTROL Add Badge]** 對話出現。

   ![](assets/add-badge1.png)

   *新增徽章名稱及其圖像*

4. 輸入 **[!UICONTROL Badge Name]**.。 **[!UICONTROL Upload Badge]**&#x200B;點擊並點擊 **[!UICONTROL Save]**。

>[!NOTE]
>
>請聯絡 Adobe Learning Manager 支援團隊 [，learningmanagersupport@adobe.com](mailto:learningmanagersupport@adobe.com) 完成課程或學習路徑後，為學習者新增自訂徽章或證書。
