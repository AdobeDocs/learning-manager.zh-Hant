# Adobe Learning Manager 2026 年 8 月版本的功能可用性

## 目的

企業客戶若透過自己的前端（即「無頭」實作）建置或擴充平台，經常會詢問新功能或變更功能是否能在標準網頁介面之外使用，例如透過學習器 API、管理 API、AEM 小工具或其他整合介面。

本文件對本版本中每個功能提供了簡明且敘述性的解答。 對於每個功能，本文件會標示支援的應用程式表面、整合可用性、遷移支援，以及任何適用的通知行為。

## 各功能可用性

### 元件式電子郵件建構器

這將是針對功能發布後註冊的不同帳號分階段啟用的啟用，將這些帳號從現有的電子郵件編輯器遷移到新的編輯器。 啟用後，客戶無法使用舊的電子郵件編輯器。 （如需功能啟用，請聯繫CSM/支援。）

* **可於：** 管理員應用程式取得。 管理員和作者在此設定電子郵件版面與範本。
* **不適用：** 面向學習者的使用者介面、無頭 API 和 AEM 小工具，因為學習者只需透過自己的郵件客戶端接收產生的電子郵件。
* **通知：**
  * 電子郵件通知持續透過支援的電子郵件客戶端發送給學習者。
  * 此功能不會引入新的平台內通知行為。

### 外部學習

* **可於：** 原生網頁、Headless（學習者）API、原生行動網頁及管理員應用程式上取得。
* **尚未在：** 原生行動應用程式上架。
* **工作 API：** 不適用。
* **遷移：** 尚未支援。
* **通知：**
  * 當外部學習核准申請提交及申請被批准或拒絕時，學習者與管理者會獲得平台內通知。
  * 目前此工作流程無法提供電子郵件通知。

### 增量用戶報告

* **僅提供於：** 工作 API。 提供使用者資料的增量（delta）匯出以供報告。
* **不適用：** 介面、其他 API 表面，以及遷移工具。

### 報表建置器

* **可於：** 管理員應用程式取得。
* **尚未在：** Job API 上架。 未來版本計劃推出基於 Job-API 的匯出。
* **遷移：** 不適用。
* **通知：**
  * 當報告下載準備好或報告產生失敗時，使用者會收到平台內通知。
  * 電子郵件通知不適用。

### 階層式內容資料夾

* **可於：** 管理員應用程式及作者應用程式上取得。
* **遷移：** 支持。
* **工作 API：** 不適用。 目前沒有專用的 API 介面。

>[!NOTE]
>
>自訂角色權限只適用於根目錄/父資料夾層級，並非層級結構中的每個資料夾。

### Insights 代理

* **可於：** 管理員應用程式取得。 目前僅限完整管理員（不包含自訂角色）。
* **管理 API：** 無法使用。
* **工作 API / 遷移：** 不適用。

### 學習路徑代理

* **可於：** 原生網頁及 Headless（學習者）API 上取得。
* **尚未在以下** 平台提供：Native Mobile Web、Native Mobile App 及 AEM Widget。
* **工作 API / 遷移：** 不適用。

### AI 助理（學習者）

* **可於：** 原生網頁、無頭（學習者）API 及原生行動網頁上取得。
* **尚未在以下** 平台提供：原生行動應用程式與 AEM 小工具。
* **工作 API / 遷移：** 不適用。

>[!NOTE]
>
>此功能必須明確啟用，學習者才能看到。

### 直播中心

* **可於：** 原生網頁、Headless（學習者）API、原生行動網頁及管理員應用程式上取得。
* **工作 API：** 不適用。
* **遷移：** 目前不支援。

### 自訂管理員：閱讀/管理其他自訂角色

* **可於：** 管理員應用程式取得。 讓自訂管理員可以查看並管理其他自訂管理員角色。
* **工作 API / 遷移：** 不適用。 目前還沒有專門的 API。

### 成績簿

* **可於：** 原生網頁、無頭（學習者）API、原生行動網頁、原生行動應用程式及管理員應用程式。
* **尚未在 AEM Widget 上** 提供。
* **遷移：** 目前不支援。
* **通知：**
  * 沒有電子郵件通知。
  * 沒有平台內通知。

### 管道

* **可於：** 原生網頁及管理員應用程式上取得。 目前處於測試階段。
* **尚未在以下** 平台提供：Headless（學習者）API、行動網頁、行動應用程式、AEM Widget 及 Admin API。
* **工作 API / 遷移：** 不適用。
