# 基於 AI 的推薦

## 概觀 {#overview}

Adobe Learning Manager 包含一個學習者首頁，內容更現代化，並依照學習者的偏好個人化。 基於 AI 的學習建議旨在提升學習者的參與度，並識別及彌補學習上的缺口。

推薦演算法設計上能吸收多元輸入，包括 Adobe 從合作夥伴處取得的產業資料、職稱與描述。 這些數據接著用來訓練 Adobe 的 AI 演算法，讓 Learning Manager 能夠繪製出一張地圖，將產業相關技能與職稱及/或職稱連結起來。 這成為推薦演算法的一個輸入

Learning Manager 接著使用主題建模演算法分析帳號內的訓練內容，並將其映射到技能上。

Learning Manager 利用同儕活動資料作為另一個訊號，以個人化方式驅動推薦演算法。 這裡會使用註冊、完成及學習者提供的任何明確回饋等活動。

此外，學習經理會利用從個別學習者那裡收集的顯性與隱性資訊，進一步個人化建議。 學習者可透過報名明確指出其興趣領域，學習經理會根據學習者最終接受培訓的方式，隱含地接收這些資訊。

最後，管理員還能利用學習者屬性影響推薦演算法，學習經理在定義同儕群組時應參考這些屬性，並實際標示特定使用者群組的培訓項目。
