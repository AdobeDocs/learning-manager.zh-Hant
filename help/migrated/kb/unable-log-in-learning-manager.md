# 無法登入學習管理員

## 子嗣

嘗試登入 Adobe Learning Manager 時，你會看到以下錯誤：

*在這個帳號中找不到該 adobeid 電子郵件的使用者。 請在登入前將您的 Adobe ID 連結到 Learning Manager 帳號。*

<!--![](assets/prime-error-message.png)-->

## 成因

瀏覽器快取與 Cookie 可能會阻止您存取 Adobe Learning Manager 平台。

## 解決方法

## 清理瀏覽紀錄/快取

以下連結是針對瀏覽器的專屬快取清理指南：

* [Google Chrome](https://support.google.com/accounts/answer/32050?co=GENIE.Platform%3DDesktop&hl=en)
* [Internet Explorer](https://kb.wisc.edu/page.php?id=1514)
* [Microsoft Edge](https://www.bitdefender.com/support/how-to-clear-the-cache-and-cookies%C2%A0in-microsoft-edge-1914.html)
* [Firefox](https://kb.iu.edu/d/ahic)
* [野生動物園](https://oit.colorado.edu/tutorial/clear-web-browser-cache-safari-6)

## 使用無痕模式

在瀏覽器中使用無痕模式，然後登入 Adobe Learning Manager。 請參閱 [說明](https://support.google.com/chrome/answer/95464?co=GENIE.Platform%3DDesktop&hl=en&oco=0)書。

## 聯絡管理員

如果你仍然無法登入，請聯絡該帳號的管理員。 管理員可以驗證你是否是該帳戶中的註冊學習者。

如果你是該帳號的一部分卻仍無法登入，管理員必須確認你的 Adobe ID 是否與你嘗試登入的 ID 相同。

有時候 Adobe ID 和帳戶上的 Adobe Learning Manager ID 會不同。

## 接下來的計畫

完成上述步驟後，若仍無法登入，管理員可收集登入所需的 HAR 日誌。 欲了解更多資訊，請參閱 [產生 HAR 檔案](/help/migrated/kb/generate-har-file.md)。

另外，請聯絡 Adobe Learning Manager 客服團隊，讓我們進一步除錯問題。
