# 故障排除 Salesforce （SFDC） 與 Adobe Learning Manager 的整合問題

## 故障排除SFDC匯出失敗（2–3+小時無法匯出）

若SFDC出口超過2至3小時&#x200B;**未成功**&#x200B;完成，請依下列步驟識別並理解問題。

1. 前往 **Salesforce 首頁** 。
2. 在 **快速搜尋** 框中輸入 **`Bulk Data Load Jobs`** 並打開。
3. 該頁面顯示 **過去 7 天**&#x200B;的大量資料載入工作。
4. 找找跟 **Adobe Learning Manager （ALM） 物件**&#x200B;相關的工作。
5. 點擊你想調查的特定職缺。
6. 請捲動到 **職缺詳情頁面底部** ，查看 **錯誤訊息** 及更多細節。

在許多情況下，根本原因是 **SFDC**&#x200B;中現場層級權限不足。 失敗的田名可能如下：

- `cp_Module_ID`
- 或其他 `cp_...` 與 ALM 自訂物件相關的欄位。

如果錯誤中出現此類欄位，請繼續到下一節。

## 在 SFDC 中授予 ALM 自訂物件欄位的權限

使用 **欄位無障礙** 功能來修正特定欄位的權限問題（例如， `cp_Module_ID`）。

### 步驟

1. 前往 **Salesforce 首頁** 。
2. 在 **快速搜尋** 框中輸入 **`Field Accessibility`** 並打開。
3. 從物件清單中選擇相關的 **報告類型/物件**。
   - 範例： `cp_LearnerTranscript_xxxx_xxxx` 學習者成績單（LT）報告。
4. 在下一頁，選擇&#x200B;**「依欄位檢視」。**
5. 在 **欄位下拉選單**&#x200B;中，選擇出現在匯出錯誤中的欄位
   - 範例： `cp_Module_ID`。
6. 在存取矩陣中，點選&#x200B;**系統管理員**&#x200B;設定檔（以及其他相關設定檔，如有需要）的「隱藏」**項目**。
7. 下一頁：
   - 在適當的地方啟用&#x200B;**「可見」。**
   - 點擊 **頁面底部的儲存** 。
8. 儲存後，你回到場地無障礙檢視。 系統管理員&#x200B;**（以及你更新過的其他設定檔）欄位現在應該會顯示**&#x200B;為「可編輯」。****

## 對所有受影響欄位重複此步驟，並重新嘗試匯出

1. **對每個在 Bulk Data Load Job** 中報告有權限問題&#x200B;**的欄位**，重複&#x200B;**第 2**&#x200B;節的欄位無障礙步驟。
2. 當所有有問題的欄位都獲得適當的可見性與編輯權限後：
   - 回去用 **Adobe Learning Manager**。
   - 在 **SFDC連接器** 配置中，請 **重新嘗試匯出**。


## 重要註解與限制

在設計或排除整合問題時，請牢記這些SFDC–ALM的細節。

### SFDC 中沒有自動建立物件/欄位

- **SFDC 連接器不會在 Salesforce** 中建立新的物件或欄位。
- 如果 **在 ALM** 新增了一個欄位，並且你希望它出現在 SFDC：
  - 在 SFDC 中手動 **建立對應的自訂欄位** 。
  - **將 SFDC 自訂欄位對**&#x200B;應&#x200B;**到連接器配置中的相應 ALM 欄位**。
  - 確保新欄位擁有 **適當的欄位層級權限** （請使用第 2 節）。

### 帶有自訂網域的 ALM 帳號回調網址

- 若 ALM 帳號使用 **自訂網域**，工程團隊必須 **將該自訂網域** 加入 **SFDC 連接器 OAuth 生產應用程式的回調 URL 允許清單** 。
- 這是透過 **Jira向工程部提出的請求** 來完成的。
- 若無此，連接器的 OAuth 流量可能會失效。

### 時區限制（僅限UTC）

- 如果SFDC組織使用 **非UTC**&#x200B;時區， **同步時可能會錯過** 完成度和註冊資料。
- 原因：ALM **目前僅支援 UTC 時區** 進行 SFDC 整合。
- 內部參考：PAPI-24525 被提升以支援額外時區。

### 過濾器資料型別限制（選擇清單與檢查清單）

- ALM 支援匯入 **以 picklist 欄位**&#x200B;建立的 SFDC 濾波器。
- ALM **不支援** 基於檢查清單/多重選擇勾選框欄位的篩選器。
- 原因：ALM **僅支援 SFDC 濾波器的字串資料型別** 。
