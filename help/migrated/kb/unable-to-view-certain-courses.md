# 在建立認證時無法查看某些課程目錄

## 子嗣

在尋找特定課程以加入認證時，無法在課程目錄中查看該課程。

## 入學類型

Learning Manager 有三種註冊類型：

* 自學
* 被提名的經理人
* 經理批准

## 自學

學習者可以直接報名這類課程。

## 經理批准

這些課程必須經經理批准。 學習者可以報名這些課程，但未經經理批准，不會直接註冊此類課程。 當學習者報名這類課程時，會向經理發出通知請求。 經經理核准後，這些課程將被列為已註冊學習者。

## 被提名的經理人

這些課程只能由經理提名。 學習者無法報名這類課程。

## 接下來的計畫

在認證中，你只能新增自選課程，不能新增經理提名或經理核准的課程。

* **永久認證：**  你可以在認證中加入CR或VC課程。
* **定期認證：** 你不能在認證中新增CR或VC課程。

這是 Learning Manager 的預設行為。
