# 經理常見問題

+++經理如何取得課程？

在管理員登入模式下，你無法存取課程。 你需要先登入到學習模式才能上課。

+++

+++我該如何向學習者提供母語回饋？

管理員可根據組織需求啟用或停用適合課程的 L3 回饋功能。 若課程要求經理提供L3回饋，則當學習者完成該課程時，經理會收到通知。

1. 點擊左側窗格的通知。
1. 點選待處理任務標籤。
1. 點擊頁面「提供回饋」分類中的通知，並提供 L3 回饋。

+++

+++當我的團隊完成課程時，我會收到通知嗎？

你可以看到通知圖示標示出待處理訊息數量。 當你的團隊成員註冊或完成課程時，會以通知的形式呈現給你。 當你在彈出選單中點擊「顯示所有通知」時，你可以查看頁面中所有通知和待處理任務。

+++

+++我可以指派多個學習者到課程並匯入學習者嗎？

你只能提名你的團隊成員到課程。 只有管理員能批量分配課程給學習者並匯入一組學習者。

在應用程式左側窗格，點選通知。

1. 會顯示一份詳細的通知清單。
1. 在待處理任務分頁中，選擇你想指派團隊成員的課程，然後點選提名。\
   會顯示課程提名對話框，顯示該課程的可用名額。
1. 在對話框中點擊「提名」。
1. 在每位團隊成員中選擇提名的勾選框，然後點擊完成。\
   申請表頂端會出現一個確認視窗。

+++

+++我可以設定通知學習者嗎？ 怎麼做到的？

當你指派課程給學習者時，他們會透過學習管理員應用程式收到通知。

你組織的管理員負責設定通知。

+++

+++我可以查看特定時期的學習者活動嗎？ 怎麼做到的？

是的。 您可以根據學習者在特定期間內完成課程的狀態建立報告，查看學習者在特定期間內的課程狀態。

你可以點擊下拉選單圖示來修改日期範圍、儲存並查看報告。

+++

+++我可以查看隊員目前的技能水平嗎？

你可以為團隊成員建立報告，查看他們分配並完成的技能清單。 在左側窗格點擊報告，然後點選範例報告標籤，即可查看技能與經理的範例報告。

欲了解更多資訊，請參閱 [學習管理工具中的報告](feature-summary/reports.md) 功能。

+++

+++我該如何查看來自團隊成員的待處理請求？

當你的團隊成員申請課程時，你可以看到通知圖示標示出待處理訊息數量。

要查看待處理的請求，請點擊此通知圖示。

+++

+++我該如何新增或修改報告？

你可以選擇「報告」，然後在頁面右上角點擊「新增」來新增報告。

修改/調整報告大小

要修改報告，請點擊報告右上角的下拉箭頭，然後點選編輯。 在報告中做修改後，點選儲存。

要取消變更，你可以點擊重置。

要調整報表大小，請點擊縮放並選擇兩個選項之一：1×1 表示小型，1×2 表示大型。

欲了解更多資訊，請參閱  [報告功能。](feature-summary/reports.md)

+++

+++我可以看到哪些類型的報告？

您可以查看以下類型的報告：

* 所指派與達成的能力
* 已報名與完成的課程
* 課程的效能
* 已註冊及完成的學習課程
* 每門課程所花費的學習時間
* 每學季學習時間
* 認證報告

你可以查看所有這些報告並附有日期範圍。

+++

+++我可以查看所有可用的課程嗎？ 怎麼做到的？

你可以切換到學習者角色，查看所有可用的課程。 更多資訊請參閱  [課程](../learners/feature-summary/courses.md) 功能

+++

+++我要如何取得經理角色的存取權？

貴公司的管理者會根據您在組織中的資格及職稱，指派您擔任經理。 登入後，你會在 Adobe Learning Manager 看到經理角色首頁。

+++

+++我該如何第一次登入學習管理器？

當你第一次使用 Learning Manager 時，有三個選項：

* 用 Adobe ID 和密碼登入。 如果你沒有 Adobe ID，可以點擊「以 Adobe ID 登入」連結並依照指示建立。
* 如果你還沒在 Adobe Learning Manager 建立帳號，請在登入畫面點擊「建立帳號」來建立你的帳號。

+++

+++我該如何分配課程給我的團隊成員？

經理只有在管理員已尋求該課程經理提名時，才能直接提名該課程的團隊成員。
