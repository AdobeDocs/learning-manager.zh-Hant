+++ 更新 114：Adobe Learning Manager 2026 年 12 月 5 日版本

## 發行重點

2026 年 12 月版本的 Adobe Learning Manager 新增了報告建構器中的圖表與儀表板，與 Adobe Experience Manager 資產整合，並擴充了檔案提交功能，包括團隊提交與評估計畫。 本次版本還新增了課程層級與實例層級電子郵件的電子郵件建構器支援、小考的安全考試瀏覽器整合、學習者助理的模型情境協定（MCP）伺服器，以及無需使用者登入即可控制學習內容的存取。

Live Hub 現支援最多 5,000 名與會者的場次、多語言隱藏字幕及本地化介面。 Live Hub 現已普遍提供給 Ultimate 客戶，而 Channels 則一般對所有客戶開放。

## 本版本的功能

**報告建立器圖表與儀表板：** 管理員現在可以在報告建立器中視覺化報告資料。 從報表欄位建立大型數字圖、折線圖、圓餅圖及樞紐分析表，並在每個圖表中提供彙總與篩選功能。 報告儀表板會儲存由單一報告建立的圖表。 自訂儀表板可整合多個報表的圖表，並支援最多 20 個小工具。 屬於報告的圖表會在您分享報告時共享。 儀表板無法匯出。

[了解更多](/help/migrated/administrators/feature-summary/report-builder-visualization.md)

**報告建立器中的 Insights Agent 報告：** 管理員可以開啟、檢視、編輯並將 Insights Agent 回答儲存為報告建構器報告，然後使用報表建構器功能，例如訂閱。 如果問題的一部分無法用 Report Builder 欄位表達，報告會將該部分列為空白。

[了解更多](/help/migrated/administrators/feature-summary/insights-agent.md#create-report-insights-agent)

**Adobe Experience Manager 資產整合：** 作者可在不離開 Adobe Learning Manager 的情況下，瀏覽並選擇 Experience Manager 資產中核准的學習內容與影像資產。 當數位資產管理器中的資產變更時，更新內容可以流向使用該資產的課程。 作者只會看到他們在 Experience Manager 資產中已擁有存取權的資產。

[了解更多](/help/migrated/integration-admin/feature-summary/aem-assets-integration.md)

**檔案提交功能增強：** 檔案提交模組現支援以下功能：

* **團隊提交：** 講師組成最多 100 人組成的團隊。 每隊提交一份檔案，講師的評估適用於每位成員。 講師在新的 **Teams 管理** 頁面上管理團隊。

  [了解更多](/help/migrated/learners/feature-summary/submit-assignment-as-team.md)

* **評估計畫評量：** 作者定義評估計畫，包含已評分選項的客觀問題與經過書面審查的主觀問題。 評估計畫最多可包含100題。

* **講師核准或自動完成：** 作者可選擇提交是否需講師核准或自動完成。 此設定與評估計畫無關。

[了解更多](/help/migrated/administrators/feature-summary/team-submissions-and-rubrics.md)

**學習者助理模型情境協議伺服器：** 學習者可透過模型情境協議（MCP）伺服器，從他們已使用的工具（如 ChatGPT、Claude 及自訂代理程式）存取 Learning Manager。 管理員會在整合管理員應用程式中設定伺服器。 它提供搜尋、列出報名、取得學習物件、取得使用者資料、回答學習內容問題，以及個人化學習路徑功能。

[了解更多](/help/migrated/integration-admin/feature-summary/configure-alm-mcp-server.md)

**適用於課程與實例的電子郵件建構器：** 完整的電子郵件建構器體驗現已適用於課程層級及實例層級的電子郵件。 管理員定義帳戶版型與範本，作者則自訂課程與實例電子郵件，同時繼承版面配置與格式。 範本會連結到最近的可用版面配置，您可以解除連結以獨立編輯。 **橫幅與簽名設定已從**&#x200B;已移除的「設定&#x200B;**」標籤移至**「全域版面配置&#x200B;**」。** **&#x200B;**&#x200B;如果您的帳戶已啟用電子郵件建構器，您將自動收到這些變更。

[了解更多](/help/migrated/authors/feature-summary/customize-course-instance-emails.md)

**小考的安全考試瀏覽器整合：** 管理員可在帳戶層級啟用整合，並上傳安全考試瀏覽器設定檔（.seb）以定義評量限制。 作者可選擇哪些測驗需要使用安全考試瀏覽器。 嘗試此類測驗的學習者會被提示啟動或下載安全考試瀏覽器。

[了解更多](/help/migrated/administrators/feature-summary/safe-exam-browser.md)

**非登入功能增強功能：** Learning Manager 現在可在不要求使用者登入的情況下，受控地存取學習內容。

* **無需登入即可使用內容：** 管理員可為帳戶開啟或關閉未登入存取權限。 作者可以讓整門課程或特定模組無需登入即可使用。 學習路徑與認證遵循其中課程的設定。 僅支援自學進度的內容。
* **公開目錄：** 管理員可選擇哪些目錄會出現在公共學院中。
* **搜尋引擎與 AI 助理的發現（測試版）：** 公共學院可由搜尋引擎與 AI 助理發現。 每個學院都有自己的網站地圖和robots.txt，Learning Manager 會自動產生 meta 標題、meta 描述和結構化資料。 此功能需要在原生 Adobe Learning Manager 上建立自訂網域。

>[!NOTE]
>
>本專題的文件將很快公開。

**虛擬教練：** Virtual Coach 是一款由 AI 驅動的角色扮演與教練解決方案，讓學習者能練習逼真的職場對話。 它支援九種語言，可以作為獨立的作業輔助工具使用，也可以嵌入課程中。

[了解更多](../authors/feature-summary/virtual-coach/what-virtual-coach-is.md)

**Live Hub：** Live Hub 現已對 Ultimate 客戶開放，Prime 客戶仍處於測試階段。

[了解更多](../administrators/feature-summary/billing-management.md)

**Live Hub** 支援最多 5,000 名與會者：作者新增虛擬教室模組時，現在可選擇最多 5,000 名與會者的容量。 在大型課程中，攝影機存取、螢幕共享及白板功能僅限講師使用。 這些場次不設分組討論室。

[了解更多](../getting-started-with-live-hub/create-a-live-hub-session.md#create-a-course-for-large-session-create-large-session)

**Live Hub** 中的多語言隱藏字幕：講師現在可以在教室設定&#x200B;**中**&#x200B;選擇隱藏字幕語言。所有參與者皆以講師所選語言觀看字幕。

[了解更多](../getting-started-with-live-hub/closed-captions-in-live-hub.md)

**群組報名預約與候補名單管理：** 作者可以將教室與虛擬教室課程中的名額分配給特定使用者群組，為這些群組及所有其他學習者設定獨立的報名開放日期，並啟用自動候補名單升級及截止日期。

[了解更多](../authors/feature-summary/courses.md#configure-enrollment-window-and-seat-allocation-for-a-classroom-course)

**支援多個 Zoom 連線：** 整合管理員可以在單一帳戶中設定多個 Zoom 連線，並將其指派給特定角色或使用者群組。 作者在建立或編輯工作階段時，可從可用的連線中選擇。

[了解更多](../integration-admin/feature-summary/zoom-connector.md)

**通路：** 通路通常對所有客戶開放。

[了解更多](../administrators/feature-summary/create-channels.md)

## 本版本的增強功能

**個人化學習路徑編輯與品牌標籤：** 學習者可一次移除建議主題或課程。 管理員可以透過品牌頁面&#x200B;**重新定位學習者首頁**&#x200B;上的個人化學習路徑條。

[了解更多](/help/migrated/administrators/feature-summary/customize-learner-homepage.md#add-reorder-homepage-strips)

**學習者助理中的學習路徑引用：** 答案現在會引用包含來源課程的學習路徑，並附上課程本身。 從工作輔助工具中擷取的答案包含下載連結。

[了解更多](/help/migrated/learners/feature-summary/learner-ai-assistant.md#learning-path-citations)

**AI 助理配置：** 管理員助理提供兩個代理程式，分別是 Insights 代理與知識代理。 學習助理提供三種代理：知識代理、回應代理與學習路徑代理。 您可以分別設定每個代理程式。

[了解更多](/help/migrated/learners/feature-summary/learner-ai-assistant.md#configure-la-agents)

**重新寄送虛擬教室課程邀請：** 具有課程編輯權限的管理員可從實例頁面重新寄送課程邀請。 此選項適用於當前及未來的場次。

[了解更多](/help/migrated/instructors/feature-summary/resend-session-invite.md)

**從 Adobe Connect 錄影檢視自動出席：** 當學習者播放錯過的虛擬教室錄音時，Learning Manager 會標記出席。 排程整合會將實際檢視時間與帳戶設定的完成條件進行比較。

[了解更多](/help/migrated/integration-admin/feature-summary/track-attendance-through-adobe-connect.md)

**下載的報告建構器報告中的欄位標題變更：** 已下載的報告建立器報告中的預設欄位標題現在會包含資料集名稱。 例如，Learning Object 資料集中的 **Name** 會顯示為 **Learning Object - Name**。 對於彙總欄位，標題也會包含功能，例如 **學習物件數量 - ID**。 在別名&#x200B;**欄位中使用自訂名稱**&#x200B;的標題不會變更。

**合規元件中的多重報名課程：** 合規小工具列出學習者必須完成的所有多選課課程實例。 如果某個實例有截止日期，沒有截止日期的實例會被隱藏。

[了解更多](/help/migrated/learners/feature-summary/multi-enrolled-learner-compliance-widget.md)

**管理員目錄搜尋中的相關性排名：** 管理員檢視中的目錄搜尋會依相關性排序結果。 最先顯示完全匹配的部分匹配，接著是部分匹配。

[了解更多](/help/migrated/administrators/feature-summary/catalogs.md#search-catalogs)

**退休課程而不使學習路徑無法存取：** 已退休課程或巢狀學習路徑會從較高階的學習物件中移除，該物件仍會持續開放以接受新報名。

[了解更多](/help/migrated/administrators/feature-summary/settings/basic-settings.md#retiral-impact-ho-lo)

**Adobe Workfront 的課程取消同步：** 在 Adobe Workfront 取消的課程可透過遷移轉移至 Learning Manager。 移轉會新增一個可選的狀態&#x200B;**欄位，可接受**「啟用&#x200B;**」或**「已取消&#x200B;**」。**

[了解更多](/help/migrated/integration-admin/feature-summary/alm-workfront-cancellation.md)

**名字字元限制：** 名字欄位現在最多可容納 255 個字元，原為 63 個。 此限制適用於介面新增的使用者、透過 CSV 匯入、自我註冊以及外部使用者身分新增的使用者。 現有使用者不會受到影響。 在表格儲存格、下拉清單項目及搜尋結果中，長名稱會被縮短。 將滑鼠移到縮短名稱上即可完整查看。

[了解更多](/help/migrated/deployment-guide/user-setup.md#character-limit-username)

**本地化的 Live Hub 介面與錄製播放器**：Live Hub 現在以 Adobe Learning Manager 所選語言顯示介面，支援相同的 18 種語言。 錄影播放器會根據球場語言進行本地化。

**課程與學習路徑的徽章資訊：** 當作者新增課程或學習路徑時，視窗會列出現有課程與學習路徑，並附有徽章資訊、出版狀態及課程格式。

[了解更多](/help/migrated/authors/feature-summary/create-learning-path.md)

**自我註冊個人檔案的未登入頁面 URL：** 每個自我註冊個人檔案都可以擁有其可分享的未登入選單 URL，內建於 Experience Builder 中。 從該網址選擇 **「註冊」** 的使用者會被加入該網址所屬的個人檔案。

[了解更多](/help/migrated/administrators/feature-summary/experience-builder/non-logged-in-menu-url-self-registration.md)

**Learning Tools 互通性中的自訂學習者屬性：** Learning Manager 透過選用的名稱與角色配置服務端點以及啟動請求讀取自訂學習者屬性。 有些學習系統，例如 Moodle，並不支援這個端點。

[了解更多](/help/migrated/integration-admin/feature-summary/lti-support-for-nrps.md)

**討論區講師通知：** 無頭用戶可透過 API 將討論區活動摘要寄送給講師及班長。

[了解更多](/help/migrated/discussion-board-instructor-notifications.md)

**教師對學習物件實例的 Webhook 編輯：** 學習物件實例修改 webhook 現在也會在講師編輯虛擬教室課程時觸發。

[了解更多](/help/migrated/integration-admin/feature-summary/webhook-instructor-edits.md)

**Learning Path 註冊的最後存取日期：** 您可以透過 API 為 Learning Path 註冊附加自訂的中繼資料，例如最後存取日期。

[了解更多](/help/migrated/api-changes-dec-2026.md#last-access-date-lp-enrollment)

## API 變更

* **書籤 API 排序與已退役內容處理：** 書籤現在會優先回傳最新的，而已退役學習物件的書籤則不再回傳。 不會新增端點、參數或回應屬性。

  [了解更多](/help/migrated/api-changes-dec-2026.md#bookmark-api-ordering-retired-content)

* **討論區講師通知的 API：** 新 API 讓講師與班級經理訂閱討論區，並控制哪些活動出現在摘要郵件中。

  [了解更多](/help/migrated/api-changes-dec-2026.md#api-discussion-board-instructors)

* **在 Learner 應用程式中支援多重註冊實例的 API：** 新增可選 `includeMultiInstanceEnrollments=true` 參數以 `GET /enrollments` 包含多重註冊實例。 預設值為 `false`。

  [了解更多](/help/migrated/api-changes-dec-2026.md#api-multienrolled-instances-lc-widget)

* **Learning Paths 註冊的最後存取日期：** 使用管理權杖在 Learning Path 註冊上設定自訂的中繼資料。 用管理員或學習者憑證閱讀。

  [了解更多](/help/migrated/api-changes-dec-2026.md#api-last-access-date-lp-enrollment)

* **報告建立器匯出的作業 API 工作類型：** 新的 `generateCustomReport` 工作類型會依報告 ID 匯出已儲存的報告建構器報告。 現有的工作類型（包括 `generateQuizReport`）保持不變。

  [了解更多](/help/migrated/api-changes-dec-2026.md#api-job-report-builder-exports)

* **Zoom 連接器的 API：** 新增 API 可擷取並管理 Zoom 連線、儲存 Zoom 認證，並設定可使用連線的使用者群組與自訂角色。 API 採用基於會話的驗證，並需要整合管理員登入。

  [了解更多](../api-changes-dec-2026.md#apis-to-create-and-manage-the-zoom-connector)

## 本版本的重大變更

### 學習者成績單的 Salesforce 連接器匯出工作流程

Salesforce 連接器中學習者成績單（LT）資料表的主鍵已更新，以支援多種註冊情境。 這是一個重大變更，要求 Salesforce 客戶物件中現有的 LT 資料必須在 2026 年 12 月版本中被刷新。 未能清除資料可能導致重複記錄。

### Email Builder 推廣至所有客戶

電子郵件建構器功能於 2026 年 8 月版本中推出，現正逐步推廣至所有客戶。 鼓勵客戶在其沙盒或正式服務帳戶中探索此功能。

>[!NOTE]
>
> 帳戶一旦遷移到新的電子郵件建立編輯器，就無法回復到先前的電子郵件編輯器。 如果您的正式或沙盒帳戶尚未啟用電子郵件建構器，請聯絡您的客戶成功經理（CSM）或 Adobe 支援尋求協助。

### 未登入目錄選擇變更會導致中斷

自 2026 年 12 月 5 日版本起，Adobe Learning Manager 將不再透過 TDA 連接器匯出已停用的目錄。 過去，客戶可以使用停用的目錄來建立未登入的體驗。

此變更影響使用停用目錄進行非登入體驗的客戶。 這些目錄的內容將不再透過 TDA 連接器提供。

**解決**&#x200B;方法：在 2026 年 12 月 5 日版本之前，啟用任何用於未登入體驗的停用目錄，以確保其內容能持續存取。

## 本次版本修正的錯誤

**活動模組影片大小調整：** 當學習者更改網頁瀏覽器視窗大小時，嵌入活動模組中的 Vimeo 或 YouTube 影片並未調整大小。 影片周圍顯示黑色條紋，或是影片控制被隱藏在播放器工具列後方，直到模組重新開啟為止。 學習者現在可以在任何視窗大小下，以完整畫面與控制項檢視活動模組影片。

**SCORM 2004 模組完成狀態：** 通過 SCORM 2004 模組（例如以 Articulate Storyline 撰寫的內容）的學習者，有時會被記錄為通過但未完成。 因此，該課程及相關學習路徑持續處於進行中狀態。 這發生在內容幾乎同時回報已通過與完成狀態時。 課程與學習路徑現在會在學習者完成所有必修模組後轉為「已完成」。

**AEM 元件：** 課程與路徑元件未顯示學習者透過學習路徑註冊的課程，即使啟用顯示所有已報名課程的帳戶設定。 透過學習路徑報名的學習者幾乎沒有或完全沒有看到預期的課程。 學習者現在可以看到他們所報名的所有課程，包括透過學習路徑分配的課程。

**作者：** 在課程、學習路徑、認證及工作輔助工具的總覽頁面中，預設目錄以原始儲存名稱顯示，而非本地化名稱。 這影響了以非英語語言建立的帳號。 例如，「選擇目錄」欄位顯示為「Standaardcatalogus」而非「預設目錄」。 預設目錄名稱會以已登入使用者的語言顯示，與管理員中的目錄頁面一致。

**報告：** 若以包含非英文字元（如日文）的使用者群組名稱進行過濾，結果無法下載並顯示錯誤「無法載入預覽，請重試」。 報表產生現已使用 UTF-8 字元編碼。 對於名稱中含有非英文字元的使用者群組，並設有篩選器的報告現在都能成功下載。

**報告：** 在學員成績單報告中，當報告產生時，課程、學習路徑及認證等級的學分欄位為空白。 無論報告中是否包含模組層級的詳細資料，學分計算均為所有等級正確。

**一般：** 當使用者存取 Adobe Learning Manager 專屬的工作流程與功能（例如社交看板）時，會出現主控台錯誤。 這些工作流程現在可以載入時不會出現主控台錯誤。

**學習路徑：** 在學習路徑的「學習者」頁面上，當選擇子課程或學習路徑時，會顯示「取消報名」選項。 選擇此選項會將學習者的報名從整個學習路徑中移除，而非個別課程。 現在，當選擇子課程或學習路徑時，取消註冊功能會被停用，這與認證的行為一致。

**技能：** 被刪除的技能仍以變更名稱（如「一般刪除）」顯示在學習者訓練卡、目錄及搜尋結果中。 在所有技能顯示給學習者的地方，刪除的技能都會被排除在外。 學習者現在只看到主動技能。

**學習路徑：** 學習者在完成屬於學習路徑的課程後，無法提交第一級回饋表單。 選擇 **「提交」** 似乎沒有任何反應，也沒有顯示任何錯誤訊息。 當課程中啟用回饋，但未啟用學習路徑時，就發生了這種情況。 學習者可依課程層級提交回饋，任何提交失敗都會回報給學習者。

**電子郵件範本：** 在電子郵件範本頁面的「提醒與更新」下，外部學習通知管道有時會以原始本地化金鑰的形式出現，例如「notification.externalLearning：：submissionApproved.name」。 這些管道僅在應用程式內使用，且不會發送電子郵件。僅限應用程式內的管道不再出現在電子郵件範本頁面上。

**出席與評分：** 在批量貼上電子郵件 ID 標記出席時，包含大寫字母的電子郵件會被拒絕，錯誤顯示「在第 line number null 不是有效的使用者電子郵件，無法用來標記出席」，且沒有學習者被標記為已出席。 電子郵件 ID 無論大小寫、多餘空格或重複，都會被匹配。 錯誤訊息現在顯示正確的行號。 使用貼上電子郵件 ID 進行批次標記出席，現在的行為與 CSV 上傳選項相同。

**電子郵件建構器：** 在儲存、預覽或傳送範本時，文字區塊中段落間新增的空白行會被移除。 有意保留空白行。 電子郵件現在會完全按照 Email Builder 中撰寫的段落間距顯示。

**學習者：** 課程的詳細概覽區段中，粗體格式在作者與管理員預覽中可見，但在發佈後在學習者檢視中消失。 粗體文字會以作者身份顯示給學習者，斜體與底線格式則不受影響。

**課程：** 當作者編輯現有模組以支援另一種傳遞類型，例如將模組從虛擬教室改為虛擬教室及教室時，學習者檢視仍會顯示先前的交付類型。 管理員與作者視圖正確顯示為混合模式。 當模組被編輯時，向學習者顯示的傳遞類型會更新。 學習者現在看到的傳遞類型與管理員及作者相同。

**搜尋：** 當套用目錄篩選時，搜尋結果不會包含學習者間接報名的課程，例如透過學習路徑、群組或管理者指派。 儘管課程對學習者開放，搜尋結果卻未回來。 目錄篩選式搜尋現在同時包含直接與間接登記。

**自訂證書：** 當課程、學習路徑或認證被刪除時，其與自訂證書設計範本的關聯並未被移除。 因此，刪除範本失敗時出現錯誤：「無法刪除此憑證，因為它已附加到學習物件或實例」，即使該學習物件已不存在。 當學習物件被刪除時，關聯也會被移除。 管理員現在可以無錯誤地刪除未使用的自訂憑證範本。

**自訂角色：** 已設定自訂角色的使用者在開啟自動產生字幕（VTT）檔案的「檢視字幕」對話框時，收到「載入字幕檔失敗」的錯誤訊息。 下載檔案如預期般運作，且未設定自訂角色的使用者未受影響。 具有自訂角色的使用者可以開啟並檢視自動產生的字幕。

**QR 碼：** 在更新帳戶的自訂學習者 URL 後，為現有課程產生的 QR 碼仍會重新導向先前設定的 URL。 報名、完成及匯出學習者名單的 QR 碼使用目前自訂的學習者 URL。

**行動應用程式：** 即使未達成完成條件，模組在嘗試間仍被鎖定。 當學習者在完成測驗前關閉沉浸式測驗時，就發生了這種情況。 當未達成完成條件時，模組不再被鎖定。 學習者現在可以重新嘗試測驗。

**Live Hub 無障礙功能：** 無障礙改進針對螢幕閱讀器、鍵盤導覽、隱藏字幕、色彩對比以及縮放與重排等問題，提升參與者的可用性。

## 本版本已知問題

**課程概覽頁面顯示多實例課程的錯誤實例詳細資訊**&#x200B;課程概覽頁面可能會顯示較早實例的截止日期、課程數或報名次數，而非目前進行中的實例。

這種情況可能發生在有兩個或以上啟用實例的課程中，且檢視者尚未註冊課程，例如作者以學習者身分預覽課程，或學習者在註冊前瀏覽課程。 因此，學習者可能會看到已過的截止日期，或已結束或取消的課程。 已註冊的學習者會看到自己實例的詳細資訊，且不會受到影響。 未來版本已規劃進行修正。

**課程層級電子郵件範本的變更也可能同時影響帳戶層級範本**&#x200B;在課程層級編輯課程-自我報名電子郵件範本，也可能變更帳戶層級的範本。

這可能發生在課程的電子郵件設定首次由管理員儲存，而其介面語言與帳戶層級範本自訂時的語言不同時發生。 課程層級範本的後續編輯也會套用到帳戶層級範本。 未來版本已規劃進行修正。

**直接報名次數包括學習計畫報名次數**&#x200B;在課程的學習者區段，透過學習計畫註冊的學習者會被計入直接報名人數。 然而，實例卡片上的工具提示將學習計畫註冊列為間接報名。

數量與提示說明不一致。 工具提示將於未來版本更新以符合數量。

**嵌入在 SCORM 內容中的 YouTube 影片在 Chrome 中無法播放**&#x200B;嵌入在 SCORM 內容中的 YouTube 影片，在 Google Chrome 中開啟時，學習者體驗中可能無法播放。

本次版本未包含任何修正，目前正在評估未來版本的相關問題。

**學習者應用程式中的作者頁面不會在高解析度螢幕上載入更多課程**&#x200B;在學習者應用程式的作者頁面上，只有前六門課程會以網格視圖顯示在高解析度螢幕上，且學習者無法載入其他課程。

**從 UI 匯出的第 2 級測驗報告所包含的資料列數少於從 Job API 匯出的報告**&#x200B;當從 UI 匯出第二級測驗報告時，匯出的檔案只包含有限的列數，例如 3,000 位使用者。 透過 Job API 產生的同一報告包含所有資料列。

UI 匯出的列數限制低於 Job API 的列數。 這點將在未來版本中處理。 在此期間，請使用作業 API 匯出完整報告。

**已刪除課程的儀表板與下載的 Excel 報告不同**&#x200B;當課程被退休並刪除時，選擇「顯示當前值資料」的儀表板報告仍會將學習者列為已報名並完成。 從同一儀表板下載的 Excel 報告並未包含學習者的詳細資料。

已刪除課程的儀表板與下載報告不一致。 未來版本已規劃進行修正。

**匯出的教室位置 CSV 中欄位名稱未本地化**&#x200B;當 UI 語系設定為非英文語言時，從教室位置頁面匯出的 CSV 檔案會以英文顯示其欄位名稱（頁首列），而非所選語言。

只有標頭列受到影響;匯出檔案中的底層位置資料則不受影響。 本次版本未包含任何修正，目前正在評估未來版本的相關問題。

**Live Hub 中的字幕品質限制**

Live Hub 的字幕在不同支援語言間的準確度可能有所不同。 字幕品質取決於語言，並可能影響直播時產生文字的準確性。

Adobe Learning Manager 支援多種語言的即時字幕，但 Word 錯誤率（WER）有所不同。 字幕準確度在以下語言間有所不同：

| 錯誤率 | 字幕品質 | 語言 |
|---|---|---|
| 最高可達 5% | 準確度良好 | 英語、西班牙語、日語、德語、義大利語、韓語、葡萄牙語 |
| 高於 5% 或低於 10% | 小錯誤 | 法語、荷蘭語、俄語、土耳其語、中文、瑞典語、芬蘭語 |
| 10% 及以上 | 精度降低 | 挪威語、丹麥語 |

這是目前版本中已知的限制。 未來版本計畫進行改進，以提升支援語言的字幕準確度與品質。

## 本版本已知問題

### 講師無法在模組間加入虛擬教室

講師若嘗試在其分配課程模組預定時間外進入教室，則無法加入虛擬教室。

Adobe Learning Manager 使用單一的虛擬教室教室來管理課程中的所有模組。 當講師啟動教室時，該課程會與該講師連接的模組相關聯網址。 任何後續的加入請求都必須與該房間關聯的活動模組相符。 如果另一位講師在其他模組啟用時嘗試使用不同模組的加入連結加入，存取權限房間被拒絕。 共用房間中一次只能啟用一個模組。

這種行為在目前版本中是預期的。 未來版本計畫推出強化功能，讓課程講師無論使用哪個模組都能加入教室。

### 當麥克風和喇叭在 macOS 上不同時，音訊會斷斷續續

在 macOS 虛擬教室作業中，當選取的麥克風與喇叭是不同裝置時，音訊可能會間歇性斷斷續續或聽起來雜亂。

當音訊輸入與輸出使用不同裝置時，例如麥克風使用AirPods，播放則使用內建喇叭，可能會出現這種行為。 因為每個裝置都會引入自己的音訊延遲，所以回聲消除效果較差，背景噪音抑制有時會將語音部分誤判為噪音。 這可能導致短暫的音訊中斷。 當說話者的聲音會以較低音量錄製，例如當麥克風擺得較遠時。

這是已知的平台限制，並非 Adobe Learning Manager 特有。 類似的行為也在其他會議應用中被觀察到。 本次版本未包含任何修正，目前正在評估未來版本的相關問題。

請同時使用同一個裝置安裝麥克風與喇叭，以避免此現象。

### 在 Chrome 中，共享影片在失去焦點後凍結

當講師分享播放影片的 Chrome 視窗後，然後將焦點從該視窗移開時，與會者可能會看到共享內容凍結或顯示黑屏。

影片會持續在本地為講師播放，但遠端參加者可能無法看到內容更新，因為共用視窗失焦。 行為會因作業系統而異：

- 在 Windows 上，與會者會看到一片黑屏。
- 在 macOS 上，與會者會看到最後顯示的影片影格。

當焦點回到共用瀏覽器視窗時，與會者的影片播放通常會恢復。

這是瀏覽器與作業系統的限制，並非 Adobe Learning Manager 專屬。 此版本沒有針對特定產品的修正。

在呈現影片內容時，保持共用瀏覽器視窗的焦點。 播放時避免切回虛擬教室視窗。

### 講師無法加入已在使用的模組

當講師嘗試同時啟動使用相同虛擬教室的兩個課程模組時，只有第一位講師能成功進入教室。

Adobe Learning Manager 使用單一共享虛擬教室作為課程實例。 當第一位講師加入教室時，該教室會與該講師的模組相關聯。 額外的加入請求包括已針對啟用模組進行驗證。 若其他講師嘗試使用其他模組連結加入，存取將被拒絕。 因此，無法在同一堂內同時進行由講師主導的課程使用共用教室的獨立模組的課程實例。

這種行為在目前版本中是預期的，也與現有的房間架構一致。 此功能正根據客戶回饋進行評估，以進行未來強化。

### 共享內容在返回 Live Hub 視窗後會顯示隧道效果

當講師分享整個螢幕後再返回 Live Hub 視窗時，參與者可能會在共享內容中感受到隧道效應。 當您分享整個螢幕時，共享資訊流會包含桌面上顯示的所有內容。 切換回 Live Hub 視窗可能導致共享內容反覆擷取並顯示 Live Hub 介面，導致意料之外的視覺現象。 這是全螢幕共享的已知限制，目前正評估未來版本的使用。

分享特定的應用程式或視窗，而不是分享整個螢幕。 例如，分享您希望參與者檢視的簡報或文件視窗。 共用單一應用程式可以讓共享內容保持隔離，並防止隧道效應。

### 重新加入已結束的工作階段後，會話儀表板報告不會立即顯示

重新加入結束的工作階段後，會話儀表板報告不會立即顯示如果講師在課程結束後查看課程儀表板，然後使用其 URL 重新加入同一課程，現有的課程儀表板報告可能不再可用。 報告在處理上一次工作階段實例期間，大約需要五到七分鐘才能重新刷新並重新可用。 這是已知的限制，目前正在評估未來版本的使用。

關閉工作階段後請等待五到七分鐘後再重新開啟儀表板 URL。 這會讓上一個工作階段執行個體完成處理，之後工作階段儀表板報告才會再次可用。

### 匯出的教室位置 CSV 中欄位名稱未本地化

當 UI 語系設定為非英文語言時，從教室位置頁面匯出的 CSV 檔案會以英文顯示其欄位名稱（頁首列），而非所選語言。

此行為發生在從管理員設定檔匯出教室位置時>設定>教室位置。 雖然檔案中的位置資料會正確回傳，但欄位標頭並未轉換成符合管理員所選擇的 UI 語系。 因此，在非英語地區工作的管理員，會在本地化環境中看到英文欄位名稱。

只有標頭列受到影響;匯出檔案中的底層位置資料則不受影響。 本次版本未包含任何修正，目前正在評估未來版本的相關問題。

### 信用期間欄位輸入上限為 9999.99

當使用者在工作階段編輯表單輸入大於 9999.99 的信用期間值（例如 999999），儲存時該值會靜默地被限制在 9999.99，且不會顯示驗證錯誤或警告給使用者。 該欄位的 HTML max 屬性設定為 9999.99，可在瀏覽器層級強制執行此上限，且不會通知使用者其輸入被拒絕或修改。 此版本尚未進行任何修正，因為此行為已確認為設計正常運作。

### 錯誤訊息未指出 CSV 上傳中缺少預設語言列

當結構化位置 CSV 上傳僅包含非預設語系的列，例如 fr、de，且帳戶預設語言中沒有列時，回傳的錯誤訊息會顯示 CSV 第 1 列為 Locale，第 2 欄無效或不支援。 這並不表示實際問題是缺少預設語言列。 這可防止使用者上傳多語系 CSV 並僅憑錯誤訊息診斷問題。 這個問題在本版本中已取消，且未進行任何修正。

### 座位限制欄位允許不切實際的數值最高可達 4,294,967,295

教室位置模式中的座位限制欄位接受最高 4,294,967,295（~43 億）的值，此上限技術上由底層資料類型驅動，而非實際的業務限制。 使用者可以輸入並儲存不切實際的座位數，例如 1,000,000,000 個，且不會經過任何業務層級的驗證。
此版本尚未進行任何修正;現實中的業務上限尚未達成共識或執行。

## 修正的錯誤

**電子郵件範本：** 針對已報名課程的學習者，即將到來的課程提醒電子郵件未提供課程日期與時間資訊。 此問題已修正，以正確填入電子郵件範本中的會話排程細節。 學習者現在會收到即將到來的課程提醒電子郵件，內含相關課程日期與時間，提供完整的排課資訊。

**連接器：** 作者在複製或編輯基於連接器的教室/虛擬教室課程時，間歇性遇到 HTTP 400 錯誤。 一旦觸發，問題就會持續存在，並阻止後續課程的建立或編輯操作，直到課程重新刷新。 此問題已修正，以確保基於連接程式的課程能可靠地重複與編輯。 作者現在可以複製、建立及修改教室/虛擬教室課程，而不會遇到重複出現的 400 錯誤。

**CMS API 請求編碼：** 一個自動化平台工作流程會以錯誤編碼的 URL 重複向 CMS HTTP API 產生下載請求，導致間歇性出現 HTTP 500 錯誤，有時每秒出現數千次無效請求。 URL 編碼邏輯已修正，以確保包含特殊字元（如空格）的資產路徑在發送請求前能正確編碼。 下載至 NetStorage 的請求現在能成功執行，消除反覆出現的 API 錯誤與請求激增。

**翻譯工作流程韌性：** 從英語發送至挪威語 Bokmal 的翻譯請求失敗，原因是底層翻譯服務不支援該語言配對，導致整個翻譯工作流程中斷。 翻譯處理邏輯已強化，以優雅管理不支援的語言配對並隔離個別翻譯失敗。 對於不支援語言的翻譯請求現在會被跳過並適當回報，而所有剩餘支援的目標語言的翻譯則持續成功處理。

## 本次版本修正的錯誤

**進階搜尋：** 當目錄存取權缺失時，進階搜尋不會根據使用者註冊來承認 LO 存取。 進階搜尋現已套用與詞彙搜尋相同的基於註冊的存取檢查，允許已註冊使用者在不存取目錄的情況下存取 LO。

**Adobe Experience Manager：** 目錄小工具標題未保留所選目錄，且開啟目錄頁面時顯示所有學習物件，而非篩選後的目錄。 現在點擊目錄小工具標題會開啟目錄頁面，並預先選取對應目錄，且學習對象已正確篩選至該目錄。

**裝置應用程式行動版：** 在行動裝置上，學習者可以完成排序學習路徑第一部分的所有項目，但即使成功完成，第二部分仍未解鎖。 在手機上完成某個章節的所有項目後，有序學習路徑中的下一個章節現在會正確解鎖給學習者。

**LMS 遷移：** 當透過遷移建立的課程實例具有字母數字實例 ID，重新執行遷移以更新 VC 會話時，會建立一個新的會話，而非更新現有會話。 遷移現在會正確更新現有的 VC 會話，適用於以字母數字 ID 為系統的課程實例，而非建立重複的會話。

**課程時長：** 對於 VILT 課程而言，課程等級的時長始終是從預設實例的靜態LO_DURATION中取得，當課程結束且未從實際實例模組重新計算時，課程長度即為 0。 VILT 課程的時長現在反映實際實例模組，而不再僅依賴預設實例的過時或零LO_DURATION值。

**連接器：** 由於 Ember 模組細節控制器在不同模組間重複使用，vcHostingSystem 未能持續更新，導致 VC/F2F 行為混合，且僅基於 vcHostingSystem 錯誤清除 instructorId。 模組處理現在能保持 vcHostingSystem 的一致性，並僅在真正的 VC 課程中清除 instructorId，因此在轉換後的 F2F 課程中，講師也能正確更新。

**LMS 遷移：** 後端未尊重 LearningProgramCourse CSV 欄位的課程順序，因此即使 orderEnforced 為 true，LP 章節的課程順序也被忽略。 為了符合後端行為，並避免透過 CSV 顯示不支援的課程排序，已移除未使用的 CSV 排序欄位。

**效能：** AWS 自動化工作流程反覆向 Akamai CMS HTTP API 發送錯誤編碼的下載請求（包含未編碼的空間），導致 500 次錯誤突發及過多無效流量。 自動化工作流程現在能正確地以 URL 編碼下載網址中的空格，避免無效請求並消除相關的 500 錯誤尖峰。

**報名與退選：** 在某些管理流程中，針對學習計畫、認證及課程的報名流程，報名來源錯誤地被記錄為 SELF_ENROLL 而非 ADMIN_ENROLL。 由管理員驅動的註冊現在會一致地以來源ADMIN_ENROLL儲存在受影響的流程中。

**報名與退選：** 對於重複認證鏈中的門檻註冊，學員即使未完成前一次重複，仍會被登記為較晚的重複。 門檻式報名現遵循重複認證鏈，學習者除非已完成必要的先前重複認證，否則不會被列入後續認證。

**管理員設定：** 管理員無法新增子網域以數字開頭的同儕帳戶，因為驗證規則要求子網域必須以字母開頭。 只要符合允許的字元規則，子網域名稱以數字開頭的同儕帳號現在也被接受。

**課程 – 測驗分數：** 在無頭遊戲啟動時，管理員重置測驗模組後，玩家顯示錯誤的總數為 12 題，而非實際的 3 題。 在無頭啟動時，測驗播放器現在會在模組重置後顯示正確的總題數。

**作者：** 當內容群組從 SCORM 更新到 CAPI 時，報告資訊與完成條件未更新，導致該內容群組沒有完成條件。 將內容群組從 SCORM 更新到 CAPI 現在會正確更新報告資訊，並為該內容群組設定適當的完成條件。

**裝置應用程式行動版：** 在 Captivate Prime 行動應用程式中，透過 target=“_blank” 在新分頁開啟的可下載資源，點擊時無法下載。 在行動應用程式中，現在只要點選可下載資源，即使內容使用 target=“_blank” 連結，也能正確啟動下載。

**富文本編輯器：** 在作者檢視中，豐富文字 LO 描述中的換行在發佈後被移除，儘管學習者仍能看到換行符號。 富文本 LO 描述現在能在作者與學習者視圖中正確保留並顯示換行符號。

## 已知問題/設計上

### Second Nature 資源的版本控制行為

Adobe Learning Manager（ALM）不會在編輯情境中遞增 Second Nature（SN）資源的版本。 此行為反映 ALM 處理 SN 內容更新的方式，而非創作選擇。

Second Nature 在其原始碼系統中不支援版本管理。 當作者在 SN 入口網站更新情境資料時，ALM 資源及其相關學習物件（LO）會自動參照更新後的內容，而不會建立新版本。

相比之下，ALM 支援基於檔案與 LTI 的資源版本控制，作者可替換檔案或更新啟動連結。 由於這些控制項不適用於 SN 整合，因此 ALM 不支援 Second Nature 內容的版本提升。

## 為已完成課程的學習者提供更佳的內容版本控制

### 概觀

當已完成課程的內容模組更新至新版本時，已完成課程的學習者仍在背景接收更新後的模組版本。 這導致他們在嘗試重溫課程時出現意料之外的異常，因為更新的內容並非為他們設計。

### 現有行為

當作者更新課程內容至新版本，並選擇僅套用於尚未開始課程的學習者時，Adobe Learning Manager 仍會為已完成課程的學習者更新模組版本。 因此，這些學習者無法如預期般存取原始內容。

這項強化確保當課程模組更新並設定僅適用於尚未開始課程的學習者時，已完成課程的學習者仍能不中斷地存取原始版本。

## 新功能 {#Newfeatures-2}

### 工作輔助工具

工作輔助工具是一個訓練內容的資料庫，學習者無需註冊或完成條件即可存取。 學習者可以參考這些工作輔助工具，以協助執行組織中的任何活動或任務。 管理員可以追蹤每個工作輔助工具的下載次數。

### 錫罐 API 支援

Adobe Learning Manager 支援 Tin Can API（亦稱為 Experience API 或 xAPI）規格。 你可以上傳並追蹤 Tin Can API 相容的內容，類似追蹤 SCORM 和 AICC 的內容。

欲了解更多資訊，請聯絡 Adobe 支援團隊。

### 航道順序

您可以透過自動指派後續課程或任何學習活動來建立學習路徑。

學習計畫相關事件已更新。 新增了幾個活動。 請參閱學習  [計畫](../learners/feature-summary/learning-programs.md) 以取得更多資訊。

### 備註提醒

如果您在課程中做筆記，Learning Manager 會在 15 天後發送通知提醒您檢視筆記。

### 團體層級的遊戲化

管理員可以透過變更範圍設定來定義遊戲化的範圍。 你可以選擇性地在相似的使用者、群組或地點間啟用遊戲化。 更多資訊請參閱  [遊戲化](../learners/feature-summary/gamification.md) 功能。

### 法語與德語支援

Learning Manager 應用程式提供法語與德語版本。 您可以自訂語言以回應回饋、課程實例及溝通。

Learning Manager 現有功能有顯著的增強。 主要的增強功能如下：

### 匯入 CSV

如果您刪除使用者，就無法再透過單一使用者新增方式將相同使用者重新加入應用程式。 不過，您可以使用 CSV 上傳流程重新加入已刪除的使用者。 CSV 上傳功能中強制欄位限制有重大變更。 [請參閱 CSV](/help/migrated/administrators/feature-summary/add-users-user-groups.md#bulk-upload-internal-users) 常見問題集以取得更多資訊。

### 刪除課程

現在你可以在草稿階段和已退役階段刪除課程。 [請參閱課程](../administrators/feature-summary/courses.md)功能以取得更多資訊。如果學習物件被刪除，其所有報告資料也會一併刪除。 如果課程被刪除且該課程屬於其他學習物件，則會顯示對使用者的適當訊息。

**學習計畫與計畫**

您可以強制執行學習者在學習計畫中修課的順序。 您可以在草稿階段與已退役階段刪除學習程式。 如果學習物件被刪除，其所有報告資料也會一併刪除。

**認證**

您可以在草稿階段與已退役階段刪除認證。 如果學習物件被刪除，其所有報告資料也會一併刪除。

**課程效能評分**

在管理員登入中，您可以匯出任何課程的 L1 和 L3 回饋資料。

**建立包含模組的課程**

你可以強制學習者在開始修課前先完成先修課程。

**使用者通知**

學習者在自行註冊學習計畫時會收到通知。

**教室模組（ILT）**

您可以為過去日期建立教室課程。 此功能讓公司管理員也能將舊課堂課程的資訊輸入學習管理員並產生報告。

**匯出報告**

學習者報告已獲得強化。 您可以在報告中查看名稱、電子郵件、學習物件狀態、註冊條件、註冊日期、完成日期及開始日期。

**新增外部合作夥伴**

將外部學習者註冊至 Learning Manager 帳戶後，若有需要，您也可以縮減學習者人數。 不過，你不能將學習者人數縮減超過已使用的座位數。 作為一個變通方法，你可以先刪除已註冊的學習者，然後再以所需名額重新註冊。
