# Adobe Learning Manager 桌面應用程式的系統需求

## 窗戶 {#windows}

### 著作

* 作業系統：Windows 7、Windows 8.1 及 Windows 10（僅限 64 位元版本）
* 處理器：Intel® CoreTM i5 及以上
* 記憶體：至少 8 GB
* 顯示器：最低解析度 1024 x 768，建議 - 1366 x 768
* 儲存空間：至少 5 GB 可用硬碟空間
* 網路連線

## Mac OS {#macos}

### 著作

* 作業系統：Mac OSX 10.12、10.13、10.14（僅 64 位元版本）
* 處理器：Intel® CoreTM i5 及以上
* 記憶體：至少 8 GB
* 顯示器：最低解析度 1024 x 768，建議 - 1366 x 768
* 儲存空間：至少 5 GB 可用硬碟空間
* 網路連線

## 語言版本 {#languageversions}

此應用程式提供以下語言版本：

* 英語
* 法語
* 德語
* 日語
* 韓語
* 葡萄牙語（巴西語）
* 西班牙語
* 阿拉伯語

## 推薦攝影機與麥克風 {#recommendedcamerasandmicrophones}

* 藍色麥克風（雪人/雪球/雪花）
* 羅技 HD 網路攝影機（930/920/910）
