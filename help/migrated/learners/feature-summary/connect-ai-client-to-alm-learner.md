# 將您的 AI 客戶端連接到 Adobe Learning Manager

您的整合管理員必須先設定連接器。 如果您看不到 Adobe Learning Manager 連接器，請聯絡您的管理員。 **此客戶僅適用於 Adobe Learning Manager Ultimate 層級**。

管理員可參考「 [將 Adobe Learning Manager 新增至您的 AI 用戶端」。](/help/migrated/administrators/feature-summary/add-alm-to-ai-client.md)

1. 開啟您組織的 AI 客戶端，例如 Claude 或 ChatGPT Enterprise。
2. 在連接器清單中找到 Adobe Learning Manager 連接器。
3. 選擇 **「連線**」。
4. 當系統提示時，請以您的企業身份登入。
5. 問一個關於你學習的問題。 如需點子，請參閱 **學習者**&#x200B;範例提示。

>[!NOTE]
>
>你只要簽一次。 您的請求會以您自己的權限執行，因此您只能看到在 Adobe Learning Manager 中能存取的內容。

## 疑難排解

**你找不到連接器**

請您的管理員為您啟用連接器。

**AI 客戶端不記得你之前的問題**

每個請求都視為全新請求。 對話是否持續，取決於你的 AI 客戶端。 在下一個問題中重複細節。

**AI 用戶端不會呼叫 Adobe Learning Manager 連接器**

請在問題中說明你想要的內容，例如報名人數或課程主題。
