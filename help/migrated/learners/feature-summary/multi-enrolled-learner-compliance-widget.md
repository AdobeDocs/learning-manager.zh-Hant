# 學習者合規小工具中的多重報名課程

在 Adobe Learning Manager 中，一位學習者可以同時報名同一課程的多個實例。 學習者合規小工具現在會列出所有有截止日期的註冊實例，讓學習者能看到每個截止日期，而非只看到主要實例。

## 多選課程的變更

在此變更之前，合規小工具僅顯示多選課課程的主要實例。 一位在多個實例中註冊的學習者，在小工具中無法看到其他人的截止日期。

現在，合規小工具會顯示所有符合上述條件的實例：

* 學習者已註冊於該實例中。
* 實例有截止日期。
* 學習者尚未完成該實例。

每個項目都會顯示實例名稱，讓學習者能區分同一課程的實例。 當學習者選取某個項目時，Adobe Learning Manager 會直接開啟該實例。

例如，學習者完成了一門初始培訓課程。 之後，行政人員會為學員報名同一課程的九月、十月及十一月版本，每期都有截止日期。 合規小工具列出了所有三個版本。

小工具會在每個合規類別中分別計算每個實例： **逾期**、 **未來 30 天**&#x200B;內即將截止，以及 **在軌狀態**。

## 出現在合規元件中的實例

下表說明小工具如何處理每種註冊情況。

| 招生狀況 | 顯示於小工具中 | 筆記 |
|--------------------------------------------------|-----------------------------------|---------------------------------------|
| 已註冊，實例有截止日期，但尚未完成 | 是的 | 以實例名稱顯示 |
| 已註冊，實例無截止日期 | 不 | 只有有截止日期的實例才會出現 |
| 實例完成 | 不 | 已完成的實例未被列出 |
| 在所有已註冊的實例中完成 | 不 | 該球場現已不復出現 |
| 一個有截止日期的實例，一個沒有 | 只有有截止日期的實例 |                                       |
| 僅有一個已註冊的實例 | 是的 | 小工具會顯示該實例 |

請參閱 [Learner 應用程式](/help/migrated/api-changes-dec-2026.md#multi-enrolled-compliance-widget) 中多重註冊實例的 API 支援以取得 API 相關資訊。
