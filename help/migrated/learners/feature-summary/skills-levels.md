# 技能與等級

閱讀本文，了解如何作為學習者在學習經理中達成技能。

技能地圖是組織中員工技能組合、知識與特質的集合。 這些技能幫助公司/組織設定或提升員工的績效期望。 技能使員工能將行為與組織期望對齊。

Adobe Learning Manager 讓你能利用技能小工具，根據學習者的技能組合來繪製他們的表現。 當學習者完成部分課程後，可點擊「學習者首頁的技能」來了解自己在各項技能上的表現。

## 查看技能 {#viewskills}

要查看技能，請點擊學習者頁面技能小工具中的任一技能名稱。 技能會顯示並附帶相應的等級。

![](assets/learner-skills1.png)

*查看所有技能*

每個技能的完成率會在小工具上的技能旁邊顯示。 當你點擊每個技能時，應用程式會帶你到技能頁面，在那裡你可以查看你點擊的技能細節。

技能頁面顯示你點擊的技能狀態。 例如，Java。 技能頁面會顯示狀態——例如「進行中」，以及製作名單——例如「2 分（滿分 10 分）」。

從此頁面，您可以點擊每一項技能以查看相應資料。

![](assets/learner-skills2.png)

*查看每個技能*

只有管理員能為學習者創建並分配技能。 學習者會自動被分配到與所選課程/學習計畫相應的技能。

>[!NOTE]
>
>學習者只能在 Classic 學習者應用程式中查看同儕技能。

## 提升技能 {#achieveskill}

學習者在完成指定的課程或學習計畫後，並獲得技能學分，即可獲得技能。 學習者也可以透過自選某項技能的課程並完成來達成技能。
