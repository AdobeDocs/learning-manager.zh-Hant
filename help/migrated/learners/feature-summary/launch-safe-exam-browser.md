# 在安全考試瀏覽器中啟動測驗

安全考試瀏覽器（SEB）是一款安全的瀏覽器，旨在為線上評量提供受控的環境。 Adobe Learning Manager 支援安全考試瀏覽器，適用於需要安全測試環境的測驗。 當您選擇需要安全考試瀏覽器的測驗時，Adobe Learning Manager 會提示您下載或啟動安全考試瀏覽器，才能存取評量。

Safe Exam Browser 提供一個受限的環境來進行測驗。 安全考試瀏覽器啟動後，將限制對其他瀏覽器及應用程式的存取，且所有有效通話會被中斷。

安全考試瀏覽器僅適用於所選測驗，且不影響其他課程模組，例如虛擬教室課程。

本文說明如何下載 Safe Exam Browser、從 Adobe Learning Manager 啟動並進入測驗。

**下載安全考試瀏覽器**

如果您的裝置尚未安裝 Safe Exam Browser，請依照以下步驟下載並安裝：

1. 開啟課程並選擇需要安全考試瀏覽器的自學測驗。
1. 選擇下載 **SEB**。 安全考試瀏覽器下載頁面隨即開啟。

   ![提示提示說明評量僅在安全考試瀏覽器開啟，並有「下載 SEB 與啟動 SEB 」按鈕](assets/download-or-launch-seb-prompt.png "。提示提示「評量僅在安全考試瀏覽器開啟，並有下載 SEB 與啟動 SEB 按鈕」")

1. 下載並安裝適合您裝置的 Safe Exam Browser 版本。
1. 安裝完成後，請返回 Adobe Learning Manager 中的測驗。

## 啟動安全考試瀏覽器

安裝 Safe Exam Browser 後，啟動應用程式以進入測驗。

1. 開啟課程並選擇需要安全考試瀏覽器的自學測驗。
1. 選擇 **「啟動 SEB**」。
1. 在系統提示時允許所需的系統權限。
安全考試瀏覽器會啟動並開啟所選測驗。
1. 請在安全考試瀏覽器中開啟測驗並完成評量。
   >[!NOTE]
   >
   > 當您透過安全考試瀏覽器（SEB）登入 Adobe Learning Manager 時，只能存取您指派且未嘗試、且需要 SEB 的測驗。 你無法存取其他學習內容。
1. 選擇退出 **SEB**。
您會被重新導向為您帳戶設定的頁面。
