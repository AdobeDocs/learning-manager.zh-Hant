# 模型上下文協定伺服器的學習工具

所有功能在學習者連線後，都會以已登入的學習者身份執行。 請求只會回傳該學習者在 Adobe Learning Manager 中能存取的內容。 欲了解更多資訊，請參閱 [「Connect your AI Client](/help/migrated/learners/feature-summary/connect-ai-client-to-alm-learner.md) 」。

## 學習者能力

| **能力** | **學習者能做什麼** | **範例請求** |
|----|----|----|
| 搜尋學習內容 | 尋找課程、認證與學習路徑 | 有哪些領導力課程可供選擇？ |
| 查看報名資料 | 檢查報名人數及應有的學習情況 | 我的哪些課程快到期了？ |
| 提出學習問題 | 從學習內容中獲得答案 | 在 FedRAMP 中，供應鏈風險管理是什麼意思？ |
| 生成學習路徑 | 建立個人化學習路徑 | 幫我找課程，提升專案管理技能。 |
| 儲存學習路徑 | 儲存已產生的學習路徑 | 保存這條學習路徑。 |

## 支援的 MCP 工具

Learner Assistant MCP 伺服器提供以下面向學習者的工具。

| **MCP 工具** | **目的** | **支援功能** |
|----|----|----|
| 搜尋 | 搜尋可用的學習內容 | 搜尋學習內容 |
| 取得報名 | 擷取學習者報名資訊 | 查看報名資料 |
| 接聽專員 | 利用學習內容回答問題 | 提出學習問題 |
| 取得使用者 | 為每個請求識別已登入的學習者 | 所有功能 |
| 取得學習物件 | 擷取學習物件的詳細資訊，例如描述與持續時間 | 搜尋學習內容，查看報名紀錄 |
| 生成學習路徑 | 建立推薦的學習路徑 | 生成學習路徑 |
| 儲存學習路徑 | 儲存已產生的學習路徑 | 儲存學習路徑 |

>[!IMPORTANT]
>
>工具名稱僅供參考，且會依客戶實作而有所不同。
