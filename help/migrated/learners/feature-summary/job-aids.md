# 工作輔助工具

學習如何在 Learning Manager 中查看及使用工作輔助工具。

工作輔助工具是一個培訓內容的資料庫，學習者無需註冊或完成標準即可取得。 學習者可以參考這些工作輔助工具，協助執行組織中的任何活動或任務。

工作輔助工具可獨立使用，或與課程共享一併使用學習管理器。

貴組織的管理員可以為學習者指派工作輔助工具。 在學習者登入時，您可以在首頁的「我的工作輔助工具」小工具中查看工作輔助工具。 如果你有任何工作輔助工具，可以在學習者頁面底部的「我的工作輔助工具」小工具中查看。

## 使用工作輔助工具 {#consumejobaids}

從「我的工作輔助工具」小工具中，點擊工作援助名稱。 工作輔助會以流體玩家的形式開啟，供你使用。 你也可以點擊播放器視窗左下角的下載圖示來下載工作輔助工具。

你也可能找到與課程相關的工作輔助工具。 然而，修讀課程時並非必須完成這些工作輔助資料。
