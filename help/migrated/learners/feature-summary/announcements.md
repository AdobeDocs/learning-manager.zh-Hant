# 公告

公告是管理員向特定使用者廣播的多媒體訊息（文字、圖片或影片）。

管理員可以向學習者廣播公告，告知他們事件或活動的發生。 當公告廣播給特定群組或學習物件使用者時，所有與目標群組相關的學習者都會收到通知。

## 公告通知 {#announcementsnotification}

學習者儀表板上會以高亮標題列的形式顯示通知廣播訊息。 若學習者在公告時未在線，則當學習者登入學習管理員應用程式時，通知會顯示。 學習者也可以透過通知查看舊公告。
