# Adobe Learning Manager 2026 年 12 月版本的新內容

本次 Adobe Learning Manager 版本引入多項新功能與增強，旨在簡化平台並擴展其功能。 這些更新簡化了日常工作流程，改善學習內容的組織與傳遞方式，並使整體體驗更加一致且直覺。

## 報表建構器圖表與儀表板

Adobe Learning Manager 現在支援在報告建工具中提供圖表與儀表板，讓管理員能直接在平台上視覺化報告資料。 管理員可以從報告欄位建立圖表，並在每個圖表中提供彙整與篩選功能。

報告建置器支援以下圖表類型：

* 大數字
* 折線圖
* 條狀圖
* 圓餅圖
* 樞紐分析表

報告儀表板會保存從一份報告建立的圖表。 自訂儀表板結合多個報表的圖表，如註冊與使用者資料，並支援最多 20 個小工具。 屬於報告的圖表會在你分享報告時被共享。 這幫助管理員將最新報告資料集中於一個檢視，而不必重複執行報告。 圖表可顯示最多 10,000 個資料點，樞紐分析表則顯示最多 100 列 100 欄。 如果圖表超過限制，請套用篩選器縮小結果範圍。 儀表板還不能匯出。

## Insights 代理報告在報表建工具中

管理員現在可以繼續在報告建構器中使用 Insights Agent 的答案。 當 Insights Agent 回答問題時，Report Builder 會以平行步驟將同一查詢映射到自己的欄位。 管理員可以開啟、審查、編輯並儲存報告。 接著你可以使用與其他報告相同的報告建構器功能，例如訂閱。

如果問題的部分無法用報告建構器欄位表達，報告會將該部分列為缺口。 如果缺少的部分是問題的核心，報告就不會被提供。 複雜的查詢可能會產生較差的結果，因此在依賴報告前務必先檢視每份報告。

## Adobe Experience Manager 資產整合

Adobe Learning Manager 現已整合至 Adobe Experience Manager 資產，讓作者能直接從集中式資料庫存取並使用核准的學習內容與影像資產。 這消除了管理數位資產管理（DAM）資產的團隊與在 Adobe Learning Manager 中建置課程的團隊之間的手動下載與上傳步驟。

改變了什麼：

* **存取核准資產：** 作者可在 Experience Manager 資產中瀏覽並選擇資產，無需離開 Adobe Learning Manager，因此課程使用最新且核准的檔案，而非可能過時的本地副本。
* **保持課程資產最新：** 當資產在 DAM 中變動時，更新可自動流入課程，保持內容在資產修訂時保持一致。
* **存取權限依照現有權限進行：** 作者只會看到他們在 Experience Manager 資產中已能存取的資產，因此在 Adobe Learning Manager 瀏覽時，權限與 DAM 本身相同。

結果是從資產到學習器有一條單一且受控的路徑，減少手動作業與版本不匹配。

## 檔案提交增強功能

檔案提交模組現在支援團隊提交及評分標準評估。 新設定也決定是否需教師批准提交作品。

### 隊伍提交

講師現在可以為檔案提交建立團隊。 每隊為整個團隊提交一份檔案。 講師會評估一次提交的作品，結果適用於每位成員。 團隊組成方式有兩種：由講師手動建立，或依據每隊成員或團隊數量，在實例開始日前排程建立。

講師在新的 **Teams 管理** 頁面管理團隊，並在團隊提交頁面審查工作。 當需要變更時，例如團隊成員離職，講師也可以撤回已核准的提交，以解鎖團隊成員。 一隊最多可容納100名成員。 學習者可以查看自己的團隊、成員以及評估結果。 團隊模組在課程發布後無法新增或刪除。

### 評分標準評量

作者現在可以為檔案提交模組定義一套稱為評估計畫的評分標準。 評分標準支持客觀題目（有評分選項）及主觀題目（書面複習）。

作者也可以設定以下設定：

* 學習者是否在提交前查看了基於評分標準的評量題目
* 無論是一個整體分數，還是每個標準的分數

每個問題都可以標示為必答，並設定以便審稿人發言。 評分標準評量可容納多達100題，作者需依據每個地點分別輸入題目。 課程發布後，只有題目文本會變動。

### 教練核准或自動完成

作者現在可以選擇提交檔案是否需要講師批准，或是自動完成。 此環境與評估計畫無關。

## Model Context Protocol server for Learner Assistant

ALM 讓學習者能透過模型情境協定（MCP）伺服器，存取他們已使用的工具中的學習。 學習者可從任何地方存取 Learning Manager，包括 ChatGPT、Claude 及自訂代理。 在整合管理應用程式中設定伺服器，讓管理員能存取六項學習者核心工具。 其中包括兩個學習助理工具：Answer Agent 與 Personalized Learning Path。

伺服器提供以下功能：

* 搜尋
* 名單註冊人數
* 取得學習對象
* 取得使用者資料
* 回答學習內容問題
* 取得個人化學習路徑

管理員可以編輯每個工具描述，加入組織專屬的範例。 用戶端會從伺服器的元資料讀取授權細節，因此設定只需要用戶端 ID 和用戶端秘密。

## 個人化學習路徑編輯與品牌條帶

學習者現在可以一次移除建議的主題或課程，此外還有透過聊天細化主題與課程清單的現有選項。

管理員現在可以透過品牌頁面重新定位學習者首頁的個人化學習路徑條。

## 在虛擬教練中練習角色扮演技巧

Adobe Learning Manager 現提供 Virtual Coach，一套由 AI 驅動的角色扮演與教練解決方案，讓學習者在面對工作前能練習真實的職場對話。 例如銷售異議、客戶升級及績效評估。

作者會利用自己的參考資料，利用範本或 AI 助理創造情境，學習者則與即時調整回應的 AI 角色對話。 每次課程結束後，學習者都能即時獲得關於知識與溝通風格的評分與輔導回饋，這些回饋皆依作者所定義的標準進行衡量。

Virtual Coach 支援九種語言，可作為獨立的職業輔助工具使用，或嵌入課程中。

## 學習者助理中的學習路徑引用

學習助理回答現在會引用包含原始課程的學習路徑，以及課程本身。 學習者可從引用中開啟課程概覽或學習路徑頁面。 從工作輔助工具中提取的答案包含下載連結。 這有助於學習者找到能解答他們問題的訓練內容。

## AI 助理配置

管理員助理提供兩個代理：洞察代理與知識代理。 它們可以單獨設定。 學習者助理提供三個代理：知識代理、回答代理與學習路徑代理。 它們可以與目錄設定一同設定。

## 用於教師編輯學習物件實例的 Webhook

學習物件實例修改的 webhook 現在會在講師編輯虛擬教室課程時觸發，除了管理員和作者變更之外。 如課程時間、場地及報名人數限制等變動都會觸發此程序。 無頭客戶可透過公開 API 取得會話細節，並將更新傳遞給學習者。

## 合規小工具中的多重註冊課程

合規小工具現在列出學習者必須完成的每一個多重註冊課程實例。 每個條目都會顯示實例名稱。 如果一個實例有截止日期，任何沒有截止日期的實例都會被隱藏。 公開 API 的註冊端點透過可選參數支援相同行為。

## 重新寄出線上教室邀請函

擁有課程編輯權限的管理員現在可以從實例頁面重新發送會議邀請。 選擇 **重送**，搜尋學習者，然後發送。 此選項適用於目前及未來的虛擬教室課程。 對於多個實例的學習者，邀請只會發送到所選實例。 未註冊課程的學習者會被跳過並警告。

## Adobe Connect 錄影檢視自動參與

Adobe Learning Manager 現在會在學習者播放缺席虛擬教室的錄影時標記出勤。 排程整合會從 Adobe Connect 擷取觀眾資料，並將播放時間與帳號設定的完成標準進行比較。 管理員在整合管理應用程式中設定排程。 Adobe Learning Manager 在判斷出席時僅考慮實際觀看時間，因此跳過錄影不計入完成標準。

## 課程與實例的電子郵件建器

Adobe Learning Manager 中的電子郵件建構器允許管理員與作者建立品牌學習者溝通範本。 在 2026 年 12 月的 Learning Manager 版本中，完整 Email Builder 體驗已提供給課程層級及實例層級的電子郵件。 作者可以自訂這些電子郵件，同時繼承管理員定義的版面與格式。

使用 Email Builder，您可以：

* 建立可重複使用的電子郵件版面
* 應用組織品牌
* 自訂橫幅與簽名
* 定義預設字型與顏色
* 標準化各課程與學習計畫間的溝通

管理員負責建立帳號範圍的電子郵件範本與版面。 作者可以在課程層級和實例層級自訂電子郵件，無需從頭重建範本。

橫幅和簽名設定已經變動。 之前這些設定會出現在另一個設定&#x200B;****&#x200B;標籤中。該分頁已被移除， **橫幅** 和 **簽名** 現在會出現在 **全域版面配置**&#x200B;中。

### 電子郵件建構器階層結構

電子郵件建構器採用階層結構。 每個關卡繼承自其父關卡，並允許本地自訂。

| **關卡** | **它所提供的是什麼** | **誰來客製化它** |
|-------------------|---------------------------------------------------------------------------------------------------------------------|-----------------------|
| 帳號架構 | 品牌、字型、顏色，以及頁首與頁尾結構 | 管理者 |
| 帳號範本 | 全球電子郵件樣式、共通訊息元件與共享品牌 | 管理者 |
| 課程範本 | 課程專屬電子郵件，如報名訊息、課程提醒、完成郵件及課程通知 | 作者 |
| 實例範本 | 最高層級的自訂，例如特定群組、會話特定或區域訊息 | 作者 |

所有課程都可以從帳號範本繼承。 課程電子郵件繼承組織的版面設計，並允許內容自訂。

### 佈局繼承

範本會連結到最近的可用版面。 實例層級範本會連結到實例層級的佈局（若存在）。 如果沒有，範本會連結到最近的父版面配置。 你可以查看版面來自哪一層。

當範本連結到版面時：

* 品牌塑造會自動融入範本。
* 作者只更新內容。
* 這種排版減少了訊息間的重複。

你可以將範本從其版面中解連結。 解除綁定範本後：

* 模板保留現有設計。
* 未來的版面更新不會影響範本。
* 範本變得可以獨立編輯。

版面繼承取決於可用的父版面配置。 當兩者同時存在時，實例層級的電子郵件會覆蓋課程層級的範本。

### 管理員與作者工作流程

管理員使用帳號層級的範本來保持訊息在帳號間的一致性，他們透過建立版面版面和範本來管理，然後發布品牌形象。

作者在需要不同訊息時使用實例層級範本，並透過課程實例管理。

### 電子郵件建置器可用於課程及實例郵件的可用性

如果你的帳號已經啟用了電子郵件建構器，你會自動收到新的變更，不需要做任何操作。 現有的電子郵件功能仍獨立於電子郵件建構器的遷移活動之外運作。

## 學習工具互通性中的自訂學習者屬性

Adobe Learning Manager 現在可以透過學習工具互通性中的可選名稱與角色配置服務端點讀取自訂學習者屬性。 它也會讀取發射請求的訊息。 屬性如國家或城市會儲存在可分組的設定欄位中。 啟動參數需要一個前綴，讓 Adobe Learning Manager 能辨識它們。 有些學習系統，例如 Moodle，並不支援這個端點。

## 討論區 講師通知

無頭用戶現在可以寄送討論區活動摘要給講師和班組經理。 透過 API，你可以將訂閱者加入論壇。 他們會在一封電子郵件中收到新文章、留言和回覆，且時間間隔由你設定。 喜歡和不喜歡的資訊不包含在內。 你是透過 API 開啟這個功能。

## 管理員目錄搜尋中的相關性排名

管理員檢視中的目錄搜尋現在依相關性排序結果，使用與 Learner 相同的搜尋服務，其他地方則是管理員搜尋。 首先會出現精確匹配的，例如帶有特定日期的目錄名稱，接著是部分匹配。 打字時的建議清單順序也一樣。

## Adobe Workfront 的會議取消同步

在 Adobe Workfront 取消的課程會透過遷移流程帶入 Adobe Learning Manager，無需手動步驟。 遷移新增一個可選 **的狀態** 欄位，可接受 **活躍** 或 **取消**。 空白值則會保持會話不變。 透過遷移所做的取消行為，類似於學習管理員介面中的取消。 學習者、講師、管理員、作者和經理都會收到相同的取消郵件。

取消課程有兩種行為：

* 遷移不會對已取消的會話套用詳細變更，並且會回傳該列的驗證錯誤。
* 將狀態設為「活動」會重新啟動會話，接著你可以更新它的細節或再次取消。

會話更新仍維持原有運作。

## 名字字元限制

Adobe Learning Manager 現在可接受最多 255 個字元的名字，從 63 個增加。 這適用於介面新增的使用者、透過 CSV 匯入以及自我註冊，因此來自其他系統的使用者同步不會因長名稱而失敗。

這在從外部系統遷移使用者或自動化建立使用者時特別有幫助。

自 2026 年 12 月版本起，名字欄位最多可容納 255 個字元。 早期版本最多可容納 63 個字元。

>[!NOTE]
>
>這個限制適用於你帳號中的所有用戶，不論他們的角色為何。 現有用戶及其姓名不會受到此變更的影響。

你可以在新增或編輯使用者時，以以下方式輸入長名字：

* 在管理介面新增單一使用者
* 編輯現有使用者
* 匯入 CSV 檔案的使用者
* 透過自助註冊註冊用戶
* 新增外部使用者

長名稱有時會比介面某些部分的空間還寬。 為了保持版面易讀，Adobe Learning Manager 會在以下簡短區域縮短長名稱：

* 表格儲存格
* 下拉清單項目
* 搜尋結果

要查看完整名稱，請將滑鼠移到縮寫名稱上。

## 課程與學習路徑的徽章資訊

當作者新增課程或學習路徑時，會有一個視窗列出現有課程與學習路徑，並附帶徽章資訊。 視窗顯示名稱、類型（課程或學習路徑）、出版狀態及課程格式，如自學、虛擬、教室或混合課程。

## 非登入增強功能

Learning Manager 現在允許用戶無需登入即可受控存取學習內容。 管理員可以指定哪些目錄是公開的，而作者則可以決定哪些課程和模組無需帳號也能使用。 公開內容以可爬取、AI 可讀的頁面形式發布，使學院可透過搜尋引擎及 Claude 和 ChatGPT 等 AI 助理被發現。 匿名使用會被追蹤每位訪客，並與登入使用分開報告。

### 無需登入即可瀏覽內容

造訪您的公共學院的訪客現在可以直接從課程總覽頁面遊玩指定內容，無需帳號、電子郵件或表單。

* **開啟或關閉未登入存取：** 管理員可為整個帳號開啟或關閉未登入內容的消費。
* **無需登入即可提供課程或模組：** 作者可讓整門課程無需登入即可開放，或僅開啟特定模組，例如在進入有門檻的進階內容之前先開啟免費入門模組。
* **從課程繼承設定：** 學習路徑與認證皆遵循課程內的設定，無需額外設定。
* **無需登入即可瀏覽內容：** 未認證的學習者可在不登入帳號的情況下查看可用內容。
* **僅限自我進度內容：** 第三方授權內容及取得的目錄內容，未經登入不得提供。
* **匿名消費報告：** 可產生每月未登入消費報告。
* **啟用跨平台的非登入學習：** 原生 Adobe Learning Manager 在網頁與行動裝置、無頭部署，以及基於 Adobe Experience Manager Sites 的小工具學院中，支援未登入內容的使用。

### 選擇哪些目錄是公開的

管理者現在可以選擇公開學院中出現的特定目錄。 只有這些目錄才能被匿名訪客瀏覽，並被搜尋引擎和 AI 助理索引，因此測試課程或內部內容保持私密。
 
### 在搜尋引擎與 AI 助理中被找到（測試版）

Adobe Learning Manager 現在能讓你的公開學院被 Google 等搜尋引擎以及 ChatGPT 、Claude 和 Gemini 等 AI 助理發現。 你的課程可能會出現在搜尋結果和 AI 生成的答案中，這些答案會歸功於你的學院。

* 帳號層級的控制讓管理員決定爬蟲是否能存取公共學院，以及其內容是否能被索引。
* 每個學院都有自己的網站地圖和robots.txt，這些都是你公開的目錄自動生成的。
* 頁面是預先渲染的，讓不執行 JavaScript 的 AI 助理也能讀取。
* 爬行者只會看到訪客能接觸到的東西。 封閉內容永遠不會被揭露。
* Meta 標題、描述與結構化資料：Adobe Learning Manager 會根據學習元資料自動為每門課程、學習路徑及認證產生這些資料。

>[!NOTE]
>
>原生 Adobe Learning Manager 上的 AI 與搜尋發現需要自訂網域。 無頭部署則需要在自己的環境中實作部分設定。

## 非登入頁面網址，用於自助註冊個人檔案

自助註冊設定檔讓外部使用者，例如合作夥伴或多個組織成員，建立自己的 Adobe Learning Manager 帳號。 每個個人檔案現在都可以擁有自己可分享的非登入選單網址，內建於體驗建器中。

當使用者從該網址進入的頁面選擇 **「註冊」** 時，他們會被加入該網址所屬的個人檔案。 這讓來自不同組織的使用者，例如不同的代理商或合作夥伴，保持在不同的個人檔案中。

## 儲存學習路徑註冊的最後存取日期

Adobe Learning Manager 現在允許你將自訂的元資料（如最後存取日期）附加到學習路徑的註冊資料中。 你透過 API 設定並閱讀，這有助於你追蹤對分配的學習路徑的限時存取權限。

課程報名已透過 API 支援最後存取日期，該 API 控制學習者可存取課程的時間長度。 Learning Path 註冊現在提供通用的元資料欄位，讓你可以儲存最後存取日期或其他想追蹤的值。

## 用工作 API 匯出報告建構器報表

此版本的 Adobe Learning Manager 新增了一個新的工作 API 工作類型。 `generateCustomReport`傳送報表 ID 後，會自動匯出你在報表建器中建立的任何報表。

結合報告建構器中的新 L2 測驗資料集，你現在可以：

* 將跨多個課程和模組的題型（L2）測驗資料匯出於單一報告，而非每門課只執行 `generateQuizReport` 一次。
* 自動化定期匯出，例如每日逐步匯出至資料倉儲或商業智慧工具。

現有的工作類型，包括 `generateQuizReport`，保持不變。

## 已下載報告中的欄目變更

報表建構器現在會在下載報告的預設欄位標題中包含資料集名稱，因此學習物件資料集中的名稱會顯示為 **學習物件 - 名稱** ，而非 **名稱**。 對於彙總欄位，標題也會包含功能，例如 **學習物件計數 - ID**。 如果你在欄位的 **別名** 欄位輸入自訂名稱，該別名會被用作標題，且不會改變。

升級後，沒有自訂別名的現有報告會顯示更新的標題，而報告資料、篩選器和排程則則不受影響。 如果你的腳本、試算表、商業智慧儀表板或整合系統以標題參考欄位，請更新為新名稱，或設定自訂別名以維持特定標題。

這讓組織能在同一平台上舉辦大型培訓課程，並設定一個可設定預期聽眾規模的教室。

## Safe Exam 瀏覽器整合測驗

當學習者嘗試使用安全考試瀏覽器的小測驗時，系統會提示他們啟動瀏覽器。 此系統會依照管理員定義的限制，在評估期間封鎖對其他瀏覽器及應用程式的存取。 未安裝的學習者會被提示下載。

**它有幫助的地方：**

* **認證評量：** 在限制外部資源取得時，進行小測驗。
* **合規訓練：** 支援針對強制性訓練及法規要求進行受控評估。
* **高風險評估：** 減少在重要評估期間存取未經授權應用程式或資源的機會。
* **彈性評量管理：** 允許作者僅在需要額外限制的小考時啟用安全考試瀏覽器。

## Adobe Learning Manager 2026 年 12 月版本的 API 變更

### 書籤 API 排序與內容處理已退休

學習者可以將培訓加入書籤，方便日後重溫。 過去，書籤 API 會無特定順序回傳已儲存的訓練，避免無頭整合先顯示最近儲存的訓練。 已退休學習物件的書籤也會留在清單中，導致「頁面未找到」錯誤。

這次更新修正了以下問題：

* 書籤現在會優先歸還最新內容。
* 已退休學習物件的書籤不再被退還。

不會新增端點、參數或回應屬性，因此現有的整合能持續運作，無需更改。

### 討論區教師通知的 API

本版本包含支援討論區講師通知的新 API。 利用它們訂閱講師和班組經理討論區，並控制哪些活動會出現在他們的摘要郵件中。

### Learner 應用程式中多重註冊實例的 API 支援

註冊 API 現在支援 Learner 應用程式中的多重註冊實例。 新增可選 `includeMultiInstanceEnrollments=true` 參數來 `GET /enrollments` 包含這些元素。 預設是 `false`，因此現有的整合，包括無頭實作，都能保持不變。

### 學習路徑報名最後存取日期

你現在可以在學習路徑註冊中儲存自訂元資料，例如最後存取日期，並透過 API 設定與讀取。 這有助於你追蹤分配的學習路徑的時限存取權限。

* 在現有註冊或註冊學習者時，使用管理員令牌設定元資料。
* 用管理員或學習者代幣閱讀。

這些元資料是用來自己追蹤的。 它不控制存取權限，也不會套用到路徑中的課程。

### 報告建構器匯出的 Job API 工作類型

Job API 新增了一個工作類型，該 `generateCustomReport`類型會在你傳遞報告 ID 時匯出任何儲存的報告建構器報告。 透過新的 L2 測驗資料集，你可以將跨多門課的題目級測驗資料匯出到一份報告中，並自動化重複導出。

現有的工作類型，包括 `generateQuizReport`，保持不變。

### Zoom 連接器的 API

使用這些 API 在 Adobe Learning Manager 中查看和管理 Zoom 連接器。 利用它們來取得現有的 Zoom 連線、儲存 Zoom 憑證、建立或更新連線，以及管理使用者群組和自訂角色的存取權限。

**API 序列**

依照以下順序使用 API：

| **步進** | **API** | **目的** | **認證** |
|------------------------------------|---------------------------------------------------------------|---------------------------------------------------------------------------------------------|-----------------------------------------------------|
| 1 | `POST /ctr/authcred/uuid/20012    ` | 儲存 Zoom 的登入資料。 | 整合管理會議 |
| 2 | `POST /ctr/app/esconnect  ` | 建立 Zoom 連線或更新現有連線。 | 整合管理會議 |
| 3 | `PUT /ctr/xtsa/{connectionId}/access` | 設定使用者群組和自訂角色，讓它們能使用該連線。 | 整合管理會議 |

**認證與權限**

這些 API 採用基於會話的認證，並要求使用者以 Adobe Learning Manager 的整合管理員身份登入。
