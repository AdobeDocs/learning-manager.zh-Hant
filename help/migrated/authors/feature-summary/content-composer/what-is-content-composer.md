# 什麼是 Adobe Learning Manager 內容撰寫器

Adobe Learning Manager 內容撰寫器將課程創建的每個階段整合成一個由 AI 導向的單一工作流程。 你描述你想教什麼，產品會根據你的輸入產生結構化的大綱和完整課程內容，包括圖片、知識檢查和分級小考。

Content Composer 將學習創作的每個階段整合成單一工作流程，並支援與理解教學設計的 AI 共同創作，幫助你創造不僅更快完成，且設計上更有效率的學習。

當你的課程準備好後，你可以：

- 直接將課程發佈到 Adobe Learning Manager，透過全面的學習者分析獲得可行的學習成效洞察。
- 下載它作為 SCORM 套件，可用於任何相容的 LMS。
