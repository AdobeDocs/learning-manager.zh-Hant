# Adobe Learning Manager 內容撰寫者不是什麼

在開始前設定準確的期望：

- Content Composer 不支援分支或自適應學習路徑。 課程遵循線性課程主題>架構。

- 目前測試版中，課末測驗僅支援多項選擇題和是非題。 其他題型已在路線圖中。

## 接下來的計畫

當您準備好開始時，請參閱 [「使用 Content Composer](#create-course) 建立課程」以獲得完整的逐步工作流程。

**試試看這個應用程式**。 打開 [**內容撰寫器**](https://contentcomposer.adobe.io/) ，並依照步驟指南操作。

如果遇到問題，請聯絡客服或在 [Adobe Learning Manager 社群](https://community.adobe.com/adobe-learning-manager-466)中提出你的疑問。
