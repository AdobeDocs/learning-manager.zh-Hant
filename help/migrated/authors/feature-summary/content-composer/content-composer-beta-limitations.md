# Adobe Learning Manager 內容作曲者測試版限制

目前 Content Composer 測試版限制的完整清單，並附有描述與解決方法（如有）。

## 電流限制

下表涵蓋目前測試版中所有已知的限制條件。

| **限制** | **描述** | **解決方法** |
|---------------------------------------------------------------|-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|---------------------------------------------------------------------------------------------------------------------------------------------------------------|
| **大綱編輯僅以對話方式進行** | 你無法在畫布上選擇課程或主題來重新命名、重新排序或刪除它。 所有大綱修改必須透過助理聊天面板進行。 | 問助理：「將第二課改名為『密碼衛生』」或「將主題 1.3 移到第二課。」 |
| **大綱階層是固定的** | 課程結構固定為課程>主題。 你無法建立子主題、額外的階層層級或自訂結構。 | 利用現有的組件來增加主題的深度。 |
| **大綱在課程生成後不能直接編輯** | 一旦課程產生，主題名稱和課程名稱仍會保留在大綱結構中。 你必須回到大綱層級的對話來改變它們。 你無法透過在課程編輯器中選擇標題來重新命名它們。 | 問課程編輯器的助理：「把第三課改名為『事件回應』。」 |
| **評量類型：僅選題與真/錯** | 目前的測試版僅支援選擇題（**MCQ**）和是非題。 其他評量類型則無法提供。 | - |
| **題庫無法提供** | 你無法匯入或管理一組預先寫好的題庫。 | 用對話方式設計額外問題：「第一課的小考再加兩題。」 |
| **知識檢定不會被評分** | 課堂中嵌入的知識檢定不會被評分。 只有課後小考評量會被評分並記錄。 | 任何必須完成或完成分數的評量，請使用小測驗（而非知識檢查）。 |
| **對話動作僅限於支援的功能** | 助理可以自由討論和腦力激盪，但實際的課程修改僅限於產品支援的功能。 要求產生不受支持的內容結構或格式可能無法成功。 | 如果請求無法運作，請助理說明它能做什麼。 |
| **文件限制產生** | 當 **啟用「限制輸出至檔案** 內容」時，Content Composer 僅從上傳的原始文件產生內容。 它不會引入超出這些來源的資訊。 | 關閉開關，讓 AI 補充一般知識。 |
| **協作功能正在演進** | 「分享以供審查與評論」以及「分享給學習者」都正在積極開發中。 實作細節可能會在正式上市前有所變動。 | 請使用 **複製連結** 分享預覽連結，方便非正式審閱。 在共同編輯方面，可以與合作者協調輪流。 不支援同時共同編輯。 |
| **產品內助理不是產品輔助系統** | 對話式助理專為課程編輯任務設計，例如產生和修改內容。 對產品使用問題的回應可能不可靠，因為此行為尚未明確設計。 | 關於操作相關問題，請使用現有的說明文件，而非直接詢問產品內的助理。 |
