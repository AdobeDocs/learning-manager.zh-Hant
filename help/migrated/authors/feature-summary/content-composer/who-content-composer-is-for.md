# Adobe Learning Manager 內容撰寫者適合誰

Adobe Learning Manager 內容撰寫器專為需要從零開始製作結構化課程的人設計。

| **角色** | **內容撰寫者如何協助** |
|-----------------------|--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| **作者** | 打造有結構且有效的課程。 無論是將自己的知識轉化為課程、從現有文件與原始資料中學習，或是精煉 AI 生成的內容以達成特定學習目標。 |
| **L&amp;D 管理員** | 提供存取權限、設定組織主題，並將完成的課程發佈至 Adobe Learning Manager。 |
| **學習與發展經理** | 在課程分發給學習者前，審核並核准。 |
