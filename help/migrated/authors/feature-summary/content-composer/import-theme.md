# 匯入主題

匯入自訂的 JSON 檔案，在 Content Composer 中套用你的變更作為新主題。

1. 從工具列選擇 **主題** 。

2. 從課程主題選項中選擇&#x200B;**匯入**&#x200B;**。**
   ![](../assets/48_course_themes_import_button_updated.png)

3. 從你的電腦選擇自訂的 JSON 檔案。

4. 選擇 **「另存為新」** 以建立新的自訂主題。

## 主題 JSON 結構概述

主題 JSON 檔案有五個主要區域：

| 章節 | 操作 |
|----------------------------------------------------------------------|-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| 元資料（ID、姓名、版本、描述、作者、來源、isDefault） | 主題識別與展示資訊 |
| foundation.palette | 主題中透過 var（--tokenName） 參考的 7 個核心顏色標記（前景、背景、強調、背景Subtle、次要、textPrimary、textInverse） |
| foundation.fonts | 標題與正文字型堆疊 |
| 基礎.間距與基礎.半徑 | 水平/垂直間距比例與角半徑標記 |
| 元素 | 每個文字角色（課程標題、主題標題、區塊標題、副標題、問題、說明、段落、buttonLabel）及每個元件（段落區塊、imageBlock、videoBlock、imageGrid、手風琴、旋轉木馬、翻轉卡、分頁、時間軸、評估）的排版與結構樣式） |

由於大多數值使用 var（--tokenName） 來參考調色盤標記，更新單一標記（如 accent）會自動連鎖變化，影響參考該元素的每個元素。 你不需要去尋找單一的色彩值。
