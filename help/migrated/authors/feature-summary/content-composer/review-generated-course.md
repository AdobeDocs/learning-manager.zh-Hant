# 檢視已生成的課程

![](../assets/11_course_view_generated_topic_content_updated.png)

Adobe Learning Manager 內容撰寫者能一次性生成完整課程，包含文字、圖片、知識檢查及小考。 **生成完成後，賽道**&#x200B;編輯器會自動開啟。

左側面板顯示課程與主題導覽。 畫布顯示所選主題的內容。 聊天面板仍開放，供對話編輯。

>[!CAUTION]
>
>在分享或發布前，請先審查所有產生的內容。 AI 輸出在不同世代之間可能有所不同，且可能包含不準確之處。 發行前必須先進行作者審查。
