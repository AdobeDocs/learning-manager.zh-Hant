# 套用主題

課程主題控制字型、顏色、標題、頁腳及組件樣式，涵蓋整個課程。

在你的球場上套用主題，無需任何客製化，打造快速、精緻且一致的視覺效果。

1. 從工具列選擇 **主題** 。 **課程主題**&#x200B;面板會打開，顯示所有可用主題。
   ![](../assets/34_course_themes_panel_open_updated.png)

2. 瀏覽可用主題：

   1. **預設：** 顯示 Content Composer 內建的主題。

   2. **自訂：** 顯示你已建立並儲存的主題。

   3. 使用 **搜尋** 欄依名稱找到主題。

3. 選擇一個主題來套用它。 課程預覽會自動更新。
