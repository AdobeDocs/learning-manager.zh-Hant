# 管理並回應留言

如果你是作者，可以使用 **專案中的留言** 面板查看並回覆留言。

1. 從頂端工具列選擇 **「留言** 」。 ****&#x200B;評論欄會打開，顯示所有評論者的留言。

   ![](../assets/63_owner_in_app_comments_panel_mention_comment.png)

2. 選擇任何留言，即可在畫布上查看上下文。

   ![](../assets/64_comment_in_context_on_canvas.png)

3. 選擇勾選勾選圖示以標記留言為已解決，或選擇 **「更多選項** 」圖示以編輯或刪除留言。

   ![](../assets/65_comment_resolve_checkmark_delete_menu.png)

4. 儲存更新後的課程。

5. 選擇 **分享** 以更新評論連結，讓評論者能看到最新版本。
