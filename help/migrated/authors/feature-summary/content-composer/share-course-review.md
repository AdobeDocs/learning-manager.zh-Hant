# 分享課程以供複習

1. 選擇 **以進行審查**。

2. 請在「新增姓名或電子郵件」欄位輸入審稿人的姓名或電子郵件地址。

3. 請檢視「 **誰有權限** 」部分，確認只有受邀者才能進入專案。

4. 選擇 **邀請留言** 或 **複製連結** 與您的評論者分享。
