# 複習共用課程

當專案被分享供審查時，你可以在分享給你的連結下添加評論。

1. 打開你分享的評論連結。

2. 在 **右側的留言** 面板，加入你的留言並選擇 **提交**。

你可以在 **留言** 面板中執行以下操作：

* 新增、編輯、刪除、回覆及解決留言。
* 查看其他評論者的評論。
* 用 **@** 來提及專案負責人或其他審核者（只有在你用Adobe ID登入時）。
* 在留言中加入表情符號。
* 請依&#x200B;**審核者**、**時間****及已解決**&#x200B;狀態篩選留言。
