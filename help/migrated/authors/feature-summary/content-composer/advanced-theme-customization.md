# 內容作曲家中的進階主題自訂

## 在應用程式中自訂進階主題屬性

使用進階主題屬性來更細緻地控制個別元素，例如課程名稱、主題名稱、區塊標題、副標題、說明文字和段落。

1. 選擇 **主題**，將滑鼠移到套用主題上，選擇 **編輯**，然後選擇 **進階**。
   ![編輯主題面板中的進階按鈕](../assets/41_edit_theme_advanced_button_updated.png)

2. 在字型屬性面板中，設定 **課程的字型配對** ：

   - 選擇&#x200B;****&#x200B;標題下拉選單，並為所有標題選擇字型。

   - 選擇 **「正文** 」下拉選單，並選擇正文字型。
     ![進階主題屬性的字型屬性標籤，顯示字型配對選項](../assets/42_advanced_theme_properties_font_pairing_updated.png)

3. 設定元素清單： **課程名稱**、 **主題名稱**、 **區塊標題**、 **副標題**、 **說明文字**&#x200B;與 **段落;** 選擇你想自訂的元素。

4. 在 [!UICONTROL Visual properties] 面板中，你可以調整賽道的佈局和間距。

   - 利用內容密度選項設定元素間距。

   - 要設定 **卡片/圖片角落半徑**，拖曳滑桿或輸入數值來設定卡片和圖片的圓度。 例如，將半徑設為 17 px。

   - 選擇 **課程** 以更改課程的背景色或圖片。

   - 選擇 **主題** 以設定主題的背景色或邊框。

   - 選擇 **頁首/頁尾** 以設定頁首和屬性。

   Content Composer 會在你修改時自動預覽畫布中的變更。

5. 對於所選元素，請依需求自訂其屬性：

   - 選擇 **字型，**&#x200B;例如大寫字母。

   - 用 + 和 - 控制鍵設定&#x200B;**字型大小**。********

   - 選擇字 **體顏色**。

   - 請使用格式，例如 **粗體**、 *斜體*、 <u>底線</u>或 ~~刪除線~~。

   - 設定 **文字對齊**。

6. 在右側畫布預覽你的變更。 使用 **「目前課程** 」和 **「測驗課程** 」分頁，查看你的變更在不同課程中的表現。
   ![進階主題屬性中的測試課程預覽](../assets/43_advanced_theme_test_lesson_preview_updated.png)

7. 選擇&#x200B;**另存為新或****另存**。
