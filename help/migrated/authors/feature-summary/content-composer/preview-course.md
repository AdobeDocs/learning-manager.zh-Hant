# 預覽賽道

![](../assets/19_preview_mode_timeline_block_updated.png)

- 在上方工具列選擇 **預覽** 。 課程的呈現與學習者實際看到的完全相同，包含應用主題、互動元素，以及以答題模式進行測驗。

- 使用 **「下一** 頁」和 **「上一**&#x200B;頁」導航，或在左側的課程面板中選擇任一主題。 在右上角選擇 **「退出預覽** 」以返回編輯。
