# 編輯課程大綱

![](../assets/10_outline_tab_generated_lessons_topics_updated.png)

Adobe Learning Manager 內容撰寫器會從你的簡報和原始檔案產生課程內容和主題結構。 大綱會出現在畫布上，顯示所有課程及其主題。

**注意：** 在測試版中，大綱編輯目前是對話式。 你無法在畫布上選擇課程或主題來重新命名或重新排序。 請在聊天面板中以純語言方式輸入變更請求。

助理則以對話的方式工作。 你可以用自己的話來表達請求。 以下是你可以做的一些例子：

| **行動** | **範例請求** |
|--------------------------|---------------------------------------------------------------------------|
| 重新命名課程或主題 | 「將第一課更名為『釣魚如何運作』」 |
| 新增課程或主題 | 「在第二課新增一個關於 QR 碼釣魚的主題」 |
| 刪除課程或主題 | 「移除主題 1.3」 |
| 分著上課 | 「把第三課分成兩堂。 一個是垃圾郵件過濾器，一個是補丁管理。」 |
| 合併課程 | 「將第三與第四課合併為一課」 |
| 重新生成大綱 | 「重生，更注重密碼衛生」 |

在聊天面板中使用簡明語言請求來修改課程、主題或完整大綱結構。

大綱階層固定為課程>主題。 你無法建立子主題或三層結構。

當輪廓看起來正確時，在上方工具列選擇 **「產生課程** 」。
