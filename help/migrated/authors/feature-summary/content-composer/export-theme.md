# 匯出主題

將主題匯出為 JSON 檔案，以便在 Content Composer 外自訂或與其他作者分享。

1. 從工具列選擇 **主題** 以開啟 **課程主題** 面板。

2. 將滑鼠移到你想匯出的主題上，然後選擇 **匯出** 圖示。
   ![](../assets/47_export_theme_save_as_json_dialog_updated.png)

3. 在跳出的對話框中，選擇一個地點，輸入 **檔案名稱。**
