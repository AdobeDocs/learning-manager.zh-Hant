# 檢視並新增課程評論

如果你是課程創作者，請在專案中選擇 **「留言** 」面板查看留言並回覆。

1. **打開留言面板**：從工具列選擇 **留言** 。 評論面板顯示評論者提供的評論。

2. 你可以將留言標記為已解決，或編輯或刪除留言。

3. 做必要的修改後 **儲存** 專案。

4. 從工具列選擇 **分享** 以更新最新連結。
