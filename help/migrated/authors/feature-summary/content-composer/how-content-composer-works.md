# 內容編輯器的運作方式

內容撰寫器負責撰寫。 Adobe Learning Manager 負責配送、註冊、追蹤與報告。 理解這種分離後，就解釋了為什麼發佈到 ALM 不需要像匯出到第三方 LMS 那樣手動重新上傳 SCORM。

| **內容撰寫者控制** | **Adobe Learning Manager 控制項** |
|-------------------------------------------------------------------------|----------------------------------------------------------|
| 課程與主題結構 | 學習者註冊與入學 |
| 課程內容 - 文字、圖片、影片、組件與知識檢查 | 模組元資料 - 持續時間、標籤、唯一 ID 與到期日 |
| 課後小考，包括題型與答案 | 課程組合與版本管理 |
| 視覺主題、完成標準與成功標準 | 學習者追蹤、報告與成績單 |

Adobe Learning Manager 內容撰寫器依序經歷四個階段：

- **主畫面：** 寫一個提示，用淺顯的語言描述課程內容。 AI 會閱讀你的提示並預先填寫課程簡報。

- **簡要說明：** 你確認以下欄位：

  - 課程名稱

  - 學習者概況

  - 學習目標

在這個階段，你可以上傳檔案讓 AI 繪製，並選擇是否只限制生成內容只能使用這些檔案。 這些輸入會影響 AI 後續產生的一切。

- **大綱：** AI 提出一堂課和一個主題，並以客觀結構呈現。 你可以透過聊天面板查看並申請修改。

當大綱正確時，你就能生成完整的課程。

- **課程：** AI 生成完整的課程，並組織成三層級階層：

  - **課程：** 課程的主要部分，每節涵蓋科目的不同部分

  - **主題：** 每堂課內的各個單元，每個單元聚焦於單一概念或技能

  - **區塊：** 構成每個主題的內容元素：文字、圖片、影片、互動元件如翻頁卡片、手風琴、時間軸，以及內嵌知識檢查

每堂課結束時會加入一個分級測驗。

**注意**：課程和主題結構來自你在前一階段核准的大綱。

你在分享或發佈前，會審查、編輯並精煉所有內容、測驗和視覺主題。

**試試看。**

試試 [**Content Composer**](https://contentcomposer.adobe.io/) ，描述你想建立的課程。

四個階段都有一位對話助理。 它會根據要求做出修改，建議替代方案，並說明能做什麼、不能做什麼。
