# 開始之前

在啟動 Adobe Learning Manager 內容撰寫器前，請確認以下事項：

>[!IMPORTANT]
>
>您必須使用有效的 Adobe Creative Cloud 帳號登入。 如果你還沒有，可以透過 Adobe Express 建立免費帳號。 欲了解更多資訊，請參閱 [「建立免費的 Adobe Express 帳號](https://helpx.adobe.com/tw/express/web/adobe-express-subscription/free.html)」。 建立 Adobe 帳號後，啟動 Content Composer 並登入開始建立課程。 如果您的組織已有 Creative Cloud 訂閱，請先聯絡管理員，讓他們在登入 Content Composer 前為您設定 Creative Cloud 帳號。

想要獲得最佳的 Content Composer **體驗，Google Chrome 是推薦的瀏覽器**。 Firefox 和 Safari 可能會在功能或行為上有所不同。

## 內容編輯器中的帳號選單與偏好設定

進入您的 Adobe 帳號設定、設定顯示偏好設定，並從內容撰寫者帳號選單開啟近期專案。

內容撰寫工具列包含 Adobe 通用導覽帳號選單。 用它來調整你的展示主題和語言，並快速重新開啟你最近參與過的專案。

### 打開帳號選單

在內容撰寫工具列右上角選擇你的個人檔案圖示，即可開啟帳號選單。

1. 設定你的偏好
2. 選擇您的個人檔案圖示以開啟帳號選單。
3. 選擇 [!UICONTROL Preferences]。 [!UICONTROL Preferences]對話開始了。
4. 在 [!UICONTROL Theme]下選 [!UICONTROL Light] 或 [!UICONTROL Dark] 以設定內容撰寫介面的顯示模式。
5. 在 [!UICONTROL Language]，選擇你偏好的顯示語言。
6. 選擇 [!UICONTROL Save] 套用您的變更。

>[!NOTE]
>
>主題與語言偏好僅適用於內容撰寫器介面。 它們不會影響課程的視覺主題或課程內容的語言。

## 開啟一個近期專案

帳號選單包含 [!UICONTROL Recents] 你最近開啟的內容撰寫者專案清單。

在列表中選擇任一個專案 [!UICONTROL Recents] 直接開啟。

## 選修要求

* 你對想涵蓋的主題領域有大致的概念。 你不需要在開始前就完全清楚。

* AI 透過對話引導你定義課程名稱、目標受眾及學習目標。

* 原始文件為選擇性。 你可以不上傳任何檔案，AI 會根據你的輸入生成內容。

* 如果你已有現有的資料想讓課程參考，可以在簡報階段上傳。 支援的檔案格式包括 PDF、Markdown（.md）、PowerPoint（.pptx）等，每種格式最高可達 100 MB。
