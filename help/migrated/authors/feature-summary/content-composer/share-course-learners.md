# 與學習者分享課程

與學習者分享課程，讓他們無需 LMS 連線或登入即可直接存取課程。 這在你希望學習者快速預覽或完成課程時非常有用——例如在試點、非正式培訓課程，或課程發佈到 Adobe Learning Manager 以供正式註冊與追蹤之前。

1. 在上方工具列選擇 **分享** 。

2. 選擇「 **學習者** 」標籤。

3. 選擇 **產生連結** 以建立學習者存取連結。

   ![](../assets/59_share_for_learners_generate_link_generated_links.png)

4. 將連結分享給你的學習者。

>[!IMPORTANT]
>
>學習者連結是依版本而定的。 每次更新課程時，產生並分享一個新連結，讓學習者能存取最新版本。 前一個連結繼續顯示早期版本。
>
>學習者存取不包含評論面板。 學習者無法新增評論或與審查工作流程互動。
