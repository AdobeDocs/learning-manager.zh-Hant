# 檢視並編輯測驗

![](../assets/12_quiz_block_question_view_updated.png)

課程結束時會出現一個評分測驗。 每題都會標註它所考的主題。

>[!NOTE]
>
>課堂中嵌入的知識檢定不會被評分。 只有課後小考會被評分。


補充一個問題：

1. 選擇問題文本來編輯，並使用文字編輯選項調整樣式。
   ![](../assets/13_quiz_question_text_edit_toolbar_updated.png)

2. 選擇你想標記為正確的選項旁的單選按鈕。

3. 你也可以為正確答案給予分數。
   ![](../assets/14_quiz_question_options_scoring_panel_updated.png)

4. 要刪除問題，請選擇 **「移除」選項**。

5. 要重新生成題目，請問助理：「重新生成第一課的小考。」
