# 在電子郵件建構器中自訂課程與實例電子郵件

作為作者，您可以為課程或特定課程實例自訂電子郵件。 這兩種程序都是從您的管理員提供的版面開始。

## 自訂課程等級的電子郵件

1. 開啟課程。
2. 選擇 **電子郵件範本**。
3. 選擇 **「課程電子郵件版面配置**」。
4. 自訂電子郵件內容。 設定字型、顏色、列與按鈕。
5. 儲存範本。
6. 發佈課程。

## 自訂實例層級電子郵件

當不同群組需要不同訊息時，請使用實例層級電子郵件。 你透過課程實例來管理這些同儕。

1. 開啟課程執行個體。
2. 開啟 **電子郵件建構器**。
3. 選擇可用的版面配置，或繼承該實例已使用的版面配置。
4. 更新訊息內容。
5. 儲存範本。

>[!NOTE]
>
>當兩者皆存在時，實例層級的電子郵件會覆蓋課程層級的範本。

## 使用標題變數與圖片作為電子郵件標頭

請使用 Title 變數搭配圖片元件來建立電子郵件標頭，而非橫幅元件。 橫幅元件的圖片不會出現在某些電子郵件用戶端（例如 Outlook）中。

Title 變數 EmailTitle 的運作方式與現有的 ChannelName 變數相同。 每封電子郵件都有其預設標題值。

新增標題標題的方法如下：

1. 為標頭圖片新增一個 Image 元件。
2. 新增一個文字元件，並從元件設定窗格的變數下拉選單插入標題變數。
3. 將文字元件置中對齊。 在全域版面配置中，將其置於頂部頁首。

5. 在變數前或後加入文字並保留 `EmailTitle`

如果您將圖片新增至橫幅元件，電子郵件建構器會顯示警告，指出該圖片可能無法在某些電子郵件用戶端正確顯示。 警告建議改用 Image 元件和 title 變數。

## 疑難排解

**你無法選擇版面配置。**
版面繼承取決於可用的父版面。 請您的管理員建立帳戶配置。

**您的電子郵件不會顯示最近的版面變更。**
範本可能已與其版面配置解除連結。 未連結的範本將不再獲得版面配置更新。

**學習者在某個情況下會收到與課程電子郵件不同的電子郵件。**
實例層級的電子郵件會覆蓋課程層級的範本。 檢視實例層級範本。

**您看不到課程或實例電子郵件的電子郵件建構器。**
Adobe 會分階段啟用電子郵件建構器。 請您的管理員確認您的帳戶已啟用電子郵件建構器。

**您的橫幅圖片不會出現在電子郵件中。**
某些電子郵件用戶端，例如 Outlook，不會顯示橫幅元件的圖片。 移除橫幅元件，新增一個圖片元件，並新增一個使用標題變數的文字元件。
