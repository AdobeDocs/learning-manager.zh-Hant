# 虛擬教練常見問題

## 著作

獲得關於建立、配置及排除虛擬教練角色扮演常見問題的解答。

1. **為什麼我的角色扮演分數是零，明明我涵蓋了大部分主題？**
檢查你的主題是否啟用**了成敗。**&#x200B;如果學習者在對話中完全沒有針對成敗主題提出任何回應，模擬的最終分數無論其他項目表現如何，都會為0分。 將成敗留給一兩個真正不可妥協的話題，以避免在合理嘗試中發生這種情況。 完整設定請參見 [「建立並發布虛擬教練角色扮演](/help/migrated/authors/feature-summary/virtual-coach/create-publish-virtual-coach-role-play.md)」。

2. **多重角色扮演可以包含多少個角色？**
單一劇本最多可有四個角色，每個角色皆有獨立配置，並擁有自己的 **角色**、 **個性**&#x200B;與 **人格關注點**。 當學習者需要在同一對話中應對多位利害關係人時，例如購買委員會簡報或執行小組審查，這點可運用。

3. **我該如何在語音、聊天和視訊之間選擇角色扮演？**
這取決於你選擇的 Persona 類型。 **系統角色** 支援 **語音與視訊** （帶有語音的動畫化身）或 **僅語音** 。 **自訂角色** 支援語音互動，且支援語音與視訊模式的角色可以分別啟用 **影片化身** 。 選擇語音與視訊模式以獲得最真實的模擬效果，或僅語音模式用於不需要視覺化身的情境，例如手機訓練。

4. **我該如何為 AI 共同創作助理寫出一個好的提示？**
輸入簡短描述，概述情境，例如 `Handling price objections in enterprise sales` 或 `Pitching our new product to a buying committee`。 AI 助理接著會提出後續問題，協助你建立概覽、AI 角色和評估主題。 盡可能提供關於情況、角色角色與關注點，以及你想如何衡量成功的背景——初步描述中更詳細，對話中來回對話也較少。 請參閱 [「收集虛擬教練角色扮演](/help/migrated/authors/feature-summary/virtual-coach/gather-materials-for-virtual-coach-role-play.md) 材料」以獲得更完整的提示範本。

5. **角色扮演發表後我可以編輯嗎？**
是的。 對於任何未公開的角色扮演，Persona 設定、主題及其他設定的變更都會立即生效。 如果角色扮演已經發佈並指派給學習者，修改後重新發布，讓學習者能看到最新版本。

關於一般產品、授權及行政問題，請參閱 [Adobe Learning Manager 虛擬教練常見問題](/help/migrated/authors/feature-summary/virtual-coach/virtual-coach-faq.md)。

## 訓練與合規

1. **Virtual Coach 如何保護客戶與學習者的資料？**
客戶資料以AES-256加密儲存，傳輸時以TLS 1.3+保護，並以唯一客戶識別碼邏輯分隔，確保客戶環境間的隔離。 這些控制措施透過年度第三方滲透測試驗證。

2. **虛擬教練的資料存放與處理在哪裡？**
客戶資料儲存在歐盟資料中心，支持符合歐洲隱私要求。

3. **Virtual Coach 能保存客戶和學習者資料多久？這些資料可以被刪除嗎？**
會話資料可在服務協議期間保留，客戶可設定公司專屬的保留政策。 個別使用者可以刪除自己的錄音，管理員可以進行大量刪除，且資料可在刪除前完成匯出。 同時也支援自動刪除機制與稽核日誌。

4. **客戶上傳的內容是否用於生成角色扮演以外的用途，例如人工智慧訓練或產品改進？**
不，客戶資料不會用於 AI 訓練。

5. **Virtual Coach 如何使用 AI？AI 生成的回應有哪些防護措施？**
Virtual Coach 利用生成式 AI 創造互動角色扮演體驗。 設有多項防護措施，包括針對暴力、仇恨言論、性內容及自殘等類別的 Azure OpenAI 內容過濾;提示層級的防護措施;以及讓 AI 專注於學習與開發應用場景的情境控制。 同時也進行 AI 安全測試，並對敏感請求採用安全導向提示轉換（Safety-Based Prompt Transformation）及澄清後拒絕行為等防護措施。 此外，合約承諾要求揭露 AI 產生的產出並遵守適用的 AI 法規。

6. **Virtual Coach 支持哪些隱私與合規標準？**
Virtual Coach 支援與 GDPR 相關的隱私保護、可設定的保存控制、審計日誌、使用者刪除功能，以及基於歐盟的資料託管。 合約還要求遵守適用法律與規範，包括歐盟人工智慧法案及加州人工智慧透明法案（SB-942）。

7. **誰擁有上傳到 Virtual Coach 的內容以及課程中產生的內容？**
客戶擁有上傳至虛擬教練的內容及課程中產生的內容。

8. **Virtual Coach 的資料存放在哪裡？是在 Adobe Learning Manager 裡，還是在 Virtual Coach 服務提供者那裡？**
角色扮演資料儲存在虛擬教練服務提供者的雲端基礎設施中，並託管於歐盟資料中心。

## 產品

1. **虛擬教練是如何為現有的 Adobe Learning Manager 客戶啟用的？**
請參閱 [啟動虛擬教練](/help/migrated/administrators/feature-summary/virtual-coach/manage-virtual-coach-usage-billing.md#activatevirtualcoach)

2. **虛擬教練啟動有效期多久？如何續約？**
Adobe Learning Manager 中的虛擬教練啟用有效期限為附加訂閱合約期間。 它並非自動永久的。 相反地，有效期限會與你的訂閱期間對齊。

   **續約：** 合約期滿後若想繼續使用虛擬教練，必須續訂。 購買時，Adobe 會提供一組啟用金鑰，帳戶管理員會用此金鑰在帳單區啟用虛擬教練。 若您續約，將收到指示及必要時的新啟用金鑰，以維持不中斷的存取權限。

   每個合約期間也會分配每月活躍用戶（MAU）積分。 合約結束時未使用的信用點數即告失效。 它們不會延續到新的時期。 您的啟用有效期會持續到付費虛擬教練訂閱有效期間，續訂則需透過您的 Adobe 帳號延長訂閱來進行。

3. **角色扮演建立或完成後，上傳的原始文件和產生的會話資料會發生什麼事？**
上傳的原始文件可用於建立與配置角色扮演情境、角色設定及評估標準。 學習者完成角色扮演後，虛擬教練會產生評估結果、分數、教練回饋及完成資訊，以支持學習與報告活動。 與角色扮演相關的資料依據適用的內容生命週期與保留政策仍可取得。

4. **學習者可以重試角色扮演嗎？**
是的。 學習者可以多次重複角色扮演課程，練習技能、應用教練回饋並提升表現。 完成角色扮演後，學習者可以檢視回饋，並開始新一輪持續發展技能的嘗試。

## 一般

1. **什麼是虛擬教練？**
虛擬教練是內建於 Adobe Learning Manager 的 AI 驅動角色扮演與教練功能。 它讓學習者能與即時智慧回應的 AI 角色練習真實對話，然後即時收到涵蓋他們所說內容及表達方式的表現報告。 完整說明請參考 [Virtual Coach 是什麼](/help/migrated/authors/feature-summary/virtual-coach/what-virtual-coach-is.md)。

2. **誰會使用虛擬教練？**
組織利用 Virtual Coach 來訓練銷售代表、客服團隊、客服人員、經理與領導者、新進員工、合作夥伴，以及學習新產品或流程的員工。 虛擬教練對所有已啟用的 Adobe Learning Manager 帳號的學習者、作者及管理員開放。 學習者可存取並完成角色扮演課程，作者可創建並發布角色扮演情境，管理員則負責管理學分並查看報告。

3. **Virtual Coach 會自動使用我現有的 Adobe Learning Manager 內容嗎？**
不。 作者必須為每個角色扮演提供參考資料，如劇本、銷售簡報、逐字稿、評分評分標準，或書面提示。 Virtual Coach 利用上傳的資料和角色定義來推動對話;它不會自動引用你內容庫或課程中已有的內容。 請參閱 [收集虛擬教練角色扮演](/help/migrated/authors/feature-summary/virtual-coach/gather-materials-for-virtual-coach-role-play.md) 的材料，了解該準備的事項。

4. **有哪些類型的角色扮演可供選擇？**
虛擬教練支援三個領域：銷售賦能、領導力發展與技能評估。 作者可從預先建立的範本中選擇，涵蓋B2B調查電話、冷電話、處理異議、給予嚴苛回饋，以及緩和客戶投訴等情境。 作者也可以利用 AI 助理從零開始創作自訂情境。 請參閱 [「創建並發佈虛擬教練角色扮演](/help/migrated/authors/feature-summary/virtual-coach/create-publish-virtual-coach-role-play.md)」。

5. **Virtual Coach 支援哪些語言？**
虛擬教練提供九種語言版本，涵蓋介面與模擬內容：德語（德國）、西班牙語（拉美語）、西班牙語（西班牙語）、法語（法國）、義大利語（義大利）、葡萄牙語（葡萄牙）、葡萄牙語（巴西）、荷蘭語（荷蘭）及英語。

6. **虛擬教練是如何取得執照和計費的？**
虛擬教練可作為 Adobe Learning Manager 的附加訂閱使用。 使用量以月活躍用戶數（MAUs）來衡量。 當學習者在曆月內啟動課程時，會消耗MAU學分;同學員當月額外修課則不會消耗額外學分。 年度合約到期時未使用的信用點數。 請參閱 [管理虛擬教練使用與帳單](/help/migrated/administrators/feature-summary/virtual-coach/manage-virtual-coach-usage-billing.md)。

7. **學習者的分數是如何計算的？**
每次會產出知識分數與風格分數。 知識分數反映學習者是否已處理所需主題並提供準確資訊。 風格分數反映學習者的溝通方式，包括語速、清晰度、填充詞、句子強度及聲音能量。 作者在設定情境時會設定每個元件的權重;常見的配置是 70% 知識與 30% 樣式。 請參閱 [了解您的虛擬教練績效報告](/help/migrated/learners/feature-summary/virtual-coach/understand-virtual-coach-performance-report.md)。

8. **學習者可以下載他們的績效報告嗎？**
是的。 除了在螢幕上查看報告外，學習者還可以下載PDF檔案，自行保存或與主管分享。

9. **學習者可以重試角色扮演嗎？**
是的。 學習者可以無限次嘗試角色扮演。 每次嘗試都是新的獨立會話，並產生新的績效報告。 只有一個日曆月的第一個會期會消耗一個MAU積分。

10. **學習者可以提交他們的課程進行人工審查嗎？**
不。

11. **虛擬教練有手機版嗎？**
Virtual Coach 支援於 Adobe Learning Manager 桌面版及行動網頁版，以及 API 支援。 目前版本的 Adobe Learning Manager 行動應用程式（iOS/Android）中無法使用。

12. **學習者資料會用來訓練 AI 嗎？**
不。 Virtual Coach 架設於符合 GDPR 規範的基礎設施上，且不使用個人學習者資料來訓練 AI 模型。

13. **Virtual Coach 的職業輔助工具和課程模組有什麼不同？**
工作輔助工具是一種獨立且隨需的資源，學習者可隨時直接從目錄中存取，無需註冊課程。 課程模組作為結構化課程序列的一部分，包含報名、完成追蹤及正式評量。 同一個角色扮演可以作為工作輔助工具發佈，並同時加入多門課程。 請參見 [「在課程](/help/migrated/authors/feature-summary/virtual-coach/add-virtual-coach-role-play-to-course.md)中新增虛擬教練角色扮演」。

14. **在推出新流程或產品時，我們應該如何包裝虛擬教練？**
將角色扮演與相關培訓內容一同包裝在課程或學習旅程中，並透過電子郵件或其他變革管理溝通方式分發課程連結。 虛擬教練最適合作為培訓的最後一哩——學習者完成相關內容後的檢查點，展示他們能應用這些內容，而非作為獨立活動。

15. **虛擬教練在 headless 或 API 實作中支援嗎？**
用於取得課程與工作輔助的公開 API 也會取得虛擬教練課程與工作輔助工具。 `jobAidType`這個篩選器專門用於取得虛擬教練的工作輔助資料。虛擬教練內容支援無頭玩家，而包含虛擬教練的課程與工作輔助則在流體玩家中工作。

關於建立和設定角色扮演的問題，請參閱此常見問題頁面。
