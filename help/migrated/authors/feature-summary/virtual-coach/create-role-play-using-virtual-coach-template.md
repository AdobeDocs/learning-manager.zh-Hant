# 使用虛擬教練範本創建角色扮演

只需從範本開始，幾分鐘內就能發布預先建構的虛擬教練情境，而非從零開始建立角色扮演。

**Virtual Coach 的特色**&#x200B;與&#x200B;**可用範本**&#x200B;區包含一組預先建構的角色扮演場景庫，涵蓋銷售、領導力及技能評估情境。使用範本是建立角色扮演最快的方式——角色設定、對話開場、主題和評分都已設定好，你可以立即發布或在發佈前自訂任何細節。

範本依據領域、模擬類型及語言組織。 使用篩選器依互動類型縮小範圍，例如 **語音對話** 或 **網路攝影機練習**，或依關鍵字搜尋最接近你使用情境的情境。

>[!TIP]
>
>選擇範本不會鎖定你的預設設定。 每個欄位，包括角色背景、主題、評分權重和對話開場，都可以在選擇範本後編輯。 把範本當作起點，而不是最終設計。 關於每個可配置欄位的完整說明，請參閱 [建立並發布虛擬教練角色扮演](/help/migrated/authors/feature-summary/virtual-coach/create-publish-virtual-coach-role-play.md)。


1. 以作者身份登入 Adobe Learning Manager。
2. 在左側導覽窗格選擇 **虛擬教練** 。
3. 選擇 **立即**&#x200B;建立。
4. 瀏覽 **可用範本** 區塊，或使用 **搜尋** 欄及領域、模擬類型和語言篩選器，找到符合你情境的範本。

   ![](/help/migrated/authors/feature-summary/assets/virtual-coach25.png)
5. 選擇範本圖塊來開啟它。 檢視角色、主題和評分配置。

   ![](/help/migrated/authors/feature-summary/assets/virtual_coach17.png)
   *在決定是否自訂範本前，先檢視預先填寫的對話上下文和人物背景。*

6. 若要依原樣使用範本，請選擇 **發佈**。 要先自訂，請選擇任一區塊並在發布前編輯相關欄位。

一旦發佈，角色扮演會被加入 **內容庫** ，並準備加入工作輔助工具並指派到課程中。 請參閱 [在課程](/help/migrated/authors/feature-summary/virtual-coach/add-virtual-coach-role-play-to-course.md) 中新增虛擬教練角色扮演以了解這些步驟，或 [用虛擬教練](/help/migrated/learners/feature-summary/virtual-coach/practice-role-play-with-virtual-coach.md) 練習角色扮演，看看學習者的學習體驗。
