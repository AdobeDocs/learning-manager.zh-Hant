# 適應性課程的多重選課

## 概觀

多重報名讓學習者可以同時報名同一門課程的多個實例。 在 Adobe Learning Manager 中，您現在可以為自適應課程啟用多重報名功能。

## 關於適應性課程的多重選課

自適應課程只向每位學習者展示符合其使用者群的模組。 啟用多重報名後，學員可以多次參加該課程的實例，例如不同月份的課程。

自適應課程是在模組層級追蹤候補名單，而非實例層級。 學習者可能同時在部分模組進行中，同時在其他模組被列入候補名單。 例如，一門課程有兩個實例，每個實例的座位限制為一位。 第一位學員同時報名並同時佔用兩個名額。 第二位同時報名的學員會在兩項課程中被列入候補名單。

## 啟用自適應課程的多重報名功能

1. 以作者身分登入 Adobe Learning Manager。
2. 在左側導覽中，選擇&#x200B;**「課程」。**&#x200B;開啟一個適應性課程或自行建立一個。
3. 新增模組。 對於每個內容模組，選擇 **「新增規則** 」以設定可查看該模組的使用者群組及強制查看規則的使用者群組。
4. 選擇「 **儲存**」。 多重登記選項將啟用。
5. 開啟 **多重登記** 切換。
6. 建立你需要的實例。 無論是課堂還是虛擬課堂，請設定座位限制。
7. 選擇 **「發佈**」。

學習者現在可以報名多於一個課程實例。

## 座位限制與候補名單行為

自適應課程會對每間教室或虛擬教室課堂強制執行座位限制。 學員會立即報名，僅在已滿的課程中列入候補名單。 學習者可以立即開始所有其他模組。

| 狀況 | 結果 |
|------------------------------------------------------------------------------|--------------------------------------------------------------------------------------------------------------|
| 所有可見的場次都有空位 | 學習者註冊時可完整使用所有模組。 |
| 一個或多個可見的工作階段已滿 | 學員僅在完整課程中被登記並列入候補名單。 |
| 您將一個沒有名額的強制課程加入已註冊學習者的課程 | 學習者在新課程中被列入候補名單。 現有的進展與存取權則不受影響。 |
| 使用者群組變更會將課程從學習者的可見模組中移除 | Adobe Learning Manager 立即釋放該席位。 |
| 學習者切換到另一個實例 | 已完成的模組會保持已完成狀態。 座位僅用於學習者尚未完成的可見模組。 |

## 自適應學習路徑的報名與完成規則

作者現在可以在 Adobe Learning Manager 的自適應學習路徑中新增自適應課程。 報名、候補名單與完成皆遵循結合章節設定與課程設定的規則，由作者設定。

### 自適應學習路徑如何評估學習者

Adobe Learning Manager 會評估在各部分層級及課程層級的可見度。 章節規則決定學習者是否會看到該章節及其自適應課程。 模組規則會決定每個自適應課程中的學習者是否已註冊該課程。

每當 Adaptive LP 內的自適應課程有本科變更時，學習者將自動被選名。 同時，學習者也會收到自動報名通知和電子郵件通知。

### 招生評估規則

當您將學習者註冊到自適應學習路徑時，Adobe Learning Manager 會依下列順序檢查該路徑：

| 訂購 | 確認 | 結果 |
|-----------|----------------------------------|------------------------------------------------------------------------------------------------------------------------------------------------------------|
| 1 | 區段可見性 | Adobe Learning Manager 僅在課程部分對學習者可見時，才會檢查是否已報名。 |
| 2 | 課程資格 | 如果課程沒有學習者必須修讀的模組，學習者就不會註冊該課程。 該課程不計入學習路徑完成度。 |
| 3 | 無合格課程的班級 | 如果某個區段僅包含自適應性課程，且學習者不符合任何課程資格，Adobe Learning Manager 會跳過該區段。 |
| 4 | 學習路徑報名 | 如果任何必修部分都不適用於學習者，則該學習者不會被註冊在學習路徑中。 |

如果學習者已經註冊在屬於該學習路徑實例的課程實例中，Adobe Learning Manager 會使用該註冊資料。

註冊後，適用以下規則：

* 如果因可見性/規則變更而因可見性而一開始跳過課程的學習者，若該自適應課程因可見性/強制規則變更而可見，則可自動註冊。
* 使用者群組變更或課程變更可能會使學習者從自適應課程中取消註冊。 如果路徑中沒有強制內容，學習者將從路徑中取消註冊。
* 若有章節變更，學習者將不會收到任何自動報名通知或電子郵件。 只要重新載入頁面，學習者就能看到這些變更。

### 自適應學習路徑中的等待名單行為

候補名單是在會話層級運作，不是實例層級。 這同樣適用於學習路徑中的自適應課程。

| 劇情 | 行為 |
|----------------------------------------------------------------------------------|----------------------------------------------------------------------------------------------------------------------------------|
| 路徑中沒有任何自適應課程設有教室或虛擬教室模組 | 不設候補名單。 |
| 自適應課程包含教室或虛擬教室模組，且不會選擇任何實例 | 課程預設為 **「無實例**」。 學習者可在任何實例中報名，且僅在已滿的課程中列入候補名單。 |
| 在註冊前會選擇一個實例 | 學習者已註冊該實例，僅在已滿的課程中列入候補名單。 |

若要管理候補名單上的學習者，請開啟自適應課程，並在「等候名單&#x200B;**」標籤>**&#x200B;選擇&#x200B;**「學習者**」。對於彈性學習路徑與自適應學習路徑中的自適應課程，候補名單的學習者只會顯示在 **課程的「等候名單** 」標籤中，而不會出現在學習路徑之下。

### 重新整理完成與回滾行為

Adobe Learning Manager 不會在使用者群組或規則變更時自動撤銷完成。 完成的學習者會保持完成狀態，直到你重新整理完成。

* 在學習路徑上執行 **刷新完成** 。 你無法單獨為學習者刷新適應性課程。

* 每門自適應課程會根據學習者目前的必修模組先行重新計算。 學習路徑會根據目前必修章節及更新後的課程狀態重新計算。

* 如果課程或路徑不再完成，學習者的狀態會變更為進行中。 原始完成的成績仍作為歷史記錄保存在學習者成績單上。

* 完成回滾會找出因使用者群組變更或重新發佈而模組變更的自適應課程。 它會重新計算那些課程，然後重新計算學習路徑。 當回滾完成時，工作狀態會顯示 **為成功** 。

候補名單會在模組層級進行追蹤。 一位學習者可能會在一次以上的完整課程中被列入候補名單。 例如，某門課程有兩個座位限制，各有一個名額上限。 第一位學員同時報名並同時佔用兩個名額。 在兩個實例中同時報名的第二位學習者會出現 **在每個實例的「等候名單** 」標籤中。

### 為候補學習者分配名額

當學習者取消註冊、作者增加座位限制，或學習者切換實例時，Adobe Learning Manager 會依報名日期順序清除等候名單。 您也可以手動分配座位。

1. 開啟自適應課程。
2. 選擇 **「學習者** 」> **「等候名單** 」標籤。
3. 勾選您想分配名額的每位學員旁的核取方塊。
4. 選擇 **「分配席位**」。

Adobe Learning Manager 會一次性從所有等候名單上的課程中清除每位已選定的學習者，而非僅限於您正在觀看的課程。 系統假設您已為學習者安排座位。
