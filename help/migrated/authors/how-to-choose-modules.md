# 如何選擇課程模組？

學習管理軟體支援四種課程模組。 如果您負責設計培訓課程，您可能會想知道應該選擇哪種類型的模組以符合組織的需求。 根據貴組織的預算與受眾需求，您可以選擇課程模組。 以下說明了每種模組類型的典型使用案例，供參考。

**何時選擇教室模組？**

<table>
 <tbody>
  <tr>
   <td><img src="assets/classroom-module.png"></td>
   <td>
    <p>在課堂訓練中，學員由講師親自參加課程。 在這類訓練中，學員必須在指定時間和地點參加課程。 教練應該隨時待命。 如果學習者和講師來自不同地點，組織將所有學習者和講師集中在同一地點會花費大量時間與成本。</p>
    <p><strong>優點</strong></p>
    <ul>
     <li>此類訓練的主要好處是學習者的社交互動。 </li>
     <li>你可以選擇課堂模組，適合需要大量面對面合作和學習者參與的課程。 </li>
     <li>此外，如果課程主題複雜、新穎，或需要學習者規劃與理解概念的紀律，那麼課堂模組是合適的選擇。</li>
    </ul></td>
  </tr>
 </tbody>
</table>

**什麼時候該選擇自學課程？**

<table>
 <tbody>
  <tr>
   <td><img src="assets/self-placed-module.png"></td>
   <td>
    <p>在自學進度訓練中，學員可以依照自己的步調開始並完成課程。 學習者不必在指定時間和地點上課。 然而，學習者必須以自律的方式掌控節奏並掌控學習進度。</p>
    <p> </p>
    <p><strong>優點</strong></p>
    <ul>
     <li>你可以選擇這種模組給能自行管理學習時間表的學習者。 </li>
     <li>當你想在更短時間內接觸更多學習者時， </li>
     <li>當你想要控制相關成本時。</li>
    </ul></td>
  </tr>
 </tbody>
</table>

**什麼時候該選擇活動模組？**

<table>
 <tbody>
  <tr>
   <td><img src="assets/activity.png"></td>
   <td>
    <p>在活動訓練中，學習者需要完成一系列線上活動，如練習、問卷和工作坊。 學習者直接參與這些活動，而非從教師那裡獲得任何輸入或資源。 這些活動是自我節奏的，但有時可能有時間限制。</p>
    <p> </p>
    <p><strong>優點</strong></p>
    <ul>
     <li>你可以選擇活動模組作為課堂和虛擬訓練的補充。</li>
     <li>完成課堂訓練後，學習者可以在課堂外的活動及線上社群中應用所學。</li>
    </ul></td>
  </tr>
 </tbody>
</table>

**何時選擇虛擬教室模組？**

<table>
 <tbody>
  <tr>
   <td><img src="assets/virtual-classroom.png"></td>
   <td>
    <p>當您希望學習者能參加線上環境下由教師主導的即時課程時，請使用虛擬教室模組。 這些課程可透過 Learning Manager 內建的 AI 虛擬實況訓練工具 Live Hub 進行，或透過外部工具如 Zoom、Microsoft Teams 等進行。</p>
    <p> </p>
    <p> </p>
    <p><strong>優點</strong></p>
    <ul>
     <li>適合需要與講師即時互動的課程，如討論、問答或引導學習</li>
     <li>讓分散式團隊能在不同地點進行訓練，而無需實體駐守。 </li>
     <li>降低學員與講師的後勤成本。</li>
     <li>透過 Live Hub，你可以直接在 Learning Manager 內進行課程，無需依賴外部工具，確保學習體驗無縫且整合。 其 AI 功能也能幫助你快速找到合適的老師和時段。</li>
    </ul></td>
  </tr>
 </tbody>
</table>
