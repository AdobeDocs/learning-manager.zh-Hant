# Adobe Learning Manager 文件

企業學習管理系統（Enterprise LMS）提供可擴展的學習者體驗、合規訓練及技能導向發展。 選擇你的角色，直接前往你的指南。 透過精心策劃的 Adobe Learning Manager Academy 課程與引導式學習路徑，培養實用的產品技能。
